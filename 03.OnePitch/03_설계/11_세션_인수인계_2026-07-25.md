# 세션 인수인계 (2026-07-25)

> 이 문서는 다음 세션(또는 compact 이후)이 빠르게 맥락을 잡기 위한 요약이다. 상세 구현 기록은 [10_구현_Phase_계획](10_구현_Phase_계획.md) §6-115~§6-124, 남은 작업 전체 목록은 같은 문서 §5 이월 레지스트리가 정본(source of truth)이다 — 이 문서는 그걸 대체하지 않고 빠른 오리엔테이션용.

## 이번 세션에 한 일 (커밋 순서대로)

1. **`advance()` 성능 조사 + 개선**(§6-115~119) — 실측 결과 1시즌 진행에 73초, 워스트케이스 46초. 원인 추적:
   - N+1 쿼리 배치(`StatScoreCache`) — 개선폭 작음(~4.5%).
   - **스케줄 분산**(프로/프로2군 3연전+휴식일 실제 KBO식으로 전환, 고교·대학 권역/리그 시작일 요일 오프셋, 포스트시즌 11개 대회 시작일 분산) — 워스트케이스 46s→24s.
   - **`schedule`/`npc` 테이블에 인덱스가 아예 없었던 게 진짜 원인**(migration v25 추가) — 워스트케이스 24s→**5.1s**(-89%, 원래 대비). 이게 가장 컸다.
   - `engine/src/bin/perf_probe.rs`(커밋됨, 영구 진단 도구) — `cargo run --release --bin perf_probe -- <시즌수>`로 재측정 가능.

2. **이벤트 콘텐츠 저작**(§6-120~121) — 문장 뱅크 엔진 신설(`events.bodies`: JSON 배열, 발동 시 직전 문장 제외하고 랜덤 선택 — FM/OOTP식 반복 회피). 고교 1·2차 배치로 14개 신규 저작. **38개 카탈로그 중 25개 완료, 13개 남음**(대부분 프로/대학 전용이라 고교엔 해당 없음; 데뷔전·대회우승 확정은 콜백 훅 신설 필요, 이월).

3. **순위 변동 알림**(§6-122) — 팀/학교 순위(지역·전국) + 투수 기대주 순위(로테이션 서열화에 이미 쓰는 점수 재사용, 새 공식 발명 안 함), 월 1회 체크·변동 시에만 `inbox` 알림. 선택지 없는 순수 정보형 — 이 경로를 실제 콘텐츠로 쓴 첫 사례.

4. **버그 2건 발견 + 수정**(§6-123, 스크린샷 검증 도중 발견) — `InboxScreen._FilterBar`가 `Wrap` 안에 `Spacer`(`Expanded`)를 넣어 특정 리렌더 시점에 크래시(수정: `Row(Expanded(Wrap)+고정컨트롤)`로 재구성). 청백전 결과 알림이 전국 고교·대학 전 팀(수백 개)에서 무조건 주인공 inbox로 왔던 스팸 버그(수정: `is_protagonist_team` 체크로 소속팀만).

5. **"일정" 탭 캘린더 뷰**(§6-124) — 세로 리스트 → 월간 그리드/주간 뷰 토글. 새 파일 `app/lib/features/league/schedule_calendar_tab.dart`. 엔진 API 추가 없음(기존 `getTeamSchedule`+`calendarDateForDay`만 재사용, 요일은 Dart `DateTime.weekday`로 클라이언트 계산).

## 알아두면 좋은 관례(이번 세션에 확립/재확인)

- **검증 사이클**(엔진 변경 시): `cargo build --lib` → `cargo test --lib` → `cargo clippy --lib --tests --bins`(경고 0) → `cargo build --release` → `flutter test -j 1`(병렬 실행 시 리소스 경합으로 불안정, 순차 권장) → `cargo run --release --bin balance_harness -- 5 3` 스모크 → `10_구현_Phase_계획.md`에 §6-N 기록 → 커밋.
- **콘텐츠 시딩**: `dart run bin/tool.dart content seed`(반드시 `tool/` 디렉터리에서, `dart run tool ...`(패키지명 호출)은 `Platform.script` 경로 해석이 깨져서 안 됨) → `engine/content.db` 갱신 → **`app/assets/content.db`에 수동 `cp` 필수**(자동 동기화 없음).
- **위젯 스크린샷 캡처 레시피**(실제 화면 검증용, 실제 UI 없이도 재현 가능): `testWidgets`에서 새 게임 생성 → 필요하면 `advance()` 반복(단, 한 번의 `advance()` 호출이 pending 없으면 며칠씩 조용히 건너뛸 수 있어 "오늘"이 의도한 시점을 벗어날 수 있음 — 필요시 화면 내비게이션(화살표 등)으로 원하는 시점으로 되돌아가는 안전장치를 넣을 것) → `RepaintBoundary`로 감싸고 `tester.runAsync(() async { ... boundary.toImage() ... })`(안 감싸면 조용히 멈춤) → 한글 폰트는 `C:/Windows/Fonts/malgun.ttf`를 `FontLoader`(`package:flutter/services.dart`)로 로드 + `ThemeData(fontFamily: ...)` 지정(안 하면 글자가 네모 박스로 렌더) → PNG로 저장. 스크린샷 전용 테스트 파일은 `_scratch_*_test.dart`로 만들고 확인 후 삭제(커밋 대상 아님).
- **`advance()`의 "하루씩 조용히 건너뛰기"**: pending action이 없으면 여러 날을 한 호출에 압축 처리 — 스크린샷/테스트에서 "오늘"이 예상 밖으로 멀리 갈 수 있다는 뜻. 날짜에 의존하는 테스트는 하드코딩된 day 값보다 실제 일정 데이터에서 계산한 값을 쓰는 게 안전(이번 세션에 한 번 걸림).
