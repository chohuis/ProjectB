## 1. 지금 무엇이 만들어지나 — 실측

씨앗 20260803 · KBL 20팀(1·2군) · 총원 600 · **세계 생성 직후**(시즌 돌리기 전)

### ① 포지션 — 공백은 없다. 대신 **스무 팀이 똑같다**

```
포지션 공백 팀        0/20
포지션 분포          C40 1B40 2B40 3B40 SS40 LF40 CF40 RF40
한 팀 구성           SP6 RP7 CP1 · C2 1B2 2B2 3B2 SS2 LF2 CF2 RF2  (야수16 투수14)
서로 다른 구성       1 / 20팀        ← 전 팀이 글자 하나까지 같다
```

🔴 **"초기 세팅인데 포지션 부족"은 생성 문제가 아니다.** 생성은 깨끗하고,
공백은 시즌이 돌면서 은퇴·방출·승강으로 빠져 생긴다. 검사(`test:rosterbalance`)가
잡는 것도 그쪽이다.

⚠ 다만 **팀 색깔이 아예 없다.** 어느 팀도 외야가 두껍거나 불펜이 얇지 않다.

### ② 경력 — 숫자는 있는데 **뒷받침하는 이력이 없다**

```
연차 분포     0년 4명 · 3년 73명 · 8년 49명 · 12년 18명 · 16년 1명   (0~16년차)
계약연수      1년 131 · 2년 159 · 3년 124 · 4년 132 · 5년 54
나이          20~36세     · 나이보다 연차가 많은 선수 0명 (여기까진 앞뒤가 맞다)
출신교        600/600 비어 있음   (schoolId: "")
졸업년        600/600 비어 있음   (graduationYear: 0)
career_history 행                  0개
```

🔴 **12년차 선수의 지난 12년이 존재하지 않는다.** `career_history` 테이블은
`slotdb.cjs`에 있고 `PlayerDetailModal`이 읽는데, **세계 생성이 안 채운다.**
그래서 "10년차·7년차인데 그전에 어느 팀에서 어떻게 온 건지 알 수 없다"가 된다.

### ③ 용병 — 규칙이 원하는 걸 이미 적어 뒀는데 절반만 선다

`foreignRules.origin._note2`:

> 예전엔 무에서 생성했다(`careerHistory: []`). **어디서 왔다는 기록이 없어
> 화면이 국내 신인과 구분을 못 했다.** ABL·JBL이 열렸으므로 실제 선수를 데려온다.

```

충원 ②  generate_foreign_players   부족분은 새로 찍는다 (proServiceYears 0 · 출신교 없음)
세계 첫 해   KBL 용병 **0명**   — `applyForeignTurnover`가 오프시즌에만 돈다
```

## 3. 요구사항

### A. 포지션 구성

- **A1** 모든 팀이 **모든 수비 포지션을 최소 1명** 갖는다. **포수만 2명**이다
  (포수 공백은 화면에서 가장 눈에 띄고 대체가 안 된다)
- **A2** 그 위의 여유분은 **팀마다 다르다.** 스무 팀이 같은 구성이면 안 된다
- **A3** 편차는 **구단 성향에서 나온다** — 랜덤이 아니다. 성향축 12개 중
  `developmentFocus` · `winNowPressure` · `farmInvestment` 같은 축이 자연스럽다
  (어느 축을 쓸지는 §5에서 정한다)
- **A4** 투수는 야수와 **다른 산식**이다. 선발/불펜/마무리 편성이 따로 있고,
  팀마다 선발이 두껍거나 불펜이 두껍다
- **A5** 시즌이 돌아 공백이 생기면 **보충 경로가 있다** (지금은 얇은 팀에서
  포수만 예외로 채우는 갈래가 `roster_gen`에 있다 — 그걸 넓히는 방향)

### B. 경력

- **B1** 모든 프로 선수가 **데뷔 연도와 출신**을 갖는다
  - 국내: 출신 고교(또는 대학) + 드래프트 연도·라운드
  - 용병: 원 소속 리그·팀 + 그 리그에서 뛴 기간
- **B2** **연차 = 이력의 길이**와 일치한다. 12년차면 12줄이 있다
- **B3** 연도별 **리그·팀 이력**이 `career_history`에 실제로 들어간다
  (표도 화면도 이미 있다 — 채우기만 하면 된다)
- **B4** 각 줄에 **요약 성적 한 줄**이 붙는다 (타자: 타율·홈런·타점 / 투수: ERA·승·세이브 수준)
- **B5** 계약·FA 자격·드래프트 대상 판정이 이력과 **모순되지 않는다**
  - FA 자격은 리그별이다 — KBL 5년 · ABL 6년 · JBL 4년 · 그 외 9년 (`faRules.eligibleYears`)
  - 5년차 이상이면 **FA를 한 번 겪었어야** 자연스럽다. 그 흔적이 이력에 남는다
- **B6** 팀 이동에는 **이유**가 붙는다 — 드래프트 / FA / 트레이드 / 방출 / 승강 / 용병 유입
  (`transactions` 테이블에 `category`가 이미 그 목록이다)

### C. 용병

- **C1** **어디서 왔는지** 보인다 — ABL 2군인지, ABL 1군에서 오래 뛰다 말년에 온 건지
- **C2** 그 리그에서의 이력이 **함께 온다** (B3·B4와 같은 형식)
- **C3** **개막부터 팀당 정원을 채운다.** 지금은 첫 해가 용병 0명이라
  **첫 시즌만 다른 규칙으로 돈다**
- **C4** 새로 찍는 폴백(`generate_foreign_players`)도 **이력을 갖고 태어난다**.
  지금은 `proServiceYears: 0`·출신교 없음이라 국내 신인과 구분이 안 된다

### D. 상무 (실측에서 나온 것 · 위와 별건일 수 있다)

- **D1** 상무 피닉스가 **11명**이다(정원 30 · 야수 6). 타순이 안 선다
- **D2** 08-28에 Phase 1/2 선발을 고친 자리다. **왜 인원이 안 차는지는 아직 안 봤다** —
  짐작하지 않는다. 고치기 전에 재현부터 한다

## 4. 🔴 내가 세운 가정 — 틀리면 여기부터 고친다

사용자 답 *"각 포지션 1-2명(이건 팀마다 랜덤 투수는 다르게 계산 필요에 맞춰서) + 포수 2명"*
을 이렇게 읽었다:

1. **총원은 지금대로 30명을 유지한다.** 포지션별 하한만 1~2로 낮추고,
   남는 자리를 성향에 따라 배분한다. → 어떤 팀은 CF가 3명, 어떤 팀은 1명
2. **하한이 1이 되는 포지션과 2가 되는 포지션이 팀마다 갈린다.** 포수만 항상 2
3. **투수 총원은 `pitcherRatio`(0.45)를 유지**하고, 그 안에서 SP/RP/CP 비율이 팀마다 다르다

⚠ **1번이 특히 중요하다.** 하한만 낮추고 총원을 안 묶으면 야수가 9명까지 줄어
타순이 안 서는 팀이 생긴다 — 지금 상무가 그 꼴이다.

## 5. 아직 안 정한 것

- **A3 어느 성향축을 쓰나** — 12축 중 무엇이 포지션 두께를 정하는지
- **B4 요약 성적을 어떻게 합성하나** — 그 시절 능력치에서 역산할지, 분포에서 뽑을지
- **B5 과거 FA·트레이드를 실제 사건으로 만들지**, 이력 줄에만 적을지
- **C3 첫 해 용병의 이력 길이** — ABL 2군 3년? 1군 8년 뒤 말년?
- **세계 생성 시간을 얼마나 쓸 수 있나** — 이력 합성은 공짜가 아니다
