## 0. 🔴 "사람만 할 수 있다"가 아니었다

지시서 3주차가 *"눈확인 1차 — 사람만 할 수 있다"* 라고 적었다.
그런데 **`scripts/drive.mjs` 가 이미 있다** — Playwright 로 앱을 실제로 띄우고
DOM 을 조작하고 **스크린샷을 남긴다.** 그 머리말이 존재 이유를 이렇게 적어 뒀다:

> 화면은 자동 테스트가 못 본다 — 이 프로젝트에서 이미 그 종류의 결함이 여러 번
> 나왔다(상무 모달 `curYear` ReferenceError 로 모달이 통째로 안 열린 건 등).

**찍은 그림은 읽을 수 있다.** 그래서 눈확인을 돌렸다.

⚠ 이 저장소에서 "없다"가 네 번째로 틀렸다 — A1 · 엔딩 · 히스토리 · **눈확인 수단**.

### 어떻게 돌리나

```
npm run dev:ui                         # Vite 5174. dev 는 쓰지 마라 (predev 가 build:native 다 — R1)
DRIVE_USER_DATA=1 SCREENSHOT_DIR=<밖> node scripts/drive.mjs <명령파일>
```

🔴 **`DRIVE_USER_DATA=1` 을 반드시 켠다.** 안 켜면 사용자의 실제 세이브를 쓴다.
슬롯이 셋뿐이라 다 차 있으면 새 게임을 못 만들고, 지우거나 앞으로 돌리면
**그 세이브가 바뀐다.** 켜면 임시 저장소로 뜬다 — 새 게임으로 확인하라는
규칙과도 맞는다.

⚠ `SCREENSHOT_DIR` 도 저장소 밖으로 뺐다. 안 그러면 `resource/logs/shots` 에 쌓인다.

## 3. 🔴 눈확인에서만 나온 결함 셋 — **정적 검사로는 못 잡는다**

셋 다 "코드는 맞는데 화면이 틀린" 종류다. 띄워 보기 전엔 안 보였다.

### ① 태그가 안 읽혔다 — 없는 토큰에 기대고 있었다

역대 탭의 통산 수상 태그가 **어두운 바탕에 어두운 글자**로 나왔다.

```
background: var(--accent-weak, #3a3320)
```

`--accent-weak` 는 **저장소 어디에도 정의된 적이 없다.** 네 군데가 전부
하드코딩 폴백(짙은 올리브)으로 떨어졌고, 글자색은 안 정해서 지면 색 그대로였다.

⚠ **내 것만이 아니었다.** `LeaguePage` 의 `.aw-tag`(그 해 수상)와
`CareerEndScreen` 의 `.yr-ps` · `.yr-aw`(연도별 포스트시즌·수상)도 같았다.
내가 `.ha-tag` 를 만들 때 그 관례를 그대로 베낀 것이다.

고침 — **지면 성격에 따라 갈랐다.** 없는 토큰을 새로 정의하지 않았다.
`.yr-ps`(초록)와 `.aw-tag`(금색)가 서로 다른 색을 기대해서 토큰 하나로는
둘 다 못 맞춘다.

| 지면 | 처리 |
|---|---|
| `LeaguePage` — 테마가 도는 지면 | `var(--panel-sunk)` + `var(--warn)` |
| `CareerEndScreen` — **어두운 섬** | 색을 직접 정한다 (그 파일 머리말 규칙) |

### ② 코치 이름 자리에 `staff:TEAM_HS_DOSEONG_COA1` 이 떴다

결산의 `사람` 절이 `npcs` 에서 이름을 찾았다. **코치·감독은 `npcs` 에 없다** —
스태프는 따로 산다. 그래서 원문 id 가 그대로 화면에 나왔다.

⚠ **조회할 필요가 없었다.** `Relationship` 은 person VIEW 조인에서 `name` 을
이미 받아 온다. `PeoplePage` 는 처음부터 그걸 쓰고 있었다 —
없으면 역할명(`(코치)`)으로 대체한다.

🔴 **기존 검사가 틀린 전제를 못박고 있었다** — *"personId 로 이름을 찾아야
한다"*. 그게 이 결함의 원인이었다. 그 단언을 바꿨다.

### ③ 팀 이름 폴백이 원문 id 였다

`대학 졸업 TEAM_UNIV_HANYANG`. 목록에 없는 팀이면 영문 id 가 샌다.
`LeaguePage` 는 같은 문제를 `(기록 없음)` 으로 **이미 막아 뒀다** — 같게 맞췄다.

> ②·③ 은 `careerEventLabel.ts` 머리말이 이미 못박은 결함 모양이다 —
> **"폴백이 원문이면 안 된다."** 라벨은 고쳐 뒀는데 이름은 안 고쳐져 있었다.

## 6. ✅ 눈확인 2차 — A 가 지목한 넷 (A 회신 3차 §7)

대기 동작은 **`season_meta.json` 을 왕복한다**(`hydrateFromSlot` 이 아는 유형만
남긴다). 그래서 픽스처로 띄울 수 있다 — 커리어를 몇 시즌 돌릴 필요가 없다.

⚠ **`stats` 는 그 블롭에 넣으면 안 된다.** `readSeason` 이 `season.stats = {}`
로 덮고 **`season_stats` 테이블에서 다시 채운다.** 처음에 블롭에 넣었다가
`AVG - HR - OPS -` 로 떠서 30분을 헤맸다. 성적은 테이블에 넣는다.

### ① 계약 협상 — **타자 주인공. A 의 수정이 화면까지 닿았다**

A 가 *"엔진 직접 호출로만 쟀다"* 며 화면 확인을 요청한 자리다.
타자 주인공(.305 · 24홈런 · OPS .898)으로 띄웠다:

```
AVG 0.305   HR 24   OPS 0.898   시즌 평점 75   시장가 7,320만원
```

**평점이 75 다** — 엔진의 "기록 없음" 기본값 50 이 아니다. A 가 적은 타자
곡선(OPS .900 → 75)과 맞는다. 역직렬화가 죽던 자리가 **살았다.**

### ② 진로 허브 — **필터가 맞다** (결함 아니다)

프로 주인공에 억지로 띄웠더니 셋만 떴다(드래프트·해외 2군·군입대).
"대학·독립이 빠졌다"로 볼 뻔했는데, **아마추어로 다시 띄우니 다섯이 다 떴다**:

```
드래프트 참가 · 대학 진학 · 독립리그 · 해외 2군 · 군입대(즉시 확정)
```

**`careerStage` 로 거르는 게 맞다.** 픽스처가 비현실적이었을 뿐이다 —
보고하기 전에 한 번 더 띄워 본 것이 갈랐다.

### ③ 부상 치료 — 정상

중증 `UCL 부분 파열` 에 세 선택지(보존 재활 · PRP 주사+재활 · **수술로 전환**).

**"수술은 심각도가 아니라 치료법"** 이라는 게 화면으로 증명된다
(내가 `severity` 에서 `"surgery"` 를 빼자고 한 근거다).

### ④ 드래프트 관전 — 정상. **빈 공간은 의도다**

실제 플레이 W32 에서 열었다. `KBL 드래프트 보드` 안내(8구단 · 10라운드 ·
80픽 · 스네이크 · 참관 모드)가 뜬다.

⚠ 시작 전에는 **아래가 흰 여백**이다. 결함으로 볼 뻔했는데
`DraftBoardModal` 을 보니 `{#if !started}` 뒤 `{:else}` 가 보드를 채우고
패널이 `flex: 1 1 0` 로 늘어난다 — **시트 높이를 미리 잡아 레이아웃이 튀지
않게 한 것**이다. 톤이 걸리면 사용자 판단이다.

## 7. 🔴 해상도 2차 — **경기 화면에서 능력치가 소리 없이 잘렸다**

A 가 `drive.mjs` 에 `resize` 를 넣어 줘서(회신 3차 §4) 경기 화면을 해상도별로
띄울 수 있게 됐다. 그러자 바로 나왔다.

### 증상

`.bar-list` · `.line-list` 가 `overflow: hidden` 이라 카드가 짧아지면 막대가
**그냥 사라진다.** 스크롤바도 없어서 **잘린 줄도 모른다.**
투구를 고르라고 띄운 **상대 타자 능력치**가 그 자리다.

```
해상도        잘린 높이 [타자, 투수]
1280×720      [104, 82]   ← FHD @150%
1366×768      [ 65, 43]   ← 노트북 표준
1536×864 이상 [  0,  0]
```

둘 다 [PARK_CLIP](PARK_CLIP_2026-08-29.md) 이 "실사용"으로 꼽은 해상도다.

### 고침 — `hidden` → `auto`

⚠ **`hidden` 을 지우면 안 된다.** 그러면 카드가 늘어나 옆 열 높이를 밀고
**구장까지 흔든다**(잘림이 막 닫힌 자리다). `auto` 는 넘칠 때만 스크롤바를
만들고 1536 이상에서는 지금과 똑같다 — 실측으로 확인했다.

1366×768 에서 다시 띄워 스크롤바가 생기고 구장이 그대로인 것을 봤다.
검사 4건 · 변이 1건.

### ⚠ `resize` 첫 호출은 한 번 더 불러야 한다

최대화 해제 직후 `setContentSize` 와 촬영이 겹쳐서 **첫 번째만 1584×861**로
찍혔다(요청은 1920×1080). 되읽기 로그는 요청대로 나왔는데 그림이 달랐다 —
창이 자리를 잡기 전에 찍힌 것이다.

```
resize 1920x1080
sleep 1500
resize 1920x1080      ← 두 번째는 풀 최대화가 없어 바로 먹는다
sleep 1500
ss ...
```

A 에게 알린다 — `resize` 안에서 잠깐 기다렸다가 되읽으면 이 함정이 없어진다.

### 스크린샷 5장 — **전부 1920×1080 으로 다시 찍었다**

경기 화면만 1920×1079 였던 것을 고쳤다.

대기(12회 × 1.2초 ≈ 14초)를 넘겼을 뿐이다.

`advance` 를 여러 번 이어 부르면 계속된다 — 한 번에 12주씩 끊어 부른다.
`scripts/` 는 A 소유라 드라이버의 대기 횟수는 안 건드렸다.

- 은퇴 직후 엔딩(`마치기` 버튼) — 실제 은퇴가 필요하다

## 9. 🔴 해상도 3차 — **선수 카드가 1280×720 에서 이름만 남는다**

7절에서 `overflow: hidden` → `auto` 로 고쳐 **닿을 수는 있게** 했다. 그런데
탈삼진을 카드에 세우려고 다시 재 보니, 닿는 것과 **보이는 것**이 달랐다.

### 실측 (2026-09-01 · 새 게임 · 1회 초)

```
해상도       카드 패널   머리글   목록에 남는 높이   내용
1280×720       44px     21px         0px          104px
1366×768       92px     21px        39px          104px
1536×864      190px     21px       137px          104px
```

1280×720 에서는 **한 줄도 안 보인다.** 스크린샷으로 확인했다 — 상대 타자
카드에 컨택·파워가 없고 이름만 있다. 투구를 고르라고 띄운 능력치다.

### 원인은 줄 높이가 아니다

줄 16px · 글자 12px · 여백 0 — 이미 최소다. **패널 자체가 44px 로 눌렸다.**

`.right-column` 은 `auto auto minmax(0, 1fr)` 이고, 앞 두 행이 해상도와
무관하게 고정이다.

```
열 높이        558 (1280×720)
상황 패널      203   (다이아몬드 104 + SBO 146)
가운데 행      285   (존 캔버스 228 · 구종 선택 [머리 31 + 목록 166 + 던지기 44])
간격            24
─────────────────
카드 행         46
```

### ⚠ 고치지 않았다 — 조작이 참고보다 우선이다

카드를 살리려면 가운데 행에서 ~100px 을 뺏어야 하는데, 거기 있는 것이
**존 캔버스 · 구종 선택 · 던지기 버튼** — 이 화면에서 실제로 누르는 것 전부다.
스트라이크 존을 720p 에서 줄이는 것은 CSS 손질이 아니라 게임 감각의 결정이라
**혼자 정하지 않는다.** 계측만 남긴다.

### 탈삼진은 머리글에 세웠다

목록에 넣으면 실사용 두 해상도에서 안 보인다. 머리글(21px)은 어디서나
남으므로 이름 옆에 `K 0` 표식으로 붙였다. 세 해상도에서 보이는 것과
뒤집기 버튼과 안 겹치는 것을 실측했다.
