예전 기준선은 **선수별 타율의 중앙값**을 썼다. 그런데 규정 타석 미달 선수가

실제로 그렇게 어긋났다:

```
타율 중앙 .256   ←→   9이닝당 피안타 10.5   ← 이 조합은 성립하지 않는다
리그 전체 타율 .272                          ← 역산과 맞는다
```

**리그 판정은 총 안타 / 총 타수로 한다.** `battingProbe` 에
`리그타율` · `리그출루` · `리그장타` · `홈런합` 을 넣었다.

⚠ 중앙값도 그대로 둔다 — **선수 분포**를 보는 데는 그게 맞다. 둘은 다른
질문에 답한다.

🔴 **둘이 반대로 어긋나 있다:**

```
폭투  20.3   목표의 **절반**        올려야 한다
보크  10.9   목표의 **두 배 남짓**   내려야 한다

```

⚠ **포일이 이미 목표 밖**이라는 게 손잡이를 정한다. `WILD_PITCH_DISTANCE`
를 내리면 폭투 후보가 늘지만 **그만큼 포일이 준다**(같은 문턱으로 갈린다) —
4.6 에서 더 떨어지면 두 지표가 다 목표 밖이 된다.
**`WILD_PITCH_BASE_PROB` 쪽이 맞아 보인다.** 다만 모수를 재고 확정한다.

⚠ **무대를 안 적으면 오독한다.** 고교는 9.8 이라 KBL 의 절반이다 —
실제로 이 숫자 하나 때문에 트랙 사이에서 오귀속이 났다.

### 산식과 손댈 자리

```
match_engine.rs:2400 근처
  dist = max(|x|, |y|)                     착지점의 존 이탈 거리 (존은 ±1)
  dist >= WILD_PITCH_DISTANCE (1.55)  →  폭투 후보, 확률 WILD_PITCH_BASE_PROB (0.16) × block
  아니면                                포일,     확률 PASSED_BALL_BASE_PROB (0.004) × block
  ⚠ **타자가 안 쳤고 주자가 있을 때만** 판정한다
```

🛑 **모수를 안 재고 값을 바꾸지 마라.** 문턱(`WILD_PITCH_DISTANCE`)을 내리면
후보가 늘지만 **포일이 같이 준다**(같은 문턱으로 갈린다). 확률만 올리면
포일은 그대로다. 어느 쪽인지는 **각 단계 모수를 재야** 정해진다:

```
주자 있고 안 휘두른 투구 수   →   그중 dist >= 1.55   →   실제 폭투
```

⚠ 지금 검사(`mod 폭투_포일`)는 **상수의 상대 관계만** 본다.
산출량을 안 봐서 팀당 20.3 이어도 초록이다.

⚠ 보크는 별개 축이다(`BALK_BASE_PROB` 0.0012 · 제구가 나쁠수록 잦다).
주석이 "실제 KBO 는 팀당 시즌 3~8개라 아주 드물게 둔다"고 적어 뒀는데
**실측이 10.9 다** — 적어 둔 의도와 나온 값이 다르다.

🔴 **값은 사용자에게 묻는다.** 여기는 근거만 둔다.
