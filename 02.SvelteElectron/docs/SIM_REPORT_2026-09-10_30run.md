## 🔴 사용자가 볼 것

### ① 고졸 직행 지명 6.7% (목표 30~40%) — 벗어났다

30판 중 **2판**. `careerEvents` 기준이라 **추정이 아니라 정확한 값**이다.
둘 다 `safe` 판이고, 성장형 20판은 **한 판도 고졸 직행이 없다.**

결정 ⑭ 로 시작 능력치를 내리기 전에는 「거의 보장」이었다. 내렸더니 **반대편으로
넘어갔다** — ⑭ 직후 4칸 실측 0/4 였고, 12시즌 30판에서도 2/30 이다.
표본이 커져도 방향이 같다.

### ② 군을 한 판도 안 밟았다 (0/30) — **결함이 아니라 계측이다**

원인을 짚었다. `runAutoAdvance` 가 `militaryEnlistAsk` 를 **「결과가 상태에
남지 않는 알림성 pending」** 목록에 두고 그냥 `resolvePendingAction` 한다:

```ts
case "sportsUnitApplication":
case "militaryEnlistAsk":
  seasonStore.resolvePendingAction(pa.type);   // ← 화면의 「입대 안 함」과 같다
```

화면 모달(`MilitaryEnlistAskModal`)에는 갈래가 둘이다 — **입대**(`enlistProtagonist("general")`)와
**연기**. 자동 진행이 고르는 것은 **늘 연기**다. 그래서 성향 셋 어느 것도
입대를 안 한다.

⚠ **트레이드·강등과 같은 분류 착오다.** 그 목록의 주석이 이미 두 번 틀렸다고
  적혀 있다(트레이드는 소속이 바뀐다 · 강등은 테스터가 겪었다). 입대는 무대가
  통째로 바뀌는데 「알림성」에 들어 있다.

⚠ 곁들여 — **`militaryDeferPenalty` 는 쌓이기만 하고 아무도 안 읽는다**
  (`advanceWeek` 이 26세 +3 · 27세+ +5 로 더하는데, 읽는 자리가 코드 어디에도
  없다). 연기에 대가가 없다.

**군 무대는 이 계측으로 못 잰다.** 잴 수 있게 하려면 성향이 입대를 고르게 해야
하고, 그건 계측 도구 변경이라 사용자 확인이 필요하다.
