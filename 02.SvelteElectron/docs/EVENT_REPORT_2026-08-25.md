## 4. 배분 — 산수가 안 맞았다

```
POOL_TEAM_LIFE_DAILY   109종 (고교 경쟁 42) · 추첨 26% → 뽑기 35회
가중치가 완벽히 균등해도  종당 0.84회
```

**눈금과 총량은 다른 문제다.**

- **눈금** — 세 풀 다 중앙값 18인데 **한 배치 17종만 5~9**였다. 자를 안 맞춘 것이라
  `[5,9] → [13,21]`로 옮겼다(순서는 지킴). 배율 7.0 → 2.7배
- **총량** — 주제별 세 갈래로 갈랐다. 추첨률은 **종수에 비례**시켜 종당 기회를 맞췄다

```
POOL_TRAIN_DAILY   훈련·폼   29종   13%
POOL_BODY_DAILY    몸·회복   21종    9%
POOL_TEAM_LIFE     팀·일상   59종   26%
                                  ────
                                  48%   (전 26%)
```

⚠ **주당 랜덤 소식이 0.66 → 1.14건으로 늘었다.** 소식함 200통 회전이 그만큼
빨라진다 — 그 축은 아직 안 쟀다(아래 §7).

## 7. 연계 — 후속 예약 수단이 없다

🔴 `nextEvents` 같은 필드가 없고, `triggeredEvents`는 **"언제"만 남기고 무엇을
골랐는지는 안 남긴다.** 그래서 연계의 유일한 수단은 **상태에 흔적을 남기는
보상**이다 — 태그·관계·돈.

작동하는 사슬 셋을 만들어 증명했다:

```
① 폼을 갈아엎을까    갈아엎는다 → 태그 「폼교정중」
                    다듬는다   → 경험치만. **②③은 영영 안 온다**
② 폼이 흔들린다      has_tag 폼교정중 · W14~
③ 자리를 잡았다      has_tag 폼교정중 · W30~ → 능력치 +2
```

⚠ **`removeTag`가 없다.** 그래서 ③을 `once_per_career`로 사슬을 닫는다 —
안 그러면 태그가 커리어 내내 붙어 ②가 계속 뜬다.
