### A-1. 리그 구성 전면 교체 [교체]

| 리그 | 현행 | **확정** |

현행 ~778경기 대비 **3.4배**. → Phase 4 성능 목표 합의의 기준 수치.

### A-2. 프로 2군 = 풀 시뮬 [교체 — R5 결정 뒤집음]

DESIGN.md §5·§7이 "팜 리그 경기 시뮬 제거 — 로스터 상태 + 콜업 테이블 룩업만"으로 확정하고
R5에서 실제로 `DEFAULT_LEAGUE_CONFIGS`에서 팜 스케줄 생성을 제거했으나, **이 결정을 되돌린다.**

- **근거**: "국내 전부 풀 시뮬" 원칙(0-5)과 일관. 2군 개인 성적이 쌓여야 콜업 판정이 능력치만이 아니라
  성적 기반이 되고, 주인공의 2군 강등·재승격 서사가 데이터로 뒷받침된다.
- **비용**: 495경기 = 국내 전체의 19%.
- **영향**: `leagueScheduler.ts`에 팜 리그 3개 스케줄 복원 + `LeaguePage` 순위표 팜 필터 해제 +
  `SeasonEndModal` 2군 우승 발표(기존 0승0패 가드로 자동 스킵되던 것) 활성화.

### A-3. 고교 권역 = 8권역으로 통일 [절충]

OnePitch 문서 자체가 불일치했다 — 주말리그 편성표는 12권역(서울A/B·경인A/B·호남A/B·영남A/B 분할),
구장·전국대회 시드는 8권역. **8권역으로 통일한다.**

- **근거**: 구장(`stadiums.csv` 8권역 거점) · 시드 공식 · 시드 데이터가 전부 이미 8권역 기준.
  OnePitch 구현도 실측으로 "12권역은 8권역 중 4개를 쪼갠 것뿐이라 소권역당 N장 공식을 8권역에 접어도
  정보 손실 없음"을 확인하고 8권역으로 접었다.
- **부작용**: 권역별 팀 수가 6(강원·제주)~20(경기·인천)으로 편차가 크다 → 라운드로빈 **바퀴 수로 보정**
  (팀 적은 권역은 여러 바퀴). 목표 경기 수는 권역 무관 균등.
- **미결**: A/B 소권역 세부 팀 편성은 채택 안 함 → 해당 항목 자체가 소멸.

### A-4. 투구수 상한 + 의무 휴식표 전면 도입 [흡수 — 신규 시스템]

현행에는 매치엔진 soft/hard cap과 `rosterEngine.ts`의 SP 의무 휴식 "경기 수"만 있다.
**리그별 투구수 상한과 투구수별 의무 휴식일 표를 새로 도입한다.**

| 리그 | 경기당 상한 |
|---|---|
| 고교 | **105구** |
| 대학 · 독립 · 프로 | **120구** |

| 당일 투구수 | 다음 등판까지 |
|---|---|
| ~30 | 다음날 가능 |
| 31~45 | 1일 |
| 46~60 | 2일 |
| 61~75 | 3일 |
| 76~95 | 4일 |
| 96~120 | 5일 |

- 고교는 76+ = 4일까지만(105구 상한이라 96~120 구간 없음).
- **목적**: 단판 넉아웃 전국대회에서 "에이스를 아껴 쓸까 밀어붙일까" 딜레마를 만든다.
  이게 고교 대회 5종을 이식하는 실질적 이유다.
- **영향**: 로테이션 배정(`rosterEngine.ts`)·스케줄러·매치엔진 강판 판정이 전부 이 표를 참조해야 함.

### A-5. 상무 = 독립리그 10번째 팀 [교체]

현행은 대학 리그 소속(7팀 + 상무). **독립리그 "상무 피닉스"(무연고)로 이전.**

- **근거**: 병역 복무 선수가 "재도전 무대"인 독립리그에서 시민구단(언더독)과 부딪히는 비대칭 구도.
- **파생 규칙**: 복무 ~1.5년 ≈ 독립 2시즌. 매 시즌 시작 시 복무 완료자는 원 소속 프로팀 복귀,
  그 자리를 신규 선발자로 충원 → **로스터 40~50% 교체**로 상무 전력이 시즌마다 요동.
- **예산**: 상무는 `budget = NULL`(국방부 예산이라 팀 예산 밴드 미적용 — 의도된 예외).

### A-6. 해외 리그 = 현행 12팀 유지 [유지]

ABL 12(동/서 6+6) · JBL 12(CL/PL). 국내 프로 10팀보다 크지만 **"더 큰 무대로 진출"로 읽는다.**

- **근거**: 팀·일정·브래킷 코드가 이미 있어 재작업 0. FA 자격 KBL 5년 / ABL 6년 / JBL 4년도 현행 유지.
- **시뮬**: 국내와 달리 **반경 적용** — 진출 전까지 순위 드리프트만, 진출 시 풀 시뮬.

### A-7. 리그 히스토리 = 고정 세계관 [흡수]

과거 5시즌 순위 · 우승 기록 · 창단 연도 · 라이벌 페어링을 **모든 플레이에서 동일한 고정값**으로 둔다.
선수만 `worldSeed`로 달라진다.

- **근거**: "무등고 = 호남 최고 명문", "한성고 = 최고 명문"처럼 기획서가 팀마다 부여한 서사 훅이
  시드마다 뒤집히면 무의미해진다. 라이벌 구도도 안정적으로 유지된다.
- **영향**: `worldSeed` 결정성 원칙의 **예외 영역**이 생긴다 — 팀 정체성은 정적 콘텐츠(master.db),
  선수는 런타임 생성(slot.db). DESIGN §8.3의 "정의/상태/파생" 3분류에서 **정의**에 속함.

### A-8. 전력★ = 문서에서 이관 [신규 데이터 작업]

기획서 표(고교 102 · 대학 50 · 프로 10)의 ★ 값이 **CSV로 옮겨진 적이 없다**(실측 확인).
OnePitch는 과거 순위에서 역산해 썼지만, **문서 값을 정본으로 CSV에 이관한다.**

- **★의 역할**: 예산 공식(`budget = 하한 + (상한−하한) × ★/5`) · 로스터 규모 · 매치 시드 기준.
- **현재 표시용 "현재 전력"은 별개** — 로스터에서 파생 계산(`03_팀_전력_공식`). ★은 고정 정체성.
- **미이관 구간**: 독립 9개 시민구단은 문서에 ★이 없어 OnePitch가 위상·자원에서 역산(★1~4)했다.
  그 역산값을 그대로 채택한다(`03.OnePitch/03_설계/12_구현확정_결정요약.md` §A-1).

## B. 커리어 · 진로 · 병역 · 시장 · 재정 (Phase 3-3) — 판정 완료

### B-1. 커리어 아크 = 6 Phase 골격 [흡수]

```
뉴게임(주인공 생성)
Phase 1 아마추어 — 고교 시작 17세
   └ 갈림길 A: 프로 지명 / 대학(최대 4년) / 독립 / 입대
Phase 2 프로 육성 — 2군                    ← B-3
Phase 3 1군 정착 & 역할 축                  ← B-4
Phase 4 주전·전성기
   └ 갈림길 B: FA / 트레이드 / 잔류·재계약
Phase 5 베테랑·노쇠
Phase 6 은퇴 → 인생 기록
```

- **목표 커리어 길이: 평균 15~20시즌** (상한 아님, 최대 ~26까지 가능). Phase 5 밸런스 하네스의 1차 통과 기준.
- **커리어 정점 = 국내 1군**이라는 OnePitch 전제는 채택하지 않는다 — 해외(ABL·JBL)를 유지하기로 했으므로
  정점은 여전히 해외 진출이다. Phase 4 갈림길 B에 **해외 진출이 선택지로 남는다.**

### B-2. 드래프트 = 11월 통합 드래프트 [교체]

현행 고교 3학년 W50→W51→W52 단발 → **연 1회 11월 통합 드래프트로 통합.**

| 경로 | 자격 |
|---|---|
| 고교 3학년 | **필수**(유일한 창구) |
| 대학 재학 중 | **1~4학년 매년 신청 가능** (4학년이 마지막 기회) |
| 독립 재적 중 | **매년 재지원 가능** |

- **주목도** = 리그 성적(경기별 S~D 등급 누적) + 대회 임팩트 + 마일스톤, **무대 수준 가중**(고교 < 대학, 독립 낮음).
- 주목도 → 라운드·픽 순위 → 계약금.
- **독립→프로 중도 지명**: 정기 드래프트 밖 경로. **7월말 트레이드 데드라인에 편승**(새 캘린더 슬롯 없음).
- 미지명 → 대학·독립·입대 재경로(현행 W52 폴백 UI 재사용 가능).

### B-3. 프로 진입 = 2군 시작 [교체]

지명 → 계약 → **2군 배치**. 특급 신인만 1군 직행.

- **근거**: A-2(2군 풀 시뮬 채택)로 2군이 실제 무대가 됐다. Phase 2→3 아크가 성립하고 콜업이 서사적 사건이 된다.
- **특급 신인 1군 직행 조건은 미확정** — 기획서가 "열린 세부"로 남긴 항목. Phase 4 구현 시 확정
  (OnePitch는 `is_elite_prospect`로 지명 확률보다 훨씬 엄격한 임계값을 D그룹 placeholder로 뒀다).

### B-4. 승강 = 상시 트리거 + 월간 정기 [절충 — 둘 다]

| 경로 | 트리거 |
|---|---|
| **상시** | 1군에 부상·부진 공백 발생 → 같은 역할 2군 상위자 콜업 후보 판정 |
| **정기** | 월 경계마다 최근 페이스 평가로 콜업·강등 확률 판정 |

- 복수 후보 경합 시 우선순위: **감독 신뢰도(관계도) → 최근 페이스 → 시즌 누적 성적**.
- OnePitch 구현은 상시 트리거를 통째로 포기하고 월간만 넣었다 — **여기서는 둘 다 넣는다.**
- ⚠ 판정 경로가 둘이라 **디버깅 시 어느 쪽이 발동했는지 로그로 구분**해야 한다(Phase 6 하네스 체크 대상).

### B-5. 역할 축 = 감독 배정 (신뢰형) [흡수]

역할(선발 / 불펜: 추격조→셋업 / 마무리 / 스윙맨)은 **감독이 배정**하고 플레이어는 성적·구위로 신뢰를 쌓아 이동.

- **감독 신뢰도 = 관계도 재사용** (−100~100, 7단계 라벨). 새 수치를 만들지 않는다.
  좋은 성적이 올리고, 감독 의견에 반하는 선택(투수 교체 강행 등)이 내린다.
- **NPC와 주인공의 비대칭**: NPC는 능력치+누적성적 서열만, 주인공은 거기에 **관계도라는 추가 렌즈**.
  S~D 등급이 주인공 전용인 것과 같은 원리.
- 구현 단계 축소 가능: 선발/중계/마무리 3분류까지가 1차, 추격조 세분화·스윙맨은 후속.

### B-6. 병역 = 3경로 + 국가대표 시스템 전체 도입 [흡수 — 대형 신규]

현행 상무/일반 2경로 → **면제 / 상무 / 현역 3경로.**

| 경로 | 조건 | 결과 |
|---|---|---|
| **면제**(예술체육요원) | 국가대표 발탁 → 지정 국제대회 성과 | 완전 면제(공백 0) + 명성 대폭↑ |
| **상무** | 상무 피닉스 선발(성적·평판) | ~1.5년, **독립리그에서 경기·성장 지속** |
| **현역/사회복무** | 위 둘 다 불가 | ~1.5~2년 공백 — 피지컬만 하락, 재기 과제 |

**국가대표 — 국제대회 3종** (OnePitch도 끝내 구현 못 한 시스템, 여기서 처음 구현):

| 대회 | 주기 | 면제 연결 |
|---|---|---|
| 아시아대회 | 4년 | **금메달 → 면제** |
| 세계게임즈 | 4년 (아시아대회와 2년 오프셋) | **메달권 → 면제** |
| 야구국가대항전 | 격년 | 면제 없음 — 명예·주목도 + 상비군 가점 |

- **캘린더 = 7월 중순**, **리그를 멈추지 않는다** — 발탁된 선수만 소속팀 로스터에서 임시 이탈(WBC 방식).
  대학은 7월이 여명기, 독립은 2차 Stage라 리그 정지가 캘린더 충돌을 일으키기 때문.
  프로는 마침 올스타 브레이크라 **"프로 선수가 국대 발탁에 가장 유리한" 자연스러운 이유**가 된다.
- **자격**: 독립·대학·프로. **고교 제외**(청소년 대표 없이 성인 국대 하나로 통일).
- **대표팀 = 합성 팀** — 상위 등급 선수 모음, 기존 팀 전력 공식으로 산출. 새 팀 데이터 불필요.
- **상대국은 익명** — "본선 상대"·"결승 상대"로만 표기(가상 세계 원칙상 실제 국명 인용 불가).
- **미이행 시**: 만 28세 상당까지 미선택 → "입영통지서" 강제 이벤트 → 현역 자동 편입.
  게임오버가 아니라 **가장 불리한 선택지로 수렴**하는 압박.

## C. 육성 코어 (Phase 3-4) — 판정 완료

### C-2. 훈련 시스템 [유지]

### D-2. 선택지 톤·힌트 자동 계산 [흡수]

저작자가 톤을 손으로 쓰지 않는다 — 선택지의 **효과 델타 부호로 런타임 자동 판정**
(positive / negative / mixed / neutral) + "사기 +10, 잔액 −500원" 형식 힌트 자동 조립.
