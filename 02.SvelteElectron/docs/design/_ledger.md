### A-1. 리그 구성 전면 교체 [교체]

| 리그 | 현행 | **확정** |

현행 ~778경기 대비 **3.4배**. → Phase 4 성능 목표 합의의 기준 수치.

### A-2. 프로 2군 = 풀 시뮬 [교체 — R5 결정 뒤집음]

DESIGN.md §5·§7이 "팜 리그 경기 시뮬 제거 — 로스터 상태 + 콜업 테이블 룩업만"으로 확정하고
R5에서 실제로 `DEFAULT_LEAGUE_CONFIGS`에서 팜 스케줄 생성을 제거했으나, **이 결정을 되돌린다.**

- **근거**: "국내 전부 풀 시뮬" 원칙(0-5)과 일관. 2군 개인 성적이 쌓여야 콜업 판정이 능력치만이 아니라
  성적 기반이 되고, 주인공의 2군 강등·재승격 서사가 데이터로 뒷받침된다.
- **비용**: 495경기 = 국내 전체의 19%.
- **영향**: `leagueScheduler.ts`에 팜 리그 3개 스케줄 복원 + `LeaguePage` 순위표 팜 필터 해제 +
  `SeasonEndModal` 2군 우승 발표(기존 0승0패 가드로 자동 스킵되던 것) 활성화.

### A-3. 고교 권역 = 8권역으로 통일 [절충]

OnePitch 문서 자체가 불일치했다 — 주말리그 편성표는 12권역(서울A/B·경인A/B·호남A/B·영남A/B 분할),
구장·전국대회 시드는 8권역. **8권역으로 통일한다.**

- **근거**: 구장(`stadiums.csv` 8권역 거점) · 시드 공식 · 시드 데이터가 전부 이미 8권역 기준.
  OnePitch 구현도 실측으로 "12권역은 8권역 중 4개를 쪼갠 것뿐이라 소권역당 N장 공식을 8권역에 접어도
  정보 손실 없음"을 확인하고 8권역으로 접었다.
- **부작용**: 권역별 팀 수가 6(강원·제주)~20(경기·인천)으로 편차가 크다 → 라운드로빈 **바퀴 수로 보정**
  (팀 적은 권역은 여러 바퀴). 목표 경기 수는 권역 무관 균등.
- **미결**: A/B 소권역 세부 팀 편성은 채택 안 함 → 해당 항목 자체가 소멸.

### A-4. 투구수 상한 + 의무 휴식표 전면 도입 [흡수 — 신규 시스템]

현행에는 매치엔진 soft/hard cap과 `rosterEngine.ts`의 SP 의무 휴식 "경기 수"만 있다.
**리그별 투구수 상한과 투구수별 의무 휴식일 표를 새로 도입한다.**

| 리그 | 경기당 상한 |
|---|---|
| 고교 | **105구** |
| 대학 · 독립 · 프로 | **120구** |

| 당일 투구수 | 다음 등판까지 |
|---|---|
| ~30 | 다음날 가능 |
| 31~45 | 1일 |
| 46~60 | 2일 |
| 61~75 | 3일 |
| 76~95 | 4일 |
| 96~120 | 5일 |

- 고교는 76+ = 4일까지만(105구 상한이라 96~120 구간 없음).
- **목적**: 단판 넉아웃 전국대회에서 "에이스를 아껴 쓸까 밀어붙일까" 딜레마를 만든다.
  이게 고교 대회 5종을 이식하는 실질적 이유다.
- **영향**: 로테이션 배정(`rosterEngine.ts`)·스케줄러·매치엔진 강판 판정이 전부 이 표를 참조해야 함.

### A-5. 상무 = 독립리그 10번째 팀 [교체]

현행은 대학 리그 소속(7팀 + 상무). **독립리그 "상무 피닉스"(무연고)로 이전.**

- **근거**: 병역 복무 선수가 "재도전 무대"인 독립리그에서 시민구단(언더독)과 부딪히는 비대칭 구도.
- **파생 규칙**: 복무 ~1.5년 ≈ 독립 2시즌. 매 시즌 시작 시 복무 완료자는 원 소속 프로팀 복귀,
  그 자리를 신규 선발자로 충원 → **로스터 40~50% 교체**로 상무 전력이 시즌마다 요동.
- **예산**: 상무는 `budget = NULL`(국방부 예산이라 팀 예산 밴드 미적용 — 의도된 예외).

### A-6. 해외 리그 = 현행 12팀 유지 [유지]

ABL 12(동/서 6+6) · JBL 12(CL/PL). 국내 프로 10팀보다 크지만 **"더 큰 무대로 진출"로 읽는다.**

- **근거**: 팀·일정·브래킷 코드가 이미 있어 재작업 0. FA 자격 KBL 5년 / ABL 6년 / JBL 4년도 현행 유지.
- **시뮬**: 국내와 달리 **반경 적용** — 진출 전까지 순위 드리프트만, 진출 시 풀 시뮬.

### A-7. 리그 히스토리 = 고정 세계관 [흡수]

과거 5시즌 순위 · 우승 기록 · 창단 연도 · 라이벌 페어링을 **모든 플레이에서 동일한 고정값**으로 둔다.
선수만 `worldSeed`로 달라진다.

- **근거**: "무등고 = 호남 최고 명문", "한성고 = 최고 명문"처럼 기획서가 팀마다 부여한 서사 훅이
  시드마다 뒤집히면 무의미해진다. 라이벌 구도도 안정적으로 유지된다.
- **영향**: `worldSeed` 결정성 원칙의 **예외 영역**이 생긴다 — 팀 정체성은 정적 콘텐츠(master.db),
  선수는 런타임 생성(slot.db). DESIGN §8.3의 "정의/상태/파생" 3분류에서 **정의**에 속함.

### A-8. 전력★ = 문서에서 이관 [신규 데이터 작업]

기획서 표(고교 102 · 대학 50 · 프로 10)의 ★ 값이 **CSV로 옮겨진 적이 없다**(실측 확인).
OnePitch는 과거 순위에서 역산해 썼지만, **문서 값을 정본으로 CSV에 이관한다.**

- **★의 역할**: 예산 공식(`budget = 하한 + (상한−하한) × ★/5`) · 로스터 규모 · 매치 시드 기준.
- **현재 표시용 "현재 전력"은 별개** — 로스터에서 파생 계산(`03_팀_전력_공식`). ★은 고정 정체성.
- **미이관 구간**: 독립 9개 시민구단은 문서에 ★이 없어 OnePitch가 위상·자원에서 역산(★1~4)했다.
  그 역산값을 그대로 채택한다(`03.OnePitch/03_설계/12_구현확정_결정요약.md` §A-1).

## B. 커리어 · 진로 · 병역 · 시장 · 재정 (Phase 3-3) — 판정 완료

### B-1. 커리어 아크 = 6 Phase 골격 [흡수]

```
뉴게임(주인공 생성)
Phase 1 아마추어 — 고교 시작 17세
   └ 갈림길 A: 프로 지명 / 대학(최대 4년) / 독립 / 입대
Phase 2 프로 육성 — 2군                    ← B-3
Phase 3 1군 정착 & 역할 축                  ← B-4
Phase 4 주전·전성기
   └ 갈림길 B: FA / 트레이드 / 잔류·재계약
Phase 5 베테랑·노쇠
Phase 6 은퇴 → 인생 기록
```

- **목표 커리어 길이: 평균 15~20시즌** (상한 아님, 최대 ~26까지 가능). Phase 5 밸런스 하네스의 1차 통과 기준.
- **커리어 정점 = 국내 1군**이라는 OnePitch 전제는 채택하지 않는다 — 해외(ABL·JBL)를 유지하기로 했으므로
  정점은 여전히 해외 진출이다. Phase 4 갈림길 B에 **해외 진출이 선택지로 남는다.**

### B-2. 드래프트 = 11월 통합 드래프트 [교체]

현행 고교 3학년 W50→W51→W52 단발 → **연 1회 11월 통합 드래프트로 통합.**

| 경로 | 자격 |
|---|---|
| 고교 3학년 | **필수**(유일한 창구) |
| 대학 재학 중 | **1~4학년 매년 신청 가능** (4학년이 마지막 기회) |
| 독립 재적 중 | **매년 재지원 가능** |

- **주목도** = 리그 성적(경기별 S~D 등급 누적) + 대회 임팩트 + 마일스톤, **무대 수준 가중**(고교 < 대학, 독립 낮음).
- 주목도 → 라운드·픽 순위 → 계약금.
- **독립→프로 중도 지명**: 정기 드래프트 밖 경로. **7월말 트레이드 데드라인에 편승**(새 캘린더 슬롯 없음).
- 미지명 → 대학·독립·입대 재경로(현행 W52 폴백 UI 재사용 가능).

### B-3. 프로 진입 = 2군 시작 [교체]

지명 → 계약 → **2군 배치**. 특급 신인만 1군 직행.

- **근거**: A-2(2군 풀 시뮬 채택)로 2군이 실제 무대가 됐다. Phase 2→3 아크가 성립하고 콜업이 서사적 사건이 된다.
- **특급 신인 1군 직행 조건은 미확정** — 기획서가 "열린 세부"로 남긴 항목. Phase 4 구현 시 확정
  (OnePitch는 `is_elite_prospect`로 지명 확률보다 훨씬 엄격한 임계값을 D그룹 placeholder로 뒀다).

### B-4. 승강 = 상시 트리거 + 월간 정기 [절충 — 둘 다]

| 경로 | 트리거 |
|---|---|
| **상시** | 1군에 부상·부진 공백 발생 → 같은 역할 2군 상위자 콜업 후보 판정 |
| **정기** | 월 경계마다 최근 페이스 평가로 콜업·강등 확률 판정 |

- 복수 후보 경합 시 우선순위: **감독 신뢰도(관계도) → 최근 페이스 → 시즌 누적 성적**.
- OnePitch 구현은 상시 트리거를 통째로 포기하고 월간만 넣었다 — **여기서는 둘 다 넣는다.**
- ⚠ 판정 경로가 둘이라 **디버깅 시 어느 쪽이 발동했는지 로그로 구분**해야 한다(Phase 6 하네스 체크 대상).

### B-5. 역할 축 = 감독 배정 (신뢰형) [흡수]

역할(선발 / 불펜: 추격조→셋업 / 마무리 / 스윙맨)은 **감독이 배정**하고 플레이어는 성적·구위로 신뢰를 쌓아 이동.

- **감독 신뢰도 = 관계도 재사용** (−100~100, 7단계 라벨). 새 수치를 만들지 않는다.
  좋은 성적이 올리고, 감독 의견에 반하는 선택(투수 교체 강행 등)이 내린다.
- **NPC와 주인공의 비대칭**: NPC는 능력치+누적성적 서열만, 주인공은 거기에 **관계도라는 추가 렌즈**.
  S~D 등급이 주인공 전용인 것과 같은 원리.
- 구현 단계 축소 가능: 선발/중계/마무리 3분류까지가 1차, 추격조 세분화·스윙맨은 후속.

### B-6. 병역 = 3경로 + 국가대표 시스템 전체 도입 [흡수 — 대형 신규]

현행 상무/일반 2경로 → **면제 / 상무 / 현역 3경로.**

| 경로 | 조건 | 결과 |
|---|---|---|
| **면제**(예술체육요원) | 국가대표 발탁 → 지정 국제대회 성과 | 완전 면제(공백 0) + 명성 대폭↑ |
| **상무** | 상무 피닉스 선발(성적·평판) | ~1.5년, **독립리그에서 경기·성장 지속** |
| **현역/사회복무** | 위 둘 다 불가 | ~1.5~2년 공백 — 피지컬만 하락, 재기 과제 |

**국가대표 — 국제대회 3종** (OnePitch도 끝내 구현 못 한 시스템, 여기서 처음 구현):

| 대회 | 주기 | 면제 연결 |
|---|---|---|
| 아시아대회 | 4년 | **금메달 → 면제** |
| 세계게임즈 | 4년 (아시아대회와 2년 오프셋) | **메달권 → 면제** |
| 야구국가대항전 | 격년 | 면제 없음 — 명예·주목도 + 상비군 가점 |

- **캘린더 = 7월 중순**, **리그를 멈추지 않는다** — 발탁된 선수만 소속팀 로스터에서 임시 이탈(WBC 방식).
  대학은 7월이 여명기, 독립은 2차 Stage라 리그 정지가 캘린더 충돌을 일으키기 때문.
  프로는 마침 올스타 브레이크라 **"프로 선수가 국대 발탁에 가장 유리한" 자연스러운 이유**가 된다.
- **자격**: 독립·대학·프로. **고교 제외**(청소년 대표 없이 성인 국대 하나로 통일).
- **대표팀 = 합성 팀** — 상위 등급 선수 모음, 기존 팀 전력 공식으로 산출. 새 팀 데이터 불필요.
- **상대국은 익명** — "본선 상대"·"결승 상대"로만 표기(가상 세계 원칙상 실제 국명 인용 불가).
- **미이행 시**: 만 28세 상당까지 미선택 → "입영통지서" 강제 이벤트 → 현역 자동 편입.
  게임오버가 아니라 **가장 불리한 선택지로 수렴**하는 압박.

## C. 육성 코어 (Phase 3-4) — 판정 완료

### C-2. 훈련 시스템 [유지]

### D-2. 선택지 톤·힌트 자동 계산 [흡수]

저작자가 톤을 손으로 쓰지 않는다 — 선택지의 **효과 델타 부호로 런타임 자동 판정**
(positive / negative / mixed / neutral) + "사기 +10, 잔액 −500원" 형식 힌트 자동 조립.

## 구현 중 추가 판정 (Phase 5)

기획 통합 시점에는 안 보였다가 **구현하면서 드러난 충돌**이다. 위 22건과 성격이 달라
따로 적는다 — 기획서끼리의 차이가 아니라 "기획서 수치가 v2 세계 규모와 안 맞는" 경우.

### P5-1. 주말리그 경기 수를 어떻게 균등하게 맞추나

- **기획서(02_고교.md §4-1)**: **12권역**(서울A/B·경인A/B·호남A/B·영남A/B 등 분할)에
  권역별 바퀴 수를 손으로 지정 — 16팀 3바퀴 21경기, 6팀 4바퀴 20경기 …
- **v2 세계**: 권역은 거점구장 공유로 **8권역**, 크기 6~20팀. 손으로 지정한 바퀴 표가 안 맞는다.
- **판정**: 바퀴 수를 입력으로 받지 않고 **목표 경기 수(20)를 입력으로 받아 바퀴를 역산**한다
  (`build_rounds_targeted`). 권역이 몇 팀이든 전 팀 정확히 20경기.
- **버린 안**: ① 12권역으로 쪼개기 — 거점구장이 8개뿐이라 권역의 물리적 근거가 사라진다.
  ② 기획서 바퀴 표를 8권역용으로 다시 손으로 쓰기 — 팀 수가 바뀔 때마다 또 손봐야 한다.

### P5-2. 전국대회 권역 배분을 어떻게 나누나

- **기획서(§4-2)**: "권역당 상위 2팀(=24)" — 12권역 × 2 기준.
- **v2 세계**: 8권역이라 × 2 = 16밖에 안 되고, 권역 크기가 6~20이라 **균등 배분이 왜곡을 만든다**.
  6팀 권역에서 4팀을 뽑으면 67%가 전국대회에 나가고 20팀 권역은 20%만 나간다.
- **판정**: **권역 크기 비례 배분(최대잔여법, 권역당 최소 1)**. 무궁화기 48팀 기준
  진출률 33~38%로 수렴한다. 참가 총수(32·32·48·102·24)는 기획서 그대로.
- **근거**: P5-1에서 "권역 크기 편차를 보정한다"고 정한 것과 같은 원칙이다. 크기가
  제각각인 권역을 균등 취급하면 어디선가 반드시 왜곡이 나온다.
- **버린 안**: 권역당 고정 3팀 + WC로 나머지 — 소권역 과대대표가 그대로 남는다.

### P5-3. 부전승 규칙을 따로 만들 것인가

- **기획서**: 48강 상위16 부전승 · 128대진 26 부전승 · 32대진 8 부전승 — 수치가 명시돼 있다.
- **판정**: **따로 만들지 않는다.** 표준 브래킷 시드 순서(1↔N, 2↔N-1 …)에서 빈 시드를
  부전승으로 두면 기획서 수치가 **정확히 그대로 나온다**(64−48=16, 128−102=26, 32−24=8).
  `test-tournament.cjs`가 이 일치를 검증한다.

### P5-4. 대회 성적을 리그 순위에 넣을 것인가

- **판정**: **넣지 않는다.** 개인 기록·피로도·로테이션은 리그 경기와 똑같이 쌓되
  순위표만 건너뛴다(`applyTournamentResult`).
- **근거**: 넣으면 전반기 대회 성적이 후반기 대회 시드에 섞여 들어간다.
  "주말리그 순위로 시드를 정한다"(§4-2)는 규칙 자체가 무의미해진다.

### P5-5. 대학 리그·대회 (Phase 5-5)

- **조 편성**: 기획서 A~E 5조는 **이미 데이터에 있었다** — 거점구장 5개에 정확히
  10팀씩. 고교 8권역과 같은 규칙(구장 공유)이라 5-3 스케줄러를 그대로 쓴다.
- **조별 요일**: 기획서가 조마다 다르게 정했다(A·B 화수목금 / C·D 목금 / E 4월 목금·5월 화수).
  요일을 `RegionInput.dayOffsets`로 올려 조별로 준다. E조의 시기 전환만은
  라운드 순환(`[3,4,1,2]`)으로 **근사**했다 — 라운드별 요일 전환은 구조가 커진다.
  **왜 살렸나**: 5-8 의무 휴식표가 일 단위라 요일이 등판 간격에 실제로 영향을 준다.
- **왕중왕전 참가**: 기획서 "조 1위 자동 5 + 조 2위 중 승률 상위 3". 5-4의 비례
  배분으로는 표현 불가 → **조당 고정 인원 모드**(`perGroupSlots`)와 **WC 후보
  순위 제한**(`wildcardMaxGroupRank`)을 넣었다. 대학 5조는 전부 10팀 균등이라
  비례 배분 자체가 의미가 없다. 고교는 기존 비례 배분 유지.
- **시드 정책**: 왕중왕전만 `autoSeedsFirst` — 조 1위 5팀이 상위 시드, WC 3팀이
  하위(기획서 명시). 고교는 "강한 권역 3위가 약한 권역 1위보다 셀 수 있다"는
  이유로 승률 통합 정렬을 유지한다. 같은 엔진에 두 정책이 공존한다.
- **조별예선**: 은하기(8조×3팀→조1위 8팀)·여명기(4조×5팀→조상위2 8팀)는
  넉아웃 브래킷으로 표현 불가 → `group_stage.rs` 신설. 예선이 끝나야 본선
  브래킷이 생긴다(`groupStages` → `tournaments`로 승격).
- **조 추첨 결정성**: 기획서는 "완전 랜덤 추첨(시드 없음)"이고 그게 '죽음의 조'
  드라마의 근거다. 다만 `rand::thread_rng()`를 쓰면 세이브를 다시 열 때마다 조가
  바뀐다 → **splitmix64 + `worldSeed × 대회id × 시즌`** 으로 결정적 셔플.
  플레이어에겐 여전히 예측 불가고, 세이브/로드 스컴도 막힌다.
  이를 위해 `SaveSeason.worldSeed`를 신설했다 — 주중에 뽑기가 필요한데 그때마다
  slot.db meta를 비동기로 읽을 수는 없다.
- **버린 안**: 예선 없이 24팀/20팀을 바로 넉아웃 — 코드는 0줄이지만 은하기(소수정예)와
  여명기(다전제)가 "참가 인원만 다른 같은 대회"가 된다.

### P5-6. 대회 시드용 순위 스냅샷 (Phase 5-5a)

- **문제**: 대회마다 보는 시점이 다른데(개나리기 전년 · 장미기/무궁화기 전반기 ·
  패왕기 후반기) 순위표가 하나뿐이었다. 누적 순위를 전부에 쓰면 패왕기가
  "그해 최강전"이 아니라 "3월부터 잘한 팀 대회"가 된다.
- **판정**: 전·후반기 경계를 **무궁화기 기준**으로 끊는다. 기획서 캘린더가
  "4~6월 전반기 / 7~8월 무궁화기(여름방학) / 9~11월 후반기"라고 적었다.
  후반기 순위는 스냅샷과의 **차분**이다(누적이 아니라 후반기 성적만).
- **첫 시즌**: 전년 순위가 없으니 **전력★ + history.seasonRanks**로 합성한다.
  DESIGN §7.1이 이걸 "모든 플레이에서 동일한 고정값"으로 정했으므로 근거가 된다.
  덕분에 "한성고 = 최고 명문"이 1학년 봄 개나리기부터 먹힌다.
- **버린 안**: 스냅샷 없이 대회 직전 누적 순위 — 장미기와 무궁화기가 같은 기준을
  쓰게 되고 패왕기 상위권이 시즌 초에 고정된다.

### P5-7. 시즌 결산 대회의 중복 (Phase 5-5a)

- **문제**: 고교·대학 모두 v1의 `top4 준결승/결승` 포스트시즌이 붙어 있는데,
  v2에서 시즌 결산이 **패왕기(고교 11월)** · **왕중왕전(대학 5월)** 로 옮겨갔다.
  그대로 두면 결승이 두 번 열린다.
- **판정**: 양쪽 다 `build_hs_bracket` / `build_univ_bracket`을 **폐기**한다
  (Rust 함수 · TS 래퍼 · preload · projectb.d.ts 전부).
  102팀 8권역에서 "전국 top4"를 매기는 것 자체가 맞붙은 적 없는 팀끼리
  승률만 비교하는 것이라 근거가 약하다. 패왕기는 후반기 권역 상위라는 명확한 규칙이 있다.
- 프로·독립·해외는 그대로 — 그쪽은 단일 리그라 top-N 포스트시즌이 정상이다.

### P5-8. 대회 시뮬 범위 (Phase 5-5a)

- **문제**: 5-4의 대회 진행이 "주인공이 고교일 때만" 돌았다. DESIGN §2는
  국내 전 리그 상시 풀 시뮬인데, 주인공이 대학에 가면 고교 전국대회가 멈춘다.
- **판정**: 리그 게이트를 없앤다. 주인공 소속과 무관하게 고교 5종·대학 3종이 매년 돈다.
  추가 경기 약 282(고교 233 + 대학 49) — 정규리그 2,635 대비 11%.
- 덕분에 "모교가 국화기 우승" 같은 뉴스가 프로 진출 후에도 성립한다.

### P5-9. 독립 생존리그 (Phase 5-6)

- **형식**: 리그도 대회도 아닌 제3의 구조다. 매 단계 하위권이 통째로 탈락한다
  (10→8→4). 각 단계는 **이전 대진을 이어받지 않고 생존팀끼리 새 라운드로빈**이라
  (기획서 §3) **단계마다 순위표도 리셋**한다. 누적을 쓰면 1차에서 벌어놓은 승수로
  3차 순위가 정해져 "매 단계 새 승부"가 무의미해진다.
- **일정 생성**: 5-3의 `build_rounds_targeted`를 그대로 재사용한다. 단계 = 팀 목록 +
  목표 경기 수라 새 알고리즘이 필요 없었다 (1차 18 · 2차 14 · 3차 3).
- **타이브레이크**: 기획서는 "승률 → **승자승** → 실점 최소 → 추첨"이지만
  **승자승은 구현하지 않고 다득점으로 대체**했다. 순위표(`Standing`)에 상대별 전적이
  없어 172팀 규모에서 필드를 늘리면 저장량·마이그레이션·스냅샷이 전부 따라온다.
  고교·대학 대회 시드가 이미 다득점 기준으로 돌고 있어 **리그 간 기준이 일치**한다.
  → 동률이 탈락을 가르는 상황에서 기획서와 다른 팀이 떨어질 수 있다. 감수한 차이.
- **4차 사다리**: 구 `build_ind_bracket`은 "1위 vs 2위 단판" 하나뿐이라 4팀 사다리를
  표현하지 못했다. `build_ind_ladder`로 교체 — 준PO(3vs4 단판) → PO(2위 vs 준PO승자
  단판) → 챔피언결정전(1위 vs PO승자, **3전2승**). `PostseasonSeries`가 `bestOf`와
  `nextSeriesId`를 이미 지원해 구조 변경 없이 들어갔다.
- **경기 수 정정**: DESIGN이 독립을 175로 적었으나 기획서 §3 표대로면 정규 **152**
  (90+56+6)이고 포스트시즌 최대 5를 더해 157이다. DESIGN의 총계도 대회분(318)이
  빠져 있어 2,635 → 약 2,930으로 고쳤다.
- **상무 로스터 40~50% 교체는 Phase 7로 이월** — 복무 완료자 복귀가 "원 소속 프로팀
  복귀"라 병역 트랙 전체와 묶여 있고, 신규 선발은 Phase 6 인물 재생성 뒤가 자연스럽다.
