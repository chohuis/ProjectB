> **수치는 여기 복제하지 않는다** — 정본은
> `resource/data/master/players/generation_rules.json`의 `financeRules`와
> `players/staff_rules.json`의 `[effects]`다. 문서에 옮겨 적으면 stale해진다.

> 실측 숫자가 필요하면 `npm run measure:finance`를 다시 돌린다.

## 0. 이 Phase가 무엇을 고쳤나

들어가기 전에 실측했더니 **DESIGN이 적어둔 것과 코드 상태가 달랐다.**

| DESIGN 기록 | 실제 |
|---|---|
| "스태프 15종 중 2종만 계산에 쓰인다" | **1종** (`coach.teaching`)만 |
| "개인 재정 — `finance` 페이지 이미 존재" | 페이지 **전체가 가짜**. `money`와 무관한 숫자 |

원인은 Phase 7에서 11번 반복된 것과 같다 — **정본이 둘 이상**이었다.

```
staff_rules.json   tacticalIQ / bullpenRead / offenseMind / motivator / clutchDecision
구 JSON            tactics / decision / ...
화면·계산          handlePressure / strategy / motivation / development / injuryMgmt
```

`staffGen`은 첫째를 쓰고 소비처는 셋째를 읽었다. `JSON.stringify`가 undefined 키를
지우므로 **에러가 한 번도 안 났다** — 매치엔진은 매 경기 기본값으로 돌았다.

같이 잡힌 것 둘이 더 컸다:

- **시설 `tier` 유령** — `TeamRef.tier`는 refs의 국내 182팀에 없는 필드다(값이
  있는 건 범위 밖 해외 56팀뿐). `?? "독립"` 폴백에 걸려 **국내 NPC 5,600명이 전부
  `facility_factor("독립") = 0.78`로 성장**하고 있었다. 고교는 1.08이어야 한다.
- **치료비 단위** — 표만 원 단위(500,000)로 만원 단위 `money`에서 뺐다.
  초기 자산 1,200만원이니 **보존 치료 한 주면 자산이 0**이 됐다.

| | `staffTrust` | 코치 5종의 실효 배수 |

**매치엔진 3종에는 계수가 없다.** Rust가 원값을 직접 쓰므로 여기서 배수를 또
곱하면 같은 능력치가 두 번 들어간다. `test:staff`가 이걸 검사한다.

강도는 **"중간"** 확정 — 능력치 30팀과 70팀의 차이가 성장 15% · 부상 20% ·
FA오퍼 12%다. 명문팀 이적이 '보너스'지 '필수'가 아니어야 한다. 약팀 지명이
페널티가 되면 드래프트 결과가 곧 커리어 결말이 된다.

### 부호를 신경 쓴 곳 둘

- **관계도는 양수 변화에만 곱한다.** 소통 좋은 코치진이라고 미움까지 빨리
  쌓이면 방향이 뒤집힌다
- **오퍼 연봉은 시장가에만 곱한다.** 현재 연봉은 이미 계약된 값이라 구단주가
  못 바꾼다. 실측 인상폭 2.35%로 계수(6%)보다 작게 나오는 게 의도한 동작이다

## 3. 부상 전조

피로 임계를 넘은 **첫 주는 경고만** 내고 부상 판정을 건너뛴다. 그대로 두 주째
넘기면 그때 판정한다. 아무 예고 없이 시즌이 끝나면 "관리 실패"가 아니라
"재수 없음"이 된다.

**유예 주에는 피로 몫만 뺀다.** 훈련 무리는 다른 축이라 그대로 둔다 —
"쉬라고 경고했는데 고강도 훈련을 밀어붙였다"가 면죄부가 되면 안 된다.

```
쉰 유예 주            부상률 0.00%
고강도+저컨디션 유예   부상률 20.7%
두 주째 (피로 92)     부상률 35.7%
```

유예는 한 번뿐이다. 임계 **아래로 내려가야** 누적이 리셋돼 유예가 되살아난다.

경고에 **다음 주 실제 확률을 숫자로 담는다.** 화면이 "위험합니다" 대신
"이대로면 35% 확률로 부상"이라고 말한다. 예방·나이·재발까지 반영한 값이라
실측과 어긋나면 거짓말이 되므로 회귀가 네 구간을 대조한다(오차 0.6%p).

**NPC는 경고가 없다** (DESIGN §7.3). 수천 명에게 경고를 내면 로그가 그것만
남고, NPC는 어차피 손쓸 주체가 없다.

## 4. 개인 재정

### 4-1. 누진세 — 한국 소득세 근사 4구간 + 최고구간

**구간을 넘어도 전액에 높은 세율이 붙지 않는다.** 단일세율로 만들면 연봉이
1만원 오를 때 실수령이 줄어드는 구간이 생기고, 그건 규칙이 아니라 버그로 읽힌다.

계약금·스폰서는 **기타소득 분리과세**다. 연봉과 합산하지 않는다 —
합산하면 5억 계약금을 받은 1순위 신인이 그해 최고세율을 맞고 파산한다.

학생·군 무대는 비과세다. 용돈에 세금을 매기면 숫자만 늘고 재미가 없다.

### 4-2. 스폰서 · CF — 명성 4카테고리

합계가 연봉의 **10~40%** (사용자 확정). 명성이 실제로 돈이 되지만 야구를
대체하지는 않는다.

문턱 위에서도 **선형 보간**한다. 계단이면 명성 1 차이로 돈이 두 배가 된다.

⚠ **명성 80부터 상한에 걸려 평평해진다** (실측). 의도한 상한이지만, 명성을 더
올릴 재정적 이유가 없어진다는 뜻이기도 하다. 명성의 다른 소비처(7-6 뉴스·
국가대표 발탁)가 그 위를 받아야 한다.

학생·독립에는 스폰서가 붙지 않는다 — 아마추어 규정 위반이다.

### 4-3. 개인 트레이닝 구독 — 팀 자원에 반비례

3분야 × 2단계. **시설 좋은 구단에선 한계효용이 낮다.** 열악한 팀에선 사비가
실제로 갈린다 — 약팀 지명이 순수한 페널티로만 남지 않게 하는 장치이기도 하다.

이게 성립하려면 스태프 15종 배선이 선행돼야 했다. 그래서 F-1이 F-3보다 앞이다.

> **실측으로 두 번 잡았다.**
> 1. 처음 0.04/0.09는 3분야 상시가 훈련 **+27%**가 됐다. 스태프 15종 전체 폭이
>    15%인데 구독 하나가 그걸 압도하면 "돈으로 성장을 산다"가 지배 루프가 되고
>    야구를 대체하지 않는다는 전제가 깨진다
> 2. 다음 0.02/0.05 + 상한 0.12는 반대 문제가 났다 — 3개 켠 순간 모든 팀이
>    상한에 걸려 **팀 자원 반비례가 통째로 사라졌다.** 상한이 기능을 지우면 안 된다

지금은 독립 13.8% ~ 명문 1군 8.2%로 상한(14%) 아래에 전부 들어온다.

하한 0.60을 둔 이유: 반비례가 너무 세면 좋은 팀에 간 순간 구독이 무의미해지고
토글 자체가 죽은 UI가 된다.

### 4-4. 투자 — 시즌말 1회 3택

**원금 손실을 허용한다** (사용자 확정). 은퇴 자산에 플레이어 판단이 실제로
반영된다. 세이브 로드로 되돌리는 문제는 시즌말 1회뿐이라 크지 않다.

전액 소실은 없다 — 그건 리셋 유도라 재미가 아니라 벌이다.

**시즌 종료 화면이 유일한 투자 시점이다.** 상시 화면에 두면 매주 눌러보는
도박이 되고, "가계부 없이 상시 잔액만"(DESIGN §7.3)과도 어긋난다.

### 4-5. 사치품

동료에게 쓰면 관계도가 오르고, 자기 소비는 **성격이 명성의 부호를 가른다.**
성실한 선수의 씀씀이는 구설이 되고 과시형에겐 화제가 된다. 같은 지출이 사람에
따라 다르게 읽히는 게 이 시스템의 요점이다.

계수만 여기 두고 **문안은 7-6 문장 뱅크가 갖는다.**

### 4-6. 관리 UI 원칙

가계부·예산배분 화면이 **없다** (DESIGN §7.3). 상시 잔액만 보이고 지출은
이벤트 선택 또는 구독 토글로만 한다. 그래서 FinancePage에 "예산 짜기"가 없다.

구독 토글은 누를 때마다 단계가 오르고 마지막 단계에서 누르면 해지된다.

## 5. 밸런스 하한 (회귀로 고정)

| 상황 | 기대 |
|---|---|
| 최저연봉 + 1단계 구독 1개 | **흑자** — 신인이 구독을 아예 못 쓰면 안 된다 |
| 최저연봉 + 상시 구독 3개 | **적자** — 감당되면 구독이 공짜 버프가 된다 |
| 연봉 5억 + 상시 3개 | 흑자 — 성장의 보상이 있어야 한다 |

실측(20시즌): 저연차 방출형이 상시 3개를 켜면 **자산 0으로 끝난다.**
선택에 무게가 있다는 뜻이고, 의도한 결과다.

> ⚠ **"구독 안 함"이 최종 자산 1위인 건 당연하다** — 구독은 돈으로 성장을 사는
> 것이므로 자산만 비교하면 언제나 손해로 보인다. 이 표를 "구독은 손해"로 읽으면
> 안 된다.

## 6. FA 시장 오프시즌 배선 (7-4 이월)

7-4가 엔진(`resolve_market`)만 만들고 **호출부가 없었다.** FA 신청자는
`LEAGUE_FREE_AGENT`로만 바뀌고 Rust `run_offseason` step 8이 리그별로 **무작위
재배치**했다 — 등급도 보상선수도 팀 예산도 아무것도 안 걸렸다. 7-4의 결과물이
데이터상 존재하지 않았던 셈이다.

이제 W43 오프시즌이 정산한다. 좋은 선수부터 팀을 고르고 자리가 하나씩 줄어들며,
원소속도 경쟁에 낀다. 이적이면 보호선수 밖 최고 OVR + 보상금, 잔류면 보상 없음.

**시장이 죽어도 오프시즌은 안 멈춘다.** 미계약자는 기존 경로로 흘러가 Rust
`Placer`가 미지명 졸업생·방출자와 **같은 로직**으로 진로를 정한다(7-1).

## 7. 구단주 관계의 재계약 소비처 (7-4 이월)

7-4는 구단주 관계를 **방출 우선순위**에만 썼다. 나를 싫어하는 구단주가 자르기만
하고 재계약에는 무관하면 그 축이 절반만 사는 것이다.

협상 화면이 **두 입력을 따로 보여준다** — 다른 축이기 때문이다:

```
구단주 관계  나를 어떻게 보는가   (내가 쌓은 것)     ±9%
구단주 예산  지갑을 여는 사람인가 (팀이 원래 가진 것) ±12%
```

관계가 좋아도 궁핍한 구단은 못 준다.

⚠ 오퍼와 함께 **수락 임계값도 같은 배수를 탄다.** 오퍼만 올리면 "더 주는데 더
짜게 구는" 협상이 된다.

## 8. 이 문서를 고칠 때

수치를 바꾸면 **규칙 파일만** 고친다. 여기 수치를 옮겨 적지 않는다.
구조를 바꾸면 회귀가 먼저 깨져야 한다 — 안 깨지면 그 테스트가 실데이터를
안 읽고 있다는 뜻이다.

| 검증 | 무엇을 지키나 |
|---|---|
| `npm run test:staff` | 규칙파일↔코드 이름 대조 · 15종 소비처 존재 · 계수가 Rust 결과를 실제로 바꾸는지 |
| `npm run test:injury` | 유예 1주 · 훈련 무리는 유예 제외 · 경고 확률이 실측과 일치 · NPC 경고 없음 |
| `npm run test:finance` | **단위 대조** · 누진세 역전 없음 · 분리과세 · 반비례 · 밸런스 하한 |
| `npm run test:fa` | FA 시장 배선 · 보호선수 · 구단주 관계 양방향 |
| `npm run measure:finance` | 20시즌 자산 곡선 (테스트 아님 — 숫자 확인용) |

능력치 픽스처는 **생성기가 만든 실데이터**를 쓴다. 손으로 적었더니 `clutch`가
빠져 역직렬화가 죽었다.
