# 구장 픽셀아트 27장 — 제작 요구서

> **이 문서 하나만 들고 가면 된다.** 첨부 4개와 함께 그림 도구/작업자에게 전달한다.
> 결과물은 zip 한 개로 받아 `resource/park/`에 푼다.

---

## 0. ⚠ 웹 Claude·Claude Design으로 받을 수 있는가 — 아니다

먼저 물어보신 것부터 답한다.

| 대상 | 결과 |
|---|---|
| 웹 Claude (claude.ai) | **불가.** Claude는 어떤 표면에서도 래스터 이미지를 생성하지 못한다 |
| Claude Design | **불가.** 디자인 시스템(HTML/CSS 컴포넌트 라이브러리) 도구다. 픽셀아트 PNG를 만드는 곳이 아니다 |
| Claude Code (지금 이 세션) | **불가.** 같은 이유 |

Claude에서 받을 수 있는 건 **코드**다 — SVG, 캔버스 드로잉, 이미지를 만드는 프로그램.
기존 3장 수준(개별 픽셀로 찍은 관중 수천 명, 잔디 깎은 방사형 줄무늬, 광고보드 글자)은
코드로 흉내 낼 수 있는 그림이 아니다.

**따라서 이 요구서는 Claude가 아니라 다음 중 하나에 준다:**

- **이미지 생성 모델** (img2img 지원 필수 — 첨부 A를 기준 이미지로 넣는다)
- **도트 작업자** (Aseprite 등)

> ⚠ 이미지 생성 모델을 쓸 경우 **§3의 등록 기준을 못 맞출 가능성이 높다.**
> 그때는 §7의 축소안(배경 띠만 요청)으로 내려간다.

## 3. ★ 가장 중요한 제약 — 등록 기준

게임 코드는 이 그림 위에 선수·주자를 **고정 좌표**로 얹는다.
좌표는 27장이 전부 같으므로, **모든 그림에서 경기장 기하가 픽셀 단위로 일치해야 한다.**

### 3-1. 맞춰야 할 14개 지점

첨부 B(`registration_overlay.png`)에 십자선으로 표시돼 있다.
**당신의 그림에서 이 14개 지점이 같은 자리에 있어야 한다.**

|---|---|---|---|
| 홈플레이트 | 649, 1034 | 투수 | 649, 717 |
| 1루 | 934, 759 | 포수 | 649, 1047 |
| 2루 | 649, 594 | 1루수 | 927, 770 |
| 3루 | 366, 759 | 2루수 | 784, 665 |
| | | 유격수 | 505, 665 |
| | | 3루수 | 355, 770 |
| | | 좌익수 | 316, 678 |

| | | 우익수 | 982, 678 |

### 3-2. ⚠ 이 좌표의 뜻 — 오해하기 쉬운 지점

**"베이스 그림의 중심"이 아니라 "선수의 발이 놓이는 자리"다.**
게임은 여기에 48×52 스프라이트를 `(x−24, y−44)` 위치로 그린다 — 즉 좌표는
선수의 **발밑**이다. 그래서 베이스 지점(빨강)이 실제 베이스 그림보다 조금 위에 찍혀 있다.

> **판정 방법**: 첨부 B를 당신의 그림 위에 겹쳐 십자선이 같은 지형지물을 가리키면 통과.
> 눈으로 재지 말고 실제로 겹쳐서 볼 것.

### 3-3. 허용 오차

| 지점 | 오차 |
|---|---|
| 홈·1루·2루·3루·투수 | **±6 px** |
| 수비 8자리 | ±12 px |

우리 쪽에 자동 검사기가 있어 27장 전수로 잰다. 넘으면 반려된다.

### 3-4. 바꿔도 되는 것 / 안 되는 것

| | |
|---|---|
| **절대 고정** | 내야 다이아몬드 위치·크기·각도 · 마운드 위치 · 파울라인 각도 · 시점 |
| **바꿔도 됨** | 하늘·배경(산·도시·건물) · 관중석 규모와 색 · 펜스 높이와 광고 · 조명탑 · 더그아웃 · 외야 잔디 무늬 · 흙 색 · 시간대와 날씨 느낌 |

**외야 펜스의 거리는 그림으로 당기지 말 것.** 펜스를 실제로 앞뒤로 옮기면
외야 잔디 모양이 바뀌어 기하가 깨진다. **거리감은 §4의 표기 숫자와 펜스 높이로만** 낸다.

## 6. 납품

```
stadiums.zip
└── park/
    ├── STADIUM_SEOUL_GUARDIANS.png
    ├── STADIUM_SEOUL_ROYALS.png
    │   … 27개 …
    └── STADIUM_HALLA.png
```

- 폴더 한 겹(`park/`) 안에 27장 평면 배치. 하위 폴더 없음
- 파일명은 §4 그대로. 확장자 소문자 `.png`
- 27장 미만이면 **있는 것만** 보내도 된다 — 나머지는 티어 기본 그림으로 대체된다

**받는 위치**: 압축을 풀어 `resource/park/` 아래 그대로 덮어쓴다.

## 7. 축소안 — 27장이 어려우면

기하 제약(§3)을 못 맞추겠다면 **배경 띠만** 요청한다. 훨씬 쉽고 실패해도 안전하다.

| 항목 | 값 |
|---|---|
| 캔버스 | **1306 × 200 px** (화면 상단 띠) |
| 내용 | 하늘·구름·산·건물만. 경기장 요소 **없음** |
| 장수 | **6장** — 바다 / 오름 / 호수 / 항만 / 농촌 / 돔천장 |
| 파일명 | `_src/L2/sea.png` `oreum.png` `lake.png` `port.png` `farm.png` `dome.png` |

이 6장이면 우리 쪽에서 기존 3장의 경기장 부분과 합성해 27장을 만든다.
**기하가 안 걸리므로 좌표 검사가 필요 없다.**
