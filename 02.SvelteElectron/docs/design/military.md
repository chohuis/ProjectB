# 병역 · 국가대표 설계 (Phase 7-3, 2026-07-31 확정)

> **수치는 여기 복제하지 않는다** — 정본은
> `resource/data/master/players/generation_rules.json`의
> `militaryRules`(상무) · `internationalRules`(국제대회)다.
>
> 회귀 `npm run test:military`

## 0. 병역을 벗어나는 길은 둘뿐이다

```
상무(체육부대)   2년 복무 → 군필
국제대회 입상    면제가 걸린 대회에서 기준 순위 이내 → 면제
```

그 외에는 일반병으로 간다. **면제를 주는 경로는 국제대회 하나뿐**이라,
대회를 매년 열면 병역이 무의미해진다 — 그래서 4년 주기다.

---

## 1. 상무

**정원이 유일한 제어다.** 상무 선수는 `career_status: "military"`인데
오프시즌 로스터 캡은 `active`만 세므로 **캡이 아예 안 걸린다.**

```
연간 입대 = rosterSize / (serviceMonths / 12)
```

> 예전엔 `game.ts`에 `maxTotal: 20`이 박혀 있었다. 정원은 26인데 매년 20명 ×
> 2년이면 정상상태 40명 — 정원의 1.5배다. 아무도 막지 않았다.

`maxPerTeam`은 한 구단이 상무를 독식하지 않게 한다.

⚠ **후보 풀에 2군이 들어가야 한다.** 실제로 상무는 2군 유망주가 많이 가고,
Phase 7-1에서 신인 대부분이 2군에서 시작하게 되면서 더 커졌다 —
FARM이 빠져 있던 동안 갓 지명된 선수는 후보조차 못 됐다.

로스터 생성·계급 규칙은 [roster.md §7](roster.md).

---

## 2. 국제대회 — 경기는 시뮬하지 않는다

사용자 확정: **결과만 합성한다.** 대표팀 전력으로 순위를 확률 산출한다.
외국 대표팀 로스터를 만들 필요가 없고, 사용자가 보는 건 발탁·결과·면제다.

```
개막 주(week)          발탁 → 소속팀에서 이탈
개막 + durationWeeks   순위 → 메달 → 면제 → 복귀
```

### 일정 — 한 해에 하나만

대회마다 `cycleYears`가 같고 `yearMod`가 달라 **겹치지 않는다**(사용자 요청).
`yearMod`가 비는 해는 대회가 없다.

⚠ 대회를 추가할 때 `yearMod`가 겹치면 `test:military`가 먼저 깨진다
(40년치를 훑는다). Rust 유닛도 같은 걸 본다.

### 순위 산출

세계 평균(OVR 75) 대비 대표팀 전력의 위치로 기대 순위를 잡고 난수로 흔든다.
**경기를 안 돌리므로 이 한 줄이 대회 전부다** — 강팀도 지고 약팀도 이변을 낸다.

실측: 20개국 대회에서 강팀(90) 평균 3.9위 · 약팀(60) 평균 16.9위.

---

## 3. 발탁

- 정렬은 `OVR + form × 8` — **승강 판정과 같은 축**이다.
  따로 만들면 "대표는 뽑혔는데 2군으로 내려간" 모순이 생긴다
- 투수 절반. 한쪽으로 쏠리면 대표팀이 성립하지 않는다
- `maxPerTeam` — 한 구단 전력이 통째로 빠지면 그 팀 리그 일정이 기운다
- `ageMax` — 병역이 걸린 대회라 젊은 선수가 간다

---

## 4. 임시 이탈 — 부상과 같은 취급

발탁되면 대회 기간 소속팀에서 빠진다(사용자 확정). 차출자는
`seasonStore.nationalDuty`에 남고, **승강의 상시 콜업이 부상자와 같은 목록으로
받아** 그 자리를 메운다.

⚠ 따로 처리하면 대회 기간에 1군이 빈 채로 돈다. 7-2의 경로를 그대로 쓴다.

---

## 5. 면제

`exemptionRank > 0`인 대회에서 그 순위 **이내**면 대표팀 전원 면제.
미필만 바뀐다 — 이미 군필·현역인 사람은 안 건드린다. 주인공도 같은 경로다.

⚠ `exemptionRank`가 `fieldSize`보다 크면 사실상 전원 면제가 된다.
Rust 유닛과 `test:military`가 둘 다 막는다.

## 6. 확정 사항 (2026-07-31)

| | |
|---|---|
| 상무 규모 | 정원 26명 유지 · 연 13명 입대 |
| 국제대회 | 결과만 합성 (경기 시뮬 없음) |
| 대회 일정 | 4년 주기 · **한 해에 하나만** |
| 임시 이탈 | 발탁되면 그 기간 소속팀 결장 |

---

## 7. 아직 없는 것

- **상무 로스터 40~50% 교체**(BACKLOG 이월)는 정원 제어로 자연히 돈다 —
  매년 13명이 들어오고 13명이 나가니 2년이면 전원 교체다. 별도 로직이 없다
- 대회 성적이 **개인 기록에 안 남는다.** 결과만 합성하므로 대표팀 성적은
  순위·메달뿐이다. 개인 기록을 남기려면 경기 시뮬이 필요하다
- 발탁 통보·대회 진행 연출이 로그뿐이다 — 메시지·이벤트는 Phase 7-6
- 병역 면제가 **국제대회 하나뿐**이다. 부상 면제·연령 초과 같은 실제 사유는 없다

## 8. 이 문서를 고칠 때

수치를 바꾸면 **규칙 파일만** 고친다. 구조를 바꾸면 `npm run test:military`가
먼저 깨져야 한다 — 안 깨지면 그 테스트가 실데이터를 안 읽고 있다는 뜻이다.
