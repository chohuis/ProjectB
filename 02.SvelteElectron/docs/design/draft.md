# 11월 통합 드래프트 설계 (Phase 7-1, 2026-07-30 확정)

> **수치는 여기 복제하지 않는다** — 정본은
> `resource/data/master/players/generation_rules.json`의 `draftRules`다.
> 문서에 옮겨 적으면 stale해진다(이 프로젝트가 이미 겪은 문제다).
>
> 회귀 검사: `npm run test:draft` · 규모 실측: `npm run measure:draft`

## 0. 언제 도는가

**드래프트는 졸업 전(W47)에 한 번.** 실제 KBO와 같고, 그래야 관전 화면과
실제 지명이 **같은 명단**을 본다.

```
W47   드래프트 (고3·대4는 재학 상태로 후보)
        ├ 관전  → DraftBoardModal이 결과를 재생
        └ 스킵  → runDraftBoardBackground
W52   시즌 종료
        1. processSeasonEnd     미지명 고3·대4 졸업 → 드래프트 풀
        2. processNpcDraft      W47에 안 돌았으면 여기서 (lastDraftYear 가드)
        3. 오프시즌             은퇴·로스터 상한·FA·**진로 배정**
W1    고교 신입생 입학
```

⚠ **2번은 오프시즌보다 앞에 있어야 한다.** 오프시즌이 미지명자 진로를
배정하므로 드래프트가 뒤에 오면 이미 대학·독립으로 흩어진 뒤가 된다.
그리고 **주인공 졸업 시즌엔 W47 관전 이벤트가 안 뜬다**(진로 결과 모달이
대신 뜬다) — 그 해엔 여기가 유일한 실행 경로다.

한 시즌에 두 번 돌지 않게 `gameStore.lastDraftYear`가 막는다.

---

## 1. 후보 — 두 종류다

| | 누구 | 미지명이면 |
|---|---|---|
| **졸업 후보** | 고교 졸업반 · 대학 졸업반 | 소속이 없어지니 **진로 배정을 받는다** |
| **신청 후보** | 대학 저학년 · 독립리그 | **제자리다** |

이 구분이 핵심이다. 신청 후보를 드래프트 풀로 옮기면 미지명일 때 돌아갈 팀이
없어져 **대학 재학생이 매년 사라진다.**

**저학년 신청 의사는 확률이 아니라 능력치 하한이다** — "지명될 만한 실력이면
신청한다". 결정적이고 화면에 설명할 수 있다.

⚠ **나이 게이트로 저학년을 막을 수 없다.** 고2도 19세일 수 있다.
학년 게이트(`gradeMax` 학년만)가 막는다. 나이 게이트는 나이 상한 쪽이 본체다.

⚠ **복무자는 후보가 아니다.** 상무가 독립리그 소속이라 리그로만 거르면
복무 중인 선수가 드래프트에 나온다.

---

## 2. 지명

- 순서는 **전 시즌 성적 역순**. 데이터가 없으면 `KBL_TEAMS` 순
- 라운드 수는 규칙 파일이 정한다 (10팀 × 11라운드 = KBO 실제 규모)
- 팀 목록 정본은 `leagueTeams.generated.ts` — **여기서 다시 만들지 않는다**

> 예전엔 `draftSystem.ts`에 팀 ID 8개가 박혀 있었고 Phase 5가 refs를 갈아엎자
> **8개 전부 존재하지 않는 팀**이 됐다. 실측에서 5시즌에 지명자 400명이
> 유령 팀 소속으로 쌓이는 게 확인됐다 — 팀 화면 어디에도 안 나오는 선수들이다.

## 3. 신인 계약

**KBO 규정: 연봉은 최저연봉으로 균일하고 차등은 계약금이 진다.**

```
연봉    순번과 무관 (리그 최저연봉)
계약금  순번 구간별 × 팀 예산 지수(clamp)
계약    3년
```

팀 예산 지수는 로스터 연봉 계산과 **같은 입력**이다
(`buildSalaryIndex`, design/roster.md §5).

> 예전 TS 표는 양쪽으로 다 틀렸다 — 1순위 연봉 9,000만원(신인 연봉 규정 위반)에
> 하위 지명 1,500만원(최저연봉 3,000만원 미달). 게다가 팀 배수 맵의 키가 전부
> 없는 팀이라 **모든 구단이 배수 1.0으로 떨어지고 있었다.**

---

## 4. 신인은 2군에서 시작한다

1군 직행이면 1군 정원이 매년 11명씩 밀려 베테랑이 대신 나간다.
1군 승격은 Phase 7-2의 승강 로직이 담당한다.

⚠ **그러면 1군에 유입이 끊긴다.** 실측에서 팀당 24명(최소 16)까지 말랐다.
오프시즌이 1군 최소 인원 미달 시 2군 상위를 끌어올린다 — 성적 기반 상시 콜업이
생기기 전까지 리그가 성립하는 최소선이다.

---

## 5. 진로 배정 — 세 종류가 한 로직을 탄다

**미지명 졸업생 · 방출된 프로 · FA 미계약자.** 셋 다 "소속이 없어진 사람"이고,
따로 짜면 셋 중 하나가 반드시 어긋난다 (`draft::Placer`).

```
고교 졸업자   대학 → 독립 → 야구 포기
그 외         독립 → 야구 포기
```

⚠ **대학은 고교 졸업자만 간다.** 스태프와 달리 선수의 `대학 → 대학`은 학적이
허용하지 않는다(`_ledger.md` P6-9). 예전엔 경로를 안 보고 남는 자리부터 채워서
**대졸 미지명자가 대학 1학년으로 재입학**했고, 그 바람에 대학 로스터가 늘
상한까지 포화였다.

독립리그는 나이 상한을 본다 — 안 보면 독립 로스터가 은퇴 직전 선수로만 찬다.
배정 시 계약을 초기화한다 — 방출된 선수가 옛 연봉을 들고 독립리그로 가면 안 된다.

야구를 그만둔 사람에게는 `quit_baseball` 이벤트가 남는다.

---

## 6. 로스터 상한

**정본은 `rosterRules[리그].rosterMin/rosterMax`다.**
`rosterSize`(생성 인원)와 다르다 — 생성은 시작 인원, 이건 매 시즌 강제되는 상한.

> 예전엔 상한이 세 곳에 따로 있었고 셋 다 달랐다:
> `generation_rules.json` 30 / Rust `roster_rule()` 65 / TS `ROSTER_RULES` 65.

⚠ **FA 재배치는 상한보다 먼저 돌아야 한다.** 뒤에 두면 캡이 34명으로 줄여놓은
팀에 FA가 그대로 얹힌다. 최소 케이스로 확인했다 — 한 팀 80명 → 캡 후 34 →
FA 재배치 후 74. **캡이 매년 통과되고 있었다.**

⚠ **2군 강등은 팀과 리그를 같이 바꿔야 한다.** 팀만 `_2`로 바꾸면 그 선수가
계속 1군으로 집계돼 2군 상한이 아무한테도 안 걸린다.

---

## 7. 저장은 자르지 않는다

야구를 그만둔 선수를 슬림 보존하려 했으나, 실측 결과 **자를 수 있는 부분이
4.5%뿐**이라 그만뒀다 (`npm run measure:slotsize`).

```
행당 781 B  ·  abilities 30% · personality 18% · 그 외 스칼라 52%
슬림 대상(xp + form + pitches) = 42 B/행
```

용량의 절반이 이름·ID·팀 같은 못 자르는 스칼라고, 나머지도 지우면 은퇴 선수
상세가 빈 껍데기가 된다. 전량 보존해도 20시즌에 약 25 MB다.

진짜 부담은 `getAllNpcs`가 매번 전 행을 메모리로 올리는 것이고, 그건 성능 측정이
전제라 Phase 8 항목이다.

---

## 8. 이 문서를 고칠 때

수치를 바꾸면 **`generation_rules.json`만** 고친다. 여기 수치를 옮겨 적지 않는다.
구조를 바꾸면 `npm run test:draft`가 먼저 깨져야 한다 — 안 깨지면 그 테스트가
실데이터를 안 읽고 있다는 뜻이다(design/roster.md §10).

**분포는 실제 규모로 돌려 숫자를 찍는다. 예측하지 않는다** —
이 단계에서만 정원 산술로는 안 보이던 결함이 여섯 건 나왔다.
