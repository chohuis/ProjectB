## 0. 자격 연수 — 정본이 하나여야 한다

착수 전에 FA 자격 연수가 **네 곳**에 있었다:
규칙 파일(신설) · TS `FA_THRESHOLD` · Rust `npc_sim` · Rust `team_engine`.
**Rust 안에서만 같은 함수가 두 번 정의돼 있었다.**

지금은 규칙 파일이 정본이고, 남은 폴백(규칙을 못 들고 오는 동기 경로용) 두 개는
`test:fa`가 규칙 파일과 대조한다. 값이 갈라지면 테스트가 깨진다.

> 이 프로젝트에서 "표가 두 곳"으로 시작한 결함이 **열 번** 나왔다.
> 폴백을 남길 거면 대조 테스트를 같이 두는 게 이 코드베이스의 규칙이다.

## 1. FA 등급 — KBO식 A/B/C

등급은 **리그 연봉 순위 백분위**로 정한다.

| | 보상선수 | 보상금 |
|---|---|---|
| A | 보호 밖에서 1명 | 직전 연봉 × % |
| B | 보호 밖에서 1명 (보호 폭이 넓다) | × % |
| C | 없음 | × % |

**보상선수가 실제로 움직인다** (사용자 확정). 영입팀 로스터에서 보호 인원 밖
최고 OVR을 원소속이 데려가고, 그만큼 **영입팀에 자리가 하나 생긴다.**

⚠ **재계약이면 보상이 없다.** 원소속도 입찰에 끼고 홈 보너스를 받는다 —
그래야 "잔류"가 시장의 한 갈래가 된다.

⚠ 같은 선수가 두 번 보상으로 가면 로스터가 어긋난다. 한 번 뽑힌 사람은 제외한다.

## 2. 시장 — 순차 처리

좋은 선수부터 팀을 고르고, 계약이 성사되면 그 팀 자리가 하나 줄어든다.
**상위 FA가 먼저 자리를 가져간다** — 실제 FA 시장과 같다.

자리를 못 찾으면 미계약으로 남고 **7-1이 만든 진로 배정**(독립 → 은퇴)으로
넘어간다. 방출자·미지명자와 같은 로직이다.

실측(FA 60명 · 10구단): 등급 A:19 B:18 C:23 · 이적 31명 · 보상선수 발생 19명.

## 3. 방출 2단계

```
1단계  로스터 초과분 밀어내기          (7-1 D-4a)
2단계  정원 안이어도 성적·연봉·뎁스로   (여기)
```

1단계만 있으면 정원이 차 있지 않은 한 아무도 안 걸린다 — **부진한 고연봉
베테랑이 정원 안에서 계속 버텼다.**

- 점수는 `eval_release_priority` — 성적 부족 · 과지급 · 포지션 뎁스 · 나이 ·
  팀 성향(규율·안정성·성적압박)
- `maxPerTeam`이 없으면 성적 나쁜 해에 팀이 통째로 갈린다
- **하한 아래로는 안 내린다.** 방출만 돌면 로스터가 마른다 (7-2 P-4의 교훈)
- 방출자는 소속만 비우고 진로 배정이 독립·은퇴를 정한다

실측(5시즌): 연 13~37명 — 20팀 기준 팀당 0.7~1.9명.

## 4. 구단주 관계 (6C 이월)

관계값(−100~+100) × `ownerRelationWeight`만큼 **방출 점수를 깎는다.**
좋으면 한 번 더 기회를 주고, 나쁘면 밀어낸다.

```
관계 나쁨(-80)  113점
관계 없음        81점
관계 좋음(+80)   49점
```

⚠ **주인공에게만 적용된다.** 관계도는 주인공 기준 1:N이라 NPC끼리의 구단주
관계는 **존재하지 않는다**(Phase 6C 설계). NPC 경로는 가중치 0으로 넘겨
점수가 안 변한다 — `test:fa`가 그것도 확인한다.

⚠ `ownerRelationWeight × 100`이 임계값을 넘으면 관계 하나로 방출이 완전히
막힌다. 테스트가 막는다.

## 6. 아직 없는 것

- **주인공 재계약 UI 경로가 없다.** 엔진(`owner_relation`)과 규칙은 준비됐지만
  주인공이 계약 만료로 재협상하는 화면 흐름이 아직 `FaMarketModal`(FA 전용)뿐이라,
  구단주 관계의 재계약 쪽 소비처는 **7-6(이벤트·연출)에서 붙는다**
- NPC FA 시장이 오프시즌 어디에 끼는지는 배선 전이다 — `resolveFaMarketNative`가
  준비됐고 호출부는 7-5 이후 오프시즌 재구성 때 넣는다
- 협상 카운터오퍼 라운드 상한은 여전히 §11 미확정 (주인공 협상 UI와 함께 정할 것)

## 7. 이 문서를 고칠 때

수치를 바꾸면 **규칙 파일만** 고친다. 폴백 표를 새로 만들 거면 대조 테스트를
같이 둔다 — 안 그러면 열한 번째가 된다.
