## 4. ✅ B7 죽은 CSS 제거 뒤 화면 재확인

커밋 `c544f11f8` 이 14건을 지우며 **띄워 보진 않았다**고 적어 뒀다.

```
NewGamePage              12건
ContractNegotiationModal  1건  .opt-row label
IndependentApplyModal     1건  .meta
```

### NewGamePage 12건 — **눈으로 봤다**

4단계(기본 정보 · 팀 선택 · 능력치 · 확인)를 전부 띄웠다. 정상이다.
지운 11개 클래스가 **그 컴포넌트 템플릿에 0회** 등장하는 것도 확인했다.

### 나머지 2건 — 구조로 결론이 났다

띄우려면 프로 계약(`salaryNegotiation`)·고3 진로 허브까지 가야 한다.
대기 동작이 메모리에만 있어 세이브 주입도 안 된다. 대신 구조를 봤다.

🔴 **`.opt-row label` 이 함정이었다.**

```svelte
<label class="opt-row">      ← label 이 .opt-row **자신**이다
  <input type="checkbox" ...>
```

지워진 규칙은 **자손 선택자**(`.opt-row label`)다. `.opt-row` 도 있고
`<label>` 도 있으니 얼핏 살아 있어 보이는데, label 이 자기 자신이라
**애초에 안 걸린다.** 클래스 이름만 세는 검사였으면 오판했을 자리다.

`.meta` 는 `IndependentApplyModal` 템플릿에 0회다.

→ **14건 전부 진짜 죽은 규칙이었다.** Svelte 판정이 맞았다.

## 5. ✅ B8 "해외 빈 순위표 56행" — **원인은 과잉 교정이었다**

백로그가 *"미확인 · 문서만"* 으로 달아 둔 것이다. 띄워 보고 잡았다.

### 증상

`ABL 마이너` · `JBL 2군` · `KBL 2군` 의 **지난 시즌 순위표가 통째로 비었다.**
화면은 *"해당 시즌 순위 기록이 없습니다"* 라고 했다.

### 그런데 데이터는 있었다

세이브를 직접 열었다 (2026시즌을 마친 세이브):

```
LEAGUE_ABL_FARM   16팀    LEAGUE_ABL   16팀
LEAGUE_JBL_FARM   12팀    LEAGUE_JBL   12팀
LEAGUE_KBL_FARM   10팀    LEAGUE_KBL   10팀
```

**멀쩡히 저장돼 있었다.** 화면이 안 보여준 것이다.

### 원인

```js
.filter(r => !r.team_id.endsWith("_2"))
```

`refs` 가 1군·팜을 **같은 `leagueId`** 로 담아서, 안 거르면 ABL 이 32팀 ·
JBL 이 24팀으로 떴다 — **그 합이 56이고 백로그 제목의 숫자다.**
그걸 막으려 넣은 필터인데, 2군 리그를 고르면 그 리그 행은 전부 `_2` 라
**통째로 사라졌다.**

실측 — 필터가 1군엔 아무 일도 안 하고 2군만 지운다:

```
league_id          전체   `_2`끝   거른 뒤
LEAGUE_ABL          16      0       16     ← 하는 일이 없다
LEAGUE_ABL_FARM     16     16        0     ← 전부 사라진다
LEAGUE_JBL_FARM     12     12        0
LEAGUE_KBL_FARM     10     10        0
```

### 고침 — **1군을 볼 때만 뺀다**

```js
.filter(r => lid.endsWith("_FARM") || !r.team_id.endsWith("_2"))
```

⚠ **그냥 지우면 안 된다.** 옛 세이브는 1군 `league_id` 아래 팜 팀이 섞여
있을 수 있고, 그때 32팀이 다시 뜬다. 그 보호는 남겼다.

확인 — 2군 셋이 살아나고 1군은 그대로다:

```
ABL 마이너  16행  뉴욕 엠파이어 (2군) 69승 51패 · 득점 659
JBL 2군     12행  나고야 아이언 드레이크스 (2군) 70승 51패
JBL(1군)    12행  도쿄 네온 크레인즈 117승 38패   ← 안 바뀌었다
고교        110행                              ← 안 바뀌었다
```

검사 1건 · 변이 1건.

## 6. ✅ 스크린샷 후보 (10월 준비)

`DRIVE_USER_DATA=1` 로 임시 저장소에 띄워 찍었다 — 실제 세이브는 안 건드렸다.
새 게임으로 한 시즌 넘긴 세이브를 썼다.

| # | 화면 | 왜 |
|---|---|---|
| 1 | 경기 화면 (2회 초 · 2스트라이크 · 2루 주자 · 중계 로그) | 이 게임의 얼굴 |
| 2 | 커리어 결산 | 감정의 마무리 — 통산 8시즌 · 우승 2회 |

| 4 | 권역 순위표 | 규모 — 102팀 · 8권역 |
| 5 | 선수 능력치 | 키우는 재미 |

⚠ **경기 화면만 1920×1079 다**(나머지는 1920×1080). `drive.mjs` 는 창 크기
명령이 없어 최대화 상태로 찍힌다. 1px 모자라니 스토어에 올리기 전에
다시 찍는 게 좋다 — 내 드라이버로 크기를 잡으려면 대기 메시지를 넘기는
진행기가 필요한데, 그건 `drive.mjs` 의 `advance` 가 이미 한다(`scripts/` 는 A 소유).

⚠ **첫 투구 전 화면은 안 쓴다.** 중계 로그가 *"매치 엔진 초기화 중…"* 만
있어서 스토어 그림으로는 비어 보인다. 열두 구 던진 뒤로 찍었다.
