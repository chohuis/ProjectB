## 2. ② 제구형 지명 — 가설이 틀렸다. 드래프트는 구속을 **안 본다**

### 2-1. 가설 둘

계획 문서의 전제는 「드래프트 점수가 구속(`velocity`)을 가중해 같은 OVR 이면
제구형이 뒤로 밀린다」였다. 갈라야 할 것은 **지명 자리**(점수식)인가
**성장 곡선**(`growth_engine`)인가다. 둘 다 가설이므로 먼저 쟀다.

- **고졸 직행 25~40%**: 33.3% → 58.3% (🔴 위로 벗어남 · §1-8).

**그래서 ② 는 닫지 않는다.** 「드래프트가 구속을 가중한다」는 **기각**(§2-2 ·
정적으로 확정)이고, 「제구형이 약하다」는 **⑤ 로 줄었지만 지명 칼끝은 남았다**.
남은 물음은 하나다 — **`UNDRAFTED_SCORE` 68.0 근처에 제구형이 왜 늘 걸리나.**
그건 값이 아니라 표본 물음이라 닫는 24판에서 본다.

## 3. 고졸 직행 재측 — 수준 중립 뒤 (2026-09-28 · 12판 × 4시즌)

§1-8 이 「폭 압축이 고졸 직행을 33.3% → 58.3% 로 밀어 올렸다(목표 25~40%)」로
열어 둔 것을 §1-9(수준 중립) 뒤에 다시 쟀다.

```
PB_SEEDS=31337,4242,9001 PB_SEASONS=4 PB_ONLY=1-12 PB_FORCE=1 PB_CONC=2 \
  npm run probe:a:simrun
PB_SEASONS=4 PB_RUNS_DIR=resource/logs/runs_103_draft_level_2026-09-28 \
```

판 폴더 `resource/logs/runs_103_draft_level_2026-09-28/` (성장형 · 프리셋 넷 ×
씨앗 셋 · 동시 2판 · **약 110분**).

### 3-1. 세 점 — 폭·수준이 각각 얼마나 밀었나

| | 폭 9 (09-27 전) | 폭 5 · 창 52~57 | **폭 5 · 창 52.5~57.5** |
|---|---|---|---|
| **고졸 직행** | **4/12 = 33.3%** (ok) | **7/12 = 58.3%** 🔴 | **5/12 = 41.7%** 🔴 |
| balanced | 1/3 · OVR 71 | 3/3 · 73 | 3/3 · 73 |
| power | 2/3 · OVR 72 | 2/3 · 72 | 2/3 · 72 |
| control | 0/3 · OVR 69 | 1/3 · 71 | **0/3 · 70** |

| 삼킨 예외 · 정지 · 못 접은 해 · 연도 겹침 | 0 | 0 | **0** |
| 폴백 | 13 (0.61%) | 12 (0.57%) | **14 / 2,196주 = 0.64%** |

**수준 중립이 되돌렸다** — 58.3% → 41.7%. 밀어 올린 두 판(control·stamina 각
1/3 → 0/3)이 정확히 되돌아왔다. 남은 초과는 **한 판**이다.

### 3-2. 🔴 그 한 판은 이 표본의 분해능 안이다

12판에서 목표 25~40% 는 **3~4.8판**이다. 정수로는 4판(33.3%)이 상한이고
5판이면 41.7% — **한 판 차이가 8.3%p** 다. 즉 41.7% 와 40% 를 **12판으로는
못 가른다.**

- 09-26 D 계측이 같은 물음(γ)에서 이미 「씨앗 둘로는 못 갈랐고 **씨앗 셋
  20짝**이 필요했다」로 닫았다. 여기도 같은 규모다.
- §1-8 이 짚은 대로 `UNDRAFTED_SCORE` 68.0 이 칼끝이라 **한 판이 쉽게
  뒤집힌다.** 뒤집히는 판은 능력치가 나빠서가 아니라 고교 3년의 난수 착지가
  달라져서다.

### 3-3. `UNDRAFTED_SCORE` 제안 — **못 쟀다. 값을 건드리지 말 것을 권한다**

`npc_sim.rs:3913 const UNDRAFTED_SCORE: f64 = 68.0`. 그 자리 주석이 이 값의
내력을 적어 뒀다 — 78.0 일 때 1/12(8.3%) · **68.0 일 때 4/12(33.3%)** 로
같은 12칸에서 목표 안에 넣은 값이고 사용자가 확정했다.

🔴 **후보 70·72 의 12판 전후를 안 돌렸다.** 한 후보가 **판당 ~110분**이라
둘이면 3시간 40분이고, 그 시간에 ④⑫ 가 통째로 멈춘다. 규칙이
「완벽한 표본보다 끝난 보고가 먼저다 · 못 잰 것은 못 쟀다고 적는다」이므로
여기 적는다.

**그리고 지금 자료로는 올릴 근거가 약하다:**

1. **초과가 한 판이고 그 한 판이 분해능이다**(§3-2). 문턱을 올리면 그 한 판만
   떨어져 4/12 가 될 텐데, 그건 **표본 잡음에 값을 맞추는 것**이다 — 규칙
   「없는 결함에 값을 넣지 않는다」가 막는 자리다.
2. **68.0 을 정한 계측이 바로 이 12칸이었다**(주석). 같은 12칸이 지금 5/12 인데
   그때는 4/12 였다 — 세계가 그 사이에 여러 번 움직였으니(⑤ 폭·수준 · γ 정원
   압축 · 창단 연도 정본) **같은 12칸이 같은 답을 낼 이유가 없다.**
3. 문턱을 올리면 **고졸 직행만 줄이는 게 아니라** 대학·독립 갈래의 인구가
   같이 늘어난다. 그쪽 목표는 이번에 안 쟀다.

**돌릴 때 쓸 명령**(값만 바꿔 같은 12판을 두 번):

```bash

PB_SEEDS=31337,4242,9001 PB_SEASONS=4 PB_ONLY=1-12 PB_FORCE=1 PB_CONC=2 \
  npm run probe:a:simrun
PB_SEASONS=4 PB_RUNS_DIR=<새 폴더> npm run report:simruns
```

`runs/#NN.json` 에는 지명 여부(`커리어이벤트: draft_picked`)만 있고 **점수가
없다** — 그래서 이미 돈 12판으로 「70 이면 몇 판이 떨어지나」를 **되계산할 수
