## 0.7 규칙 한 줄이 **기계**가 됐다

> 주사위가 부른 것은 상태를 못 바꾸고, 상태가 부른 것만 상태를 바꾼다.

검사(L6)를 기다리지 않는다. `applySideEffects` 가 갈래를 보고 상태 효과를
**안 먹인다** — 검사는 데이터를 보는 것이지 동작을 막는 것이 아니고, 검사를 안
돌린 사이에 들어온 데이터는 그대로 세계를 바꾼다. 무시할 때 조용히 넘어가지
않고 로그를 남긴다(`[갈래] 상태 효과 무시 …`).

## 0.8 통지를 쓰는 법 — 세 줄이면 된다

```jsonc
{
  "id": "EVT_FARM_DEMOTED",
  "tier": "notice",                       // ← 등급 대신 이것. 등급 칸은 지운다
  "conditions": [
    { "type": "outcome_within", "outcome": "demote", "weeks": 0 }   // ← 실제로 내려갔을 때만
  ]
}
```

그리고 선택지 효과에 상태를 적으면 **진짜로 일어난다**:

```jsonc
{ "id": "accept", "label": "받아들인다", "effects": { "rosterMove": "demote" } }
```

문자열 축약형도 파서에 넣었다 — `"rosterMove:demote"` · `"rosterMove:callup"`.

### 갈래 값

| `tier` | 뜻 | 등급 추첨 | 주 1건 상한 | 상태 효과 |
|---|---|---|---|---|
| `normal`·`rare`·`unique`·`hidden` | 이벤트 | 탄다 | **걸린다** | ❌ 무시된다 |
| `notice` | **통지** | 안 탄다 | **안 걸린다** | ✅ 먹는다 |
| `urgent` | 통지의 **옛 이름** | 안 탄다 | 안 걸린다 | ✅ 먹는다 |
| (없음) | 필수(달력) | 안 탄다 | 안 걸린다 | ❌ |

⚠ `urgent` 를 `notice` 로 바꾸는 것은 네 몫(L4)이고 **급하지 않다** —
  `noticeOf()` 가 둘을 같이 보므로 옮기는 중에도 동작이 같다. 하는 일이 같은 것을
  둘로 두면 정본이 둘이 되니 결국은 한 이름으로 모아라.
