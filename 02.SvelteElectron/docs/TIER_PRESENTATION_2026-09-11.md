# 등급별로 플레이어에게 어떻게 보이나

> 2026-09-11 · 노말 · 레어 · 유니크 · 히든 · 통지 — 실제 이벤트 다섯으로.
> 화면 정본: `EventPendingModal.svelte` · `EventTierChip.svelte` · `eventTierCopy.ts`(C 4-5). 아래 예시는 **데이터에 실제로 있는 이벤트**를 그 규칙대로 그린 것이다.

---

## 0. 규칙 한 장

모달은 **다섯 등급이 같은 틀**이다. 등급이 바꾸는 것은 세 가지뿐이다.

| | 노말 | 레어 | 유니크 | 히든 | 통지 |
|---|---|---|---|---|---|
| **등급 칩** | 없음 | 🔵 **레어** (파랑) | 🟣 **유니크** (보라) | 🟡 **히든** (금색) | 없음 |
| **선택지 힌트** | 숫자 그대로 | 숫자 그대로 | **종류만** | **종류만** | 숫자 그대로 |
| **대가 한 줄** | 없음 | 없음 | 있음 | 있음 | 없음 |
| 「위기」 표시 | — | 몸 계열이면 붙음 | 몸 계열이면 붙음 | — | — |
| 뜨는 조건 | 주사위 | 주사위 | 주사위 | 주사위 + 숨은 조건 | **세계의 상태** |

**왜 노말에 칩이 없나** — 늘 오는 것에 이름표를 붙이면 이름표가 배경이 되어 레어·유니크가 안 보인다.
**왜 유니크·히든은 숫자를 감추나** — 요점이 「얼마를 얻나」가 아니라 **「무엇을 내주고 무엇을 얻나」**다. 숫자를 지우는 게 아니라 **효과 객체에서 종류를 다시 짓는다** — 「+3」만 지우면 「크게」가 남는 반쪽이 되기 때문이다.
**왜 통지에 칩이 없나** — 통지는 등급이 아니다. 주사위가 아니라 **세계가 정한 일**이 부른다. 선택지가 세계를 실제로 바꾼다.

모달의 순서는 늘 같다:

```
[이벤트] [등급 칩]
제목
본문
(유니크·히든: 이 선택에는 대가가 따른다 — 종류)
──────────────
[ 선택지 1 ]   힌트
[ 선택지 2 ]   힌트
```

## 1. 노말 — 늘 오는 것

`EVT_HS_Y2_WEEKEND_TRAIN` · 고교 2학년 · 결 `train`

```
┌──────────────────────────────────────────────┐
│ [이벤트]                                      │
│                                              │
│ 주말 자율 훈련의 유혹                          │
│                                              │
│ 주말이라 공식 훈련은 없다. 팀원 일부는 자율      │
│ 훈련을 간다. 당신은 어떻게 할 건가.             │
│                                              │
│ 아무도 없는 주말, 어떻게 보내겠습니까?           │
│ ────────────────────────────────────────────  │
│ [ 불펜을 던진다 ]        구속 XP +2, 피로 +8    │
│ [ 제구 드릴을 한다 ]     제구 XP +2, 피로 +5    │
│ [ 완전히 회복한다 ]      컨디션 +10, 사기 +1    │
└──────────────────────────────────────────────┘
```

- 칩이 **「이벤트」 하나뿐**이다. 등급 이름표가 없다.
- 숫자가 **그대로** 보인다 — XP 1~3 · 사기 · 컨디션 · 피로. 작은 것을 자주 고르는 자리라 값을 보고 골라야 한다.
- 대가 줄이 없다.
- **소식 목록에서도** 분류 칩(「훈련」 같은 회색 글자)만 있고 등급 칩은 없다.

## 2. 레어 — 가끔 오는 것

`EVT_FARM_R_CALLUP_LIST` · 2군 · 결 `career`

```
┌──────────────────────────────────────────────┐
│ [이벤트]  ( 레어 )                             │  ← 파랑 테두리 칩
│                                              │
│ 콜업 명단                                     │
│                                              │
│ 이번 주 콜업 명단에 이름이 올랐다는 이야기를     │
│ 들었습니다.                                   │
│                                              │
│ 확정은 아닙니다.                               │
│                                              │
│ 오늘 어떻게 하겠습니까?                         │
│ ────────────────────────────────────────────  │
│ [ 다 보여준다 ]      피로 +14, 감독 관계 +10    │
│ [ 몸을 맞춘다 ]      컨디션 +10, 사기 +4        │
└──────────────────────────────────────────────┘
```

- **파랑 「레어」 칩**이 「이벤트」 옆에 선다. 목록에서도 한 단 작게 같은 칩이 붙는다.
- 숫자는 **그대로** 보인다. 레어까지는 값을 보고 고른다.
- 대가 줄은 없다. 레어의 대가는 「가벼움」이고 그건 선택지 안의 피로로 이미 보인다.
- 이 이벤트는 결이 `career` 라 「위기」가 안 붙는다. 같은 레어라도 **몸 계열**(`theme: body`)이면 칩 옆에 빨간 **「위기」**가 붙는다 — 예: 「또 그 자리」(유리몸 후속).

```
│ [이벤트]  ( 레어 │ 위기 )                     │  ← 몸 계열 레어
```

## 3. 유니크 — 시즌의 사건

`EVT_UNIV_U_SENIOR_GRIP` · 대학 · 결 `people` · 대가: 동료 관계 −5

```
┌──────────────────────────────────────────────┐
│ [이벤트]  ( 유니크 )                           │  ← 보라 테두리 칩
│                                              │
│ 선배의 그립                                   │
│                                              │
│ 졸업하는 선배가 자기 슬라이더 그립을 알려주겠다고  │
│ 합니다.                                       │
│                                              │
│ 그 공으로 여기까지 온 사람입니다.               │
│                                              │
│ 이 선택에는 대가가 따른다 — 관계를 내준다        │  ← 대가 한 줄
│                                              │
│ 그 그립을 어떻게 하겠습니까?                     │
│ ────────────────────────────────────────────  │
│ [ 받는다 ]           큰 것을 얻는다 · 몸을 갈아 넣는다   │
│ [ 내 것으로 간다 ]   큰 것을 얻는다 · 학업이 오른다     │
└──────────────────────────────────────────────┘
```

- **보라 「유니크」 칩.**
- 🔴 **숫자가 사라지고 종류만 남는다.** 데이터의 힌트는 「구종 습득, 피로 +6」인데 화면은 그 문장을 **아예 안 쓰고** 효과 객체를 다시 읽는다 — `pitchGrant` → 「큰 것을 얻는다」, `fatigueDelta +6` → 「몸을 갈아 넣는다」.
- **대가 한 줄이 선택지 위에** 선다. 대가는 이벤트에 붙어 **어느 갈래를 골라도 낸다**(동료 관계 −5 · 선배가 자기 무기를 넘기는 자리라 라커룸이 안다). 그래서 선택지 안이 아니라 위에 있다.
- 종류 힌트는 **최대 세 개**이고, **내주는 쪽 한 자리를 먼저 떼어 둔다.** 얻는 것으로 줄을 채우면 「돈을 낸다」가 잘리는 걸 실제 유니크에서 봤다 — 유니크의 요점은 무엇을 내주고 얻나다.
- 같은 종류가 얻고 잃는 양쪽에 서면 **내주는 쪽만** 남긴다. 「얻고 잃는다」는 아무 말도 아니다.

**종류 아홉** — 얻는 말과 내주는 말이 따로 있다:

| 종류 | 얻을 때 | 내줄 때 |
|---|---|---|
| 큰 것(스탯·잠재력·성장률·구종·특성) | 큰 것을 얻는다 | 가진 것을 잃는다 |
| 기회 | 기회가 열린다 | 기회가 닫힌다 |
| 훈련(XP·효율·진행도) | 실력이 는다 | 훈련이 밀린다 |
| 사람 | 사람을 얻는다 | 관계를 내준다 |
| 이름 | 이름이 알려진다 | 이름값을 깎는다 |
| 돈 | 돈이 들어온다 | 돈을 내준다 |
| 몸(피로·컨디션·부상 위험) | 몸이 편해진다 | 몸을 갈아 넣는다 |
| 마음(사기) | 마음이 놓인다 | 마음을 다친다 |
| 학업 | 학업이 오른다 | 학업을 미룬다 |

## 4. 히든 — 드물게 오는 사건

`EVT_HID_PRO_AFTER_CG` · 프로 · 결 `body` · 대가: 4주간 부상 위험 +15%
숨은 조건: **지난 경기가 완투** 이고 **피로 85 이상**

```
┌──────────────────────────────────────────────┐
│ [이벤트]  ( 히든 )                             │  ← 금색 테두리 칩
│                                              │
│ 완투한 다음 날                                 │
│                                              │
│ 완투한 다음 날입니다. 팔이 안 올라옵니다.        │
│                                              │
│ 그런데 손끝에 남은 감각이 있습니다.             │
│                                              │
│ 이 선택에는 대가가 따른다 — 몸을 갈아 넣는다     │  ← 대가 한 줄
│                                              │
│ 그 감각을 어떻게 하겠습니까?                     │
│ ────────────────────────────────────────────  │
│ [ 지금 잡아 둔다 ]   큰 것을 얻는다 · 몸을 갈아 넣는다  │
│ [ 몸을 먼저 본다 ]   큰 것을 얻는다 · 몸이 편해진다    │
└──────────────────────────────────────────────┘
```

- **금색 「히든」 칩.** 히든에는 「위기」를 안 겹친다 — 히든 칩 자체가 사건의 표시라, 위에 위기를 겹치면 무엇이 드문 것인지 안 보인다.
- 숫자는 **종류만.** 「구종 등급 +1」이 「큰 것을 얻는다」로, 「잠재력 +1」도 「큰 것을 얻는다」로 보인다. 플레이어는 **무엇이 오르는지 정확히 모른 채** 고른다 — 히든은 되돌릴 수 없는 사건이라 숫자를 재고 고르는 자리가 아니다.
- 대가 한 줄: 부상 위험 4주 +15% → 「몸을 갈아 넣는다」.
- 🔴 **숨은 조건은 화면에 안 보인다.** 「완투 다음 날 · 피로 85+」는 플레이어가 그렇게 해서 만난 것이지, 조건표를 보고 맞춘 것이 아니다. 조건이 보이면 히든이 아니라 퀘스트가 된다.
- 히든은 **커리어에 한 번**이다. 뜨면 다시 안 온다.

## 5. 통지 — 세계가 정한 일

`EVT_PRO_EARLY_DEMOTION_TALK` · 프로 초반 · 결 `career`
조건: 프로 연차 2 이하 · 방어율 5.5+ · 8경기+ (주사위가 아니라 **성적이 부른다**)

```
┌──────────────────────────────────────────────┐
│ [이벤트]                                      │  ← 등급 칩 없음
│                                              │
│ 내려간다는 이야기                              │
│                                              │
│ 코치가 조심스럽게 불렀습니다. 2군에서 다시       │
│ 만들자는 말입니다.                             │
│                                              │
│ 받아들일 수도, 한 번만 더 달라고 할 수도         │
│ 있습니다.                                     │
│                                              │
│ 강등 이야기를 어떻게 받겠습니까?                 │
│ ────────────────────────────────────────────  │
│ [ 받아들인다 ]        성실 +6, 코치 관계 +7,    │
│                       사기 -6, 2군으로 내려간다  │
│ [ 한 번만 더 달라고 한다 ]                      │
│                       감독 관계 -5, 사기 +8,    │
│                       피로 +8                  │
└──────────────────────────────────────────────┘
```

- **등급 칩이 없다.** 겉보기는 노말과 같다.
- 숫자는 **그대로**다. 그리고 힌트에 **「2군으로 내려간다」**가 적혀 있다 — 이게 통지의 표시다. 수치가 아니라 **세계의 상태**를 바꾼다는 말이 힌트에 들어간다.
- 🔴 **「받아들인다」를 고르면 진짜로 내려간다.** 소속이 `_1` 에서 `_2` 로, 리그가 1군에서 2군으로, **일정까지** 따라간다. 테스터가 「가겠다고 했는데 안 내려갔다」고 한 그 자리이고, 지금은 실측으로 확인됐다.
- 주 1건 추첨에 **안 걸린다.** 조건이 맞으면 그 주 이벤트와 **같이** 온다. 그래서 어떤 주에는 이벤트 1 + 통지 1~2가 함께 뜬다.
- 통지 열셋 중 선택지가 없는 것(콜업 통보·탈락·미지명 등)은 **읽고 넘긴다.** 과거형으로 쓰여 있고 그게 참이다 — 실제로 일어난 뒤에만 뜨기 때문이다.

## 6. 소식 목록에서 — 한눈에 가르는 법

```
  훈련        주말 자율 훈련의 유혹                      W14
  커리어  (레어)  콜업 명단                              W22
  사람    (유니크)  선배의 그립                          W31
  몸      (히든)  완투한 다음 날                        W19
  커리어      내려간다는 이야기                          W15
  몸      (레어 │ 위기)  또 그 자리                     W08
```

- 회색 **분류 칩**(훈련·커리어·사람·몸)은 늘 있고, **등급 칩**은 레어부터만 그 옆에 선다.
- 등급 칩은 **테두리를 가진 꼴**이라 색이 안 보이는 화면에서도 분류 칩과 갈린다.
- 색은 레어 파랑 · 유니크 보라 · 히든 금 — 분류 칩의 색조와 **겹치지 않게** 골랐다. 어두운 화면에서는 같은 자리에 밝은 값이 든다.
- 「위기」는 **등급색을 안 쓴다**(늘 빨강). 등급과 위기는 다른 축이라, 같은 색이면 「빨간 유니크」가 새 등급처럼 보인다.

## 7. 한 시즌에 몇 번 만나나 (12판 최종 실측 · 프로 1군)

| 등급 | 시즌당 | 감각 |
|---|---|---|
| 노말 | 45.7 | 거의 매주 |
| 레어 | 5.8 | 두 달에 한 번 |
| 유니크 | 2.0 | 시즌에 두 번 |
| 히든 | 0.2 | 5년에 한 번 · 커리어 통틀어 2~4번 |
| 통지 | 0.2 | 일이 있을 때만 |

12시즌 커리어 하나에 노말 약 900 · 레어 약 100 · 유니크 약 30 · 히든 2~4 · 통지 10~14 다.
