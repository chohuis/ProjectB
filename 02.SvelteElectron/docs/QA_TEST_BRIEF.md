# QA 테스트 의뢰서 — 야구 선수 인생 시뮬

> 작성 2026-08-01. 대상 빌드: `extract-modals` 브랜치.
> 실행: `npm run dev` (Electron 포함). 브라우저 단독으로는 저장이 안 된다.

---

## 0. 먼저 읽을 것 — 이 게임에서 결함은 이렇게 생긴다

지난 작업에서 결함 **32건**을 잡았다. 전부 **에러를 안 냈다.** 화면은 멀쩡했고
게임은 계속 돌았다. 그래서 QA 관점이 보통과 다르다.

| 실제로 나온 형태 | 예 |
|---|---|
| **코드는 있는데 안 돈다** | 은퇴 판정이 도달 불가능한 분기에 있었다. 25시즌 완주해도 은퇴 0건 |
| **조용히 사라진다** | 자동 진행이 재계약 제안을 그냥 버렸다. 계약이 `remaining:0`인 채 7시즌 |
| **같은 화면이 다시 뜬다** | 주를 안 넘기고 pending만 밀어넣어 매년 W49에서 멈췄다 |
| **엉뚱한 데로 간다** | 전역 후 21세가 **고등학교로 돌아갔다** |
| **숫자가 조용히 틀리다** | 프로 순위표에 2군 10팀이 섞여 20팀이었다 |

**"진행이 되니까 정상"은 근거가 안 된다.** 아래 시나리오는 전부 *무엇이
화면에 보여야 하는가*를 같이 적어뒀다. 그게 안 보이면 결함이다.

### 이 게임은 축이 둘이다

| 축 | 무엇 | 시나리오 |
|---|---|---|
| **주인공** | 내가 겪는 커리어 | S1~S10 |
| **NPC 세계** | 182팀 5,600명이 나와 무관하게 도는가 | N1~N10 |

**둘째 축을 빠뜨리면 세계가 멈춘 걸 모른다.** 주인공 화면만 보면 정상인데
배경 리그가 전부 0승이거나, 5시즌째 아무도 은퇴하지 않거나, 입대만 하고
전역이 없는 상태를 놓친다 — 전부 실제로 나왔던 결함이다.

### 자동화가 이미 보는 것 (중복 제보 불필요)

`npm run test:v3`(27스위트) · `harness`(NPC 불변식 8종) ·
`test:careerpaths`(경로 6종) · `test:events`(이벤트 정합성) ·
`scenarios`(읽기전용 11종)가 **데이터**를 본다.

**화면은 하나도 안 본다.** 렌더링·레이아웃·버튼 반응·문구는 전부 사람 몫이다.
NPC도 마찬가지다 — 숫자가 맞는지는 `harness`가 보지만, **그게 화면에 보이는지와
서사가 성립하는지**는 사람만 볼 수 있다.

## 1. 제보 양식

결함 하나당 아래를 채워주세요. **재현 절차가 없으면 고칠 수 없다.**

```

[심각도] 진행불가 / 데이터손상 / 기능누락 / 표시오류 / 문구

[기대] 무엇이 보여야 했나
[실제] 무엇이 보였나 (스크린샷)
```

"실패 신호"는 이 프로젝트에서 **실제로 나왔던 증상**이다.

### S1. 새 게임 → 고교 1년 (약 20분)

**사전조건**: 새 슬롯

| | |
|---|---|
| 절차 | 새 게임 생성 → 이름·구질 선택 → 고교 배정 확인 → Ctrl+Q로 W40까지 자동 진행 |
| 기대 | 매주 훈련 결과·경기 결과가 메시지함에 쌓인다. 순위표에 우리 팀이 있다 |

**볼 것**

- [ ] 새 게임 생성 중 콘솔 에러가 없다 (F12 → Console)
- [ ] 주인공이 실제 고교 팀에 배정됐다 (팀명이 "-"나 ID 문자열이 아니다)
- [ ] 훈련 화면에서 **코치 이름과 능력치가 뜬다** — "-"면 결함
- [ ] 경기 후 개인 기록이 누적된다 (ERA·탈삼진이 0에서 안 움직이면 결함)

**실패 신호**
- 팀명 자리에 `TEAM_HS_XXX` 같은 ID가 그대로 보인다
- 코치·감독 능력치가 전부 50으로 같다 → 스태프가 안 붙은 것
- 같은 주차가 반복된다

### S3. W44 진로 허브 → W47 결과 (15분) — **가장 위험한 구간**

**사전조건**: 고교 3학년, W43까지 진행

| | |
|---|---|
| 절차 | W44 진로 허브에서 **드래프트·대학·독립 전부 체크** → 신청 완료 → W47까지 진행 |
| 기대 | 결과 화면에 지명/합격 여부가 뜨고, 선택지를 고르면 다음 단계로 넘어간다 |

**볼 것**
- [ ] 허브에서 대학·독립 팀을 **각각 3개까지** 고를 수 있다
- [ ] 고른 팀 이름이 체크 후 화면에 남는다
- [ ] W47 결과 화면에 **드래프트 보드**가 보인다 (라운드·순번·팀)
- [ ] 지명됐다면 계약 조건(연봉·기간·계약금)이 뜬다
- [ ] "거부"를 누르면 대안(대학/독립/현역)으로 실제로 넘어간다

**실패 신호**
- 진로 허브가 W47에도 또 뜬다
- 지명 통보를 수락했는데 **다음 시즌에 경기가 0건**
- 결과 화면에 선택지가 **하나도 없다** (4학년 미지명 시 특히 확인)

> ⚠ 이 구간은 **관전 보드가 재작성됐다**(634줄 → 425줄). 관전과 스킵의
> 결과가 다르면 결함이다. 두 번 플레이해서 비교해주세요.

### S4. 대학 4년 → 졸업 (40분) — **신규 기능**

**사전조건**: S3에서 대학 진학

| | |
|---|---|

**학업 모드별로 각각 한 학기씩 해보세요**

| 모드 | 기대 |
|---|---|
| `focus` | 학점 약 3.8 · 훈련 효율 70% |

- [ ] 3차: 유급 — 졸업이 한 해 밀린다

**실패 신호**
- 학점이 **4.50에 고정**된다 (상한 튐)
- 중간고사에서 **매번** 경고가 걸린다 (학기 길이 미보정)

## 3. NPC 세계 — 주인공 밖에서 무엇이 도는가

**여기가 이 게임의 절반이다.** 국내 **182팀 5,600명 + 스태프 1,180명**이
주인공과 무관하게 나이를 먹고, 성장하고, 이적하고, 입대하고, 은퇴한다.
주인공만 보면 **세계가 멈춘 걸 모른다** — 실제로 그런 결함이 여럿 나왔다.

### 자동화가 이미 보는 것 (중복 제보 불필요)

`npm run harness`가 3시행 × 5시즌으로 불변식 8종을 본다:

| | 무엇 |
|---|---|
| INV1 | 은퇴자를 뺀 **전원이 정확히 나이 +1** |
| INV2 | 인원 붕괴 없음 |
| INV3 | 모든 소속팀이 refs에 실재 |
| INV4 | 저장 왕복에서 나이·팀·상태 보존 |
| INV5 | **은퇴 단조** — 은퇴자가 다시 활동하지 않음 |
| INV6 | 고교 재학생 학년 1~3 |
| INV7 | 스키마 |
| INV8 | 고교 로스터 |

**즉 "숫자가 맞는가"는 자동화가 본다.** 아래는 **화면에 그게 보이는가**와
**서사가 성립하는가**를 본다 — 자동화가 못 보는 부분이다.

### NPC를 볼 수 있는 화면

| 화면 | 무엇이 보이나 |
|---|---|
| 리그 → 순위·기록 | 팀별 성적, 개인 순위(ERA·탈삼진 등) |
| 리그 → **거래기록** | 이적·트레이드·드래프트·입대·은퇴 이력 |
| 팀 화면 | 우리 팀 로스터 |
| 인물 화면 | 감독·코치·구단주 |
| **선수 상세 모달** | 개인 능력치·기록·커리어 이력 |
| 메시지함 (뉴스) | 세계에서 일어난 일 |

### N1. NPC 성장 — 능력치가 실제로 변하는가 (2시즌, 15분)

| | |
|---|---|
| 절차 | 시즌 시작 시 같은 팀 NPC **5명의 OVR을 적어둔다** → 2시즌 진행 → 다시 본다 |
| 기대 | 어린 선수는 오르고, 30대 중반 이상은 내려간다 |

**볼 것**
- [ ] 20대 초반 선수의 OVR이 **올랐다**
- [ ] 35세 이상 선수의 OVR이 **내려갔다**
- [ ] 전원이 똑같은 폭으로 움직이지 않는다 (개인차가 있다)
- [ ] 선수 상세에서 **시즌별 기록이 쌓인다**

**실패 신호**
- 2시즌이 지나도 OVR이 **한 명도 안 변한다**
- 전원이 정확히 같은 값만큼 오른다
- 능력치가 전부 50이다 → 생성이 안 된 것

### N2. 드래프트 — 매년 신인이 들어오는가 (10분)

| | |
|---|---|
| 절차 | W47 드래프트 관전 또는 스킵 → 리그 거래기록 확인 |
| 기대 | 매년 신인이 프로에 배정되고, 미지명자는 대학·독립으로 흩어진다 |

**볼 것**
- [ ] 거래기록에 그해 **드래프트 항목**이 쌓인다
- [ ] 지명자가 **실재하는 프로팀**에 배정된다 (유령 팀 없음)
- [ ] 특급 신인은 1군, 나머지는 2군에서 시작한다
- [ ] 미지명 고교생이 **대학·독립으로 간다** (사라지지 않는다)
- [ ] 같은 해에 드래프트가 **두 번** 열리지 않는다

### N3. 승강 — 1군↔2군이 실제로 오가는가 (1시즌, 15분)

| | |
|---|---|
| 절차 | 시즌 초 우리 구단 1군/2군 로스터를 적어둔다 → 시즌 말 비교 |
| 기대 | 월 1회 정기 승강 + 부상 시 상시 콜업이 돈다 |

**볼 것**
- [ ] 시즌 중 1군 로스터 **구성원이 바뀐다**
- [ ] 거래기록에 콜업·콜다운이 남는다
- [ ] 1군 인원이 상한(34) 안에 있다
- [ ] 2군이 마르지 않는다 (인원이 계속 줄면 결함)

**실패 신호**
- 로스터가 시즌 내내 **한 명도 안 바뀐다**
- 1군이 30 → 16명으로 줄어든다

> ⚠ "본문이 빈 트레이드 메시지"는 실제로 나왔던 결함이다.

### N6. NPC 은퇴 — 세대가 교체되는가 (5시즌, 20분)

| | |
|---|---|
| 절차 | 시즌 시작 시 리그 최고령 선수 3명을 적어둔다 → 5시즌 진행 |
| 기대 | 노쇠한 선수가 은퇴하고 그 자리를 신인이 채운다 |

**볼 것**
- [ ] 적어둔 노장이 **5시즌 안에 은퇴**한다
- [ ] 거래기록에 은퇴 항목이 쌓인다
- [ ] 은퇴한 선수가 **다음 시즌 로스터에 없다**
- [ ] 리그 평균 연령이 폭주하지 않는다 (매년 오르기만 하면 신인 유입 부족)

**실패 신호**
- 5시즌 동안 은퇴가 **0건**
- 반대로 **전원이 조기 은퇴**한다

> ⚠ 이 프로젝트의 전신에서 **"20명 중 20명 전원 조기 은퇴"** 가 나왔다.
> 은퇴가 너무 없는 것도, 너무 많은 것도 결함이다.

### N7. NPC 병역 — 입대·전역이 도는가 (3시즌, 20분)

- 상무가 정원의 1.5배로 불어난다

### N10. 배경 리그가 도는가 (상시)

주인공이 어느 무대에 있든 **나머지 4개 리그가 같이 돌아야 한다.**

| | |
|---|---|
| 절차 | 고교생일 때 리그 화면에서 **프로·대학·독립 순위표**를 본다 |
| 기대 | 주인공과 무관하게 경기가 소화되고 순위가 쌓인다 |

**볼 것**
- [ ] 프로 순위표에 승패가 쌓여 있다 (전부 0승이면 결함)
- [ ] 대학·독립도 마찬가지다
- [ ] 개인 기록 순위에 NPC 이름이 뜬다
- [ ] 시즌 종료 시 **각 리그 우승팀 발표**가 온다

**실패 신호**
- 주인공 리그만 숫자가 있고 나머지는 전부 0
- 모든 경기가 0-0이거나 홈팀만 이긴다 → 로스터 없이 시뮬된 것

## 4. 우선순위

시간이 부족하면 이 순서로.

| 순위 | 시나리오 | 이유 |
|---|---|---|
| 1 | **S3 진로 허브** | 커리어가 갈리는 지점. 여기서 막히면 이후 전부 못 본다 |
| 2 | **S7 재계약** | 최근 고친 곳. 자동/수동 차이가 핵심 |
| 3 | **N10 배경 리그** | 5분이면 보는데 **세계가 멈췄는지**를 바로 가른다 |
| 4 | **N9 스태프** | 5분. 전부 50이면 큰 결함 |
| 5 | **S4 대학 학업** | 신규 기능. 화면이 처음 붙는다 |
| 6 | **S5 군 복무** · **N7 NPC 병역** | 전 구간이 미검증이었다. 같이 보면 효율적 |
| 7 | **N6 NPC 은퇴** · **N8 학교 세대** | 세대 교체가 안 돌면 5시즌 뒤 세계가 굳는다 |
| 8 | S6 프로 시즌 · N3 승강 | 순위표 20팀·학업 혼입을 방금 고쳤다 |
| 9 | N2 드래프트 · N4 트레이드 · N5 FA | 시장 3종 |
| 10 | S1·S2·S8·S9·S10 | 기반·표시 |

### 긴 판 한 번 vs 짧은 판 여러 번

NPC 항목(N1·N6·N7·N8)은 **여러 시즌을 봐야** 판정된다.
**고교 1학년으로 시작해 프로 5년차까지 한 판을 길게** 가는 게 가장 효율적이다 —
그 한 판에서 N1~N10과 S1~S8이 거의 다 지나간다.

시즌마다 **로스터·순위표를 스크린샷으로 남겨두면** 비교가 쉽다.

## 4. 알려진 미구현 (제보 불필요)

- **인생 기록/엔딩 화면** — 설계 전
- **해외 리그(ABL·JBL)** — 1차 출시 범위 밖. 화면에 안 보이는 게 정상
- 메일함 50개 상한 — 오래된 메시지가 밀려나는 건 의도된 동작
- 대회·국제대회 성적이 개인 기록에 안 남음 — 알려진 제약
