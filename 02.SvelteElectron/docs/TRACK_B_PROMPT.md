## 1. 🔴 절대 규칙 — 이걸 어기면 셋이 하루씩 잃는다

### R1. `npm run build:native` 를 **돌리지 마라**

Rust 빌드는 `.node` 파일 하나를 덮어쓴다. A 가 동시에 돌리고 있으면
**파일 잠금으로 조용히 실패**하고, 고친 줄 알았는데 옛 바이너리를 재게 된다
(이 저장소에서 이미 세 번 겪었다).

Rust 가 바뀌면 A 가 알린다. 그때 `.node` 를 **복사해 쓴다.**

### R2. 아래 파일은 **열지 마라** — A·C 소유다

```
packages/engine-native/**                      A
resource/data/master/players/generation_rules.json   A  ← 수치 정본
apps/ui/src/shared/stores/game.ts              A
apps/ui/src/shared/usecases/advanceWeek.ts     A
apps/ui/src/shared/usecases/weekPhases/market.ts     A
scripts/**                                     A
apps/ui/src/pages/**                           C
apps/ui/src/features/**                        C
apps/ui/src/shared/repo/slotRepo.ts            C
apps/desktop/ipc/slotdb.cjs                    C
docs/RESUME.md · CLAUDE.md                     A
```

**이벤트 확률·수치를 바꾸고 싶으면 A 에게 넘긴다.** `generation_rules.json`
에서 충돌이 나면 어느 쪽 값이 맞는지 사후에 못 가린다.

### R3. 네 소유는 이것이다

```
resource/data/master/events/**            607개 파일
resource/data/master/messages/**
apps/ui/src/shared/usecases/eventEngine*  조건 판정만
apps/ui/src/shared/usecases/weekPhases/digest.ts
docs/TRACK_B_*.md                         네 문서
```

검사는 **새 파일로만** 추가한다. 기존 `__tests__` 파일을 고치면 셋이 같은
파일에서 만난다.

### R4. 브랜치

네 브랜치에서 일한다. **A 가 하루 한 번 트렁크로 병합**한다. 병합 뒤
트렁크를 받아 이어 간다. 며칠씩 안 합치면 R1~R3 을 지켜도 갈라진다.

## 2. 이 저장소에서 일하는 법 — 반드시 지켜라

`CLAUDE.md` 와 `02.SvelteElectron/CLAUDE.md` 를 먼저 읽어라. 요점만:

- **값은 실측으로.** 추측하지 않는다. 적용 전후를 잰다. **3회씩 잰다**
- **가설을 세웠으면 그것부터 재라.** 이 저장소에서 가설이 틀린 적이 훨씬 많다
- **고치려는 자리의 주석을 먼저 읽어라.** 대개 이미 답이 적혀 있다
- **문서를 그대로 믿지 마라.** "87% 유실"이 실제로는 52% 였다 —
  **낡은 기록을 옮겨 적어 헛짚은 게 이 저장소에서만 여섯 번**이다
- 주석은 **왜**를 적는다. 코드로 알 수 있는 건 안 적는다. 평서체로 쓴다
- 사용자 응답만 존댓말
- 검사에 **정규식을 쓰지 마라**. 좁은 필터로 grep 하고 단정하지 마라
- **변이 검증**을 해라 — 고친 곳을 되돌리면 네 검사가 실패해야 한다.
  실패하지 않으면 그 검사는 아무것도 안 보고 있다
- 커밋 전 회귀: `npx vitest run` · `npx tsc --noEmit`

### ⚠ 소식(MessageItem) `id` 는 유일해야 한다

중복이 **하나만 생겨도** Svelte 가 `each_key_duplicate` 로 죽고
**세이브가 아예 안 열린다.** 로드 화면에서 멈춘 채 단서가 없다.

```
msg-digest-w13               ✗ weekNum 은 시즌마다 1로 리셋 → 해마다 겹친다
msg-digest-2027-w13          ○ 연도를 넣는다
msg-tour-open-TOUR_HS_X-2027 ○ 대상 ID + 연도
```

표시용 한글 라벨을 `id` 에 넣지 마라 — 계측이 종류를 못 뽑는다.

### ⚠ 데이터가 코드와 어긋나도 **아무도 안 죽는다**

게임은 돌고 콘텐츠만 사라진다. 조건 오타 하나로 이벤트 35종이 죽어 있었고
아무 로그도 안 났다. **네가 만든 이벤트가 실제로 화면에 닿는지 반드시 재라.**

계측: `npm run measure:eventfunnel`
