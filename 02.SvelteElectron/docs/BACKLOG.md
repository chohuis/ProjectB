## 2. Phase 8 — 성능 (R6d)

**국내 약 2,930경기/시즌**(주당 약 56경기)이 설계 제약이다.

- [ ] **성능 목표 수치 합의** — 이게 먼저다. 추측으로 최적화하지 않는다
- [ ] 프로파일 → 진범 특정 → **그것만** 수정
- [ ] **은퇴자를 `getAllNpcs`에서 빼기** (Phase 7-1 D-4b 이월). npc 행은 781 B고
      20시즌 누적 약 25,000행 ≈ 25 MB — **파일 크기는 문제가 아니다.**
      부담은 매번 전 행을 메모리로 올려 파싱하는 것이다. 은퇴자를 조회 시에만
      읽으면 되는데 게임 로직 여러 곳이 은퇴자를 참조해 파급이 크다 —
      측정 후에 손댄다. 근거: `npm run measure:slotsize`
- 참고: OnePitch는 같은 규모를 Rust 단독 1시즌 24.75초로 처리했고 **최대 개선 요인은
  인덱스 부재 해소**였다(73s→24.75s). 현행은 주간 처리 상당부분이 TS(`advanceWeek.ts`)에 있다

⚠ **현재 성능은 측정된 적이 없다.** Phase 8은 이 숫자를 만드는 것부터 시작한다.
로스터 확대(4,390 → 5,600명)와 국내 전 리그 로스터 생성이 이 위에 얹혔다.
해외를 뺀 만큼(56팀·ABL 288경기·JBL 240경기) 부하는 줄었다.

> `season` 블롭 → 테이블 분리는 **이미 끝났다**(마이그레이션 v2). R6a는 8/8 완료.
