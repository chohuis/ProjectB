## 1. Phase 7 — 커리어·시장·신규 (R6c)

가장 덩치가 크다. 6개 묶음이고 서로 의존한다. **권장 순서는 아래 번호순** —
드래프트가 2군 배치를 부르고, 2군 배치가 승강을 부르고, 병역이 상무 로스터를 부른다.

### 7-1. 11월 통합 드래프트
- 대학 1~4학년·독립 **매년 신청** (현재는 졸업반만)
- 지명 순서·라운드·미지명자 처리
- 관련 기존 코드: `weekPhases/market.ts`(1,038줄), `draftObserve`, W47 배경 드래프트

### 7-2. 프로 진입 · 승강
- 신인은 **2군 배치**가 기본 (특급 신인 1군 직행 조건은 §11.1 미확정 — 스탯 스케일 확정 후)
- 승강 **2경로**: 상시 콜업 + 월간 정기
- 2군 스케줄·PO는 Phase 5에서 이미 복원됨 → 여기서 선수 흐름만 연결

### 7-3. 국가대표 · 병역
- 국제대회 3종 · 합성 대표팀 · 시즌 중 임시 이탈
- 병역 면제 판정
- **상무 로스터 40~50% 교체** (Phase 6에서 이월 — 복무 완료자 복귀가 병역 트랙 전체와 묶여 있어 떼어낼 수 없었다)
- 발탁 커트라인·대회 성과 확률은 §11.1 미확정

### 7-4. 방출 · FA
- 방출 **2단계 판정**
- FA **등급제** — 보상선수가 실제로 이동해야 한다
- 협상 카운터오퍼 라운드 상한 §11.1 미확정 (OnePitch는 1회로 단순화했다)

### 7-5. 개인 재정 · 스태프 배선 · 부상 전조
- 개인 재정 **전체** — 세율 구간·트레이닝 보너스·팀자원 반비례 계수·투자 수익률 전부 §11.1 미확정
- **스태프 15종 배선** — 6A에서 생성만 했다. 실제 효과 계수 15개가 미정 (§7.3)
- 부상 전조 경고

### 7-6. 문장 뱅크 · 뉴스
- 문장 뱅크 엔진 · 뉴스 4종
- **6C 관계도가 선결**이다 — "동료 상태" 뉴스가 관계 데이터를 실측 근거로 쓴다

### 7-7. Phase 6에서 이월된 대학 이벤트
- **쇼케이스** (감독 4명 지명) · **올스타전** (포지션별 인기도 랭킹)
- 고교 대응 이벤트(스카우트 데이 등)는 **기획 자체가 없다** — §11.1 신규 기획 필요

## 2. Phase 8 — 성능 (R6d)

**국내 약 2,930경기/시즌**(v1 대비 3.8배)이 설계 제약이다. 주당 약 56경기.

- [ ] **성능 목표 수치 합의** — 이게 먼저다. 추측으로 최적화하지 않는다
- [ ] 프로파일 → 진범 특정 → **그것만** 수정
- [ ] `season` 단일 JSON 블롭 → `schedule`/`standings`/`season_stats` **테이블 분리**
      — R6a에서 유일하게 안 한 항목. 172팀 규모에서 블롭은 한계라고 이미 판정했다(AUDIT §5-2)
- 참고: OnePitch는 같은 규모를 Rust 단독 1시즌 24.75초로 처리했고 **최대 개선 요인은 인덱스 부재 해소**였다
  (73s→24.75s, 워스트 46s→5.1s). 현행은 주간 처리 상당부분이 TS(`advanceWeek.ts`)에 있다

⚠ **현재 성능은 측정된 적이 없다.** Phase 8은 이 숫자를 만드는 것부터 시작한다.

## 5. 값이 안 정해진 것 (DESIGN §11 · §11.1)

전부 **"스탯 스케일 확정 후"** 성격이라 밸런스 하네스에서 결정한다.

- 특급 신인 1군 직행 조건 · 협상 카운터오퍼 라운드 상한
- 개인 재정 전 수치 (세율 구간·보너스 폭·반비례 계수·수익률)
- 국가대표 발탁 커트라인 · 대회 성과 확률
- **스태프 15종 각각의 계수**
- 고교 유사 이벤트 구체 기획 (기획서에 없던 신규)
- 성능 목표 수치
- npc 테이블 능력치 JSON의 Rust serde 규약 (camelCase 유지 여부)
- 드리프트 리그의 "리그 리더" 생성 규칙 — **해외 전용으로 범위 축소됨**
- 감정 시스템 dormant 재정의 (Named 타 리그 준활성)
