## 1. E2 — 경기 출전이 성장에 얼마나 기여하나

**어떻게 쟀나**: 별도 판을 안 돌리고 DR(고교 3~4년)·LOC(프로 1시즌) 판에
훈련 주 슬롯 몰빵(`setTrainingSlots([주프로그램뿐])`) 상태로 매주(`runOneWeek()`)
투구 velocity+command+control 합의 증가분을 찍는 계측을 얹었다. "그 주 등판
있음/없음"으로 갈라 없는주 평균(훈련만)과 등판주 평균(훈련+경기)의 차를 그 주
게임 수로 나눠 **경기 1회의 증분**을 역산한다(`probe-morale.cjs`가 사기에 쓴
것과 같은 방식). 대학·독립 행은 `probe:paths`로 등판·이닝만(주별 증분은 별도
계측 없음 — 아래 표에 "—"로 남긴다).

## 2. DR — 드래프트 결과 분포 기준선

**어떻게 쟀나**: `npm run probe:d:dr`(동시성 1로 낮춤 — 경합 사고 뒤). 시작
프리셋 넷(균형·파워·제구·체력 — `NewGamePage.svelte` PRESETS와 같은 값을
`perfEntry.ts`의 `PB_START_PRESET`으로 심는다). 진로 정책은 드래프트·대학·독립을
전부 열어 둔다. 고교 3학년 결판 시점의 `careerProbe()`를 찍는다(⚠ `chooseDraft`/
`chooseSchoolOrIndependent`가 결과를 지우므로 **지워지기 전 마지막 값**을 따로
든다 — 처음엔 이걸 놓쳐 전부 null로 나왔었다). 구속(km/h) = 100 + velocity × 0.65.

⚠ **이 판은 훈련을 주 슬롯 몰빵으로 고정했다**(E2 겸용) — 몰빵 전 개별
확인(같은 씨앗 20260802 · balanced)에서는 **2R 11P 지명**이 나왔는데, 몰빵
뒤에는 **대학합격**으로 바뀌었다. 드래프트 분포가 훈련 슬롯 배분에 민감하다는
뜻이다 — 아래 표는 "몰빵 기준"이고, 결정 ⑤(슬롯 배수)가 정해지기 전 값이다.

⚠ 결정 ⑭(프리셋 OVR을 58~62로 내리기) 자체는 아직 반영 전이다 — 이 표는 "내리기 전".

## 5. REU — 재회 12종 무대별 도달 분포

**어떻게 쟀나**: `npm run probe:d:reu`. 프로 전역 판(드래프트+대학 닫음) · 독립
전역 판(드래프트 닫음) × 씨앗 하나(20260802). 고교 졸업 직후 `forceEnlist`로
입대 시점을 고정(자연 진행을 기다리면 씨앗마다 입대 시점이 흔들려 "전역 후 몇
주"를 서로 못 비교한다). 전역 뒤 최대 110주를 한 주씩 밀며 재회 12종 각각을
`eventRuleProbe()`로 폴링해 최초 발동 주와 순서를 잡는다.

⚠ 입대 시점을 고교 졸업 직후로 고정했으므로 **이 숫자는 "가능한 가장 이른
조건"에 가깝다** — 실제 플레이는 입대가 이보다 늦을 수 있다.

**구조상 상한(코드 실측·`events/conditional/EVT_MILREUNION_*.json`)**: 12종 중
5종(BULLPEN_CATCH·OPP_MOUND·SAME_CLUB·TICKETS·UNIT_INVITE)이 `career_stage:
pro_kbl(등 pro_*)` 조건이라 **독립 전역 판에서는 구조적으로 0/12**다. INDIE_FIELD
는 반대로 `career_stage: independent`만 인정해 **프로 전역 판에서는 구조적으로
안 뜬다.** 나머지 6종은 무대 제한이 없다. → 프로 전역 판 이론상 최대 11/12,
독립 전역 판 이론상 최대 7/12.
