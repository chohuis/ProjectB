## 1. E2 — 경기 출전이 성장에 얼마나 기여하나

**어떻게 쟀나**: 별도 판을 안 돌리고 DR(고교 3~4년)·LOC(프로 1시즌) 판에
훈련 주 슬롯 몰빵(`setTrainingSlots([주프로그램뿐])`) 상태로 매주(`runOneWeek()`)
투구 velocity+command+control 합의 증가분을 찍는 계측을 얹었다. "그 주 등판
있음/없음"으로 갈라 없는주 평균(훈련만)과 등판주 평균(훈련+경기)의 차를 그 주
게임 수로 나눠 **경기 1회의 증분**을 역산한다(`probe-morale.cjs`가 사기에 쓴
것과 같은 방식). 대학·독립 행은 같은 계측을 `probe-d-e2-growth.cjs --path
univ|indie`로 따로 돌려 얻었다(각 4시즌 · 표본 1시즌뿐).

## 2. DR — 드래프트 결과 분포 기준선

**어떻게 쟀나**: `npm run probe:d:dr`(동시성 1). 시작 프리셋 넷(균형·파워·
제구·체력 — `NewGamePage.svelte` PRESETS와 같은 값을 `perfEntry.ts`의
`PB_START_PRESET`으로 심는다). 진로 정책은 드래프트·대학·독립을 전부 열어
둔다. 고교 3학년 결판 시점의 `careerProbe()`를 찍는다(⚠ `chooseDraft`/
`chooseSchoolOrIndependent`가 결과를 지우므로 **지워지기 전 마지막 값**을 따로
든다 — 처음엔 이걸 놓쳐 전부 null로 나왔었다). 구속(km/h) = 100 + velocity × 0.65.
**정본은 기본 훈련**(부팅 시 기본 배정 그대로 · 보통 플레이어가 그냥 두는 경로)

기준으로 못 쓴다는 지적(코치 2026-09-06)에 따라 **몰빵은 별도 "훈련 배분
민감도" 표로만 남긴다**.

⚠ 결정 ⑭(프리셋 OVR을 58~62로 내리기) 자체는 아직 반영 전이다 — 이 표는 "내리기 전".

## 5. REU — 재회 12종 무대별 도달 분포

**어떻게 쟀나**: `npm run probe:d:reu`. 프로 전역 판(드래프트+대학 닫음) · 독립
전역 판(드래프트 닫음) × 씨앗 하나(20260802). **고교를 건너뛰고 부팅 직후 바로
입대시킨다**(`forceEnlist`) — 고교(3~4시즌·약 175주)까지 다 걸으면 복무 100주
+ 전역 후 관찰까지 실측 40~65분이 걸려 1200초 상한을 못 맞췄다(아래 「못 잰
것」에 그 경로 기록). 복무 100주(규정·불변)만으로도 약 900초 안팎이 걸리므로,
전역 뒤는 **벽시계 자체 컷오프**(1080초 데드라인)로 남은 시간만큼만 한 주씩
밀며 재회 12종을 `eventRuleProbe()`로 폴링한다 — 다 못 보면 `못본전역후주`에
남은 주수를 정직하게 남긴다.

⚠ **이중 근사다** — 입대 시점을 고교 없이 즉시로 고정했고(실제 최이른 조건보다도
이르다) 전역 후 관찰도 시간이 다하면 끊긴다. **이 숫자는 "이론상 가장 이르고
가장 짧게 본" 하한**이지 실제 플레이 분포가 아니다.

**구조상 상한(코드 실측·`events/conditional/EVT_MILREUNION_*.json`)**: 12종 중
5종(BULLPEN_CATCH·OPP_MOUND·SAME_CLUB·TICKETS·UNIT_INVITE)이 `career_stage:
pro_kbl(등 pro_*)` 조건이라 **독립 전역 판에서는 구조적으로 0/12**다. INDIE_FIELD
는 반대로 `career_stage: independent`만 인정해 **프로 전역 판에서는 구조적으로
안 뜬다.** 나머지 6종은 무대 제한이 없다. → 프로 전역 판 이론상 최대 11/12,
독립 전역 판 이론상 최대 7/12.

있을 수 있다** — 이 실측은 코드가 아니라 내 사전 판정(위 「구조상 상한」 문단)이
넷 종에 대해 틀렸다는 뜻이다. 정확한 `stages` 배열은 재확인이 필요하다(아래
「못 잰 것」).

**닿지 못한 둘(UNIT_LETTER·FIRST_CALL)은 둘 다 `relation_gte unitmate`
문턱(각각 30·20)이 있다** — 나머지 열은 이 조건이 없다. 복무 100주 동안
`PB_MIL_CHOICE=ball`(공 위주 선택)로는 특정 한 전우와의 관계값이 20~30까지
못 쌓이는 것으로 보인다(두 경로·양쪽 다 0/1 — 재현성 있음).

⚠ 이 표는 "고교 생략 + 부팅 즉시 입대"라 실제 플레이(고교를 거치고 나이가 더
든 뒤 입대)와 조건 판정 나이·전역 연도가 다를 수 있다 — 절대 주차는 참고용,
**순서와 상대 간격**이 이 계측의 핵심이다.

## 못 잰 것

- **REU 원안(고교부터) 실측 실패** — 고교 3~4시즌부터 걸으면 복무 100주 +
  전역 후 관찰까지 실측 40~65분이 걸린다. 1,100,000ms(18분)·3,600,000ms(60분)·
  4,800,000ms(80분) 세 번 타임아웃을 늘려 봤지만 **80분판도 두 판 다 시간이
  다 됐다**(CPU 시간이 벽시계와 거의 같아 진짜 그만큼 걸린다 — 코드 결함이
  아니라 규정 복무 기간 자체가 크다). 1200초 상한을 지키려고 **고교를 생략하고
  부팅 즉시 입대시키는 근사법으로 바꿔** 재측정했고, 그 결과가 5절 표다. 원안
  (고교부터 자연스럽게 입대)으로 잰 값은 없다 — 절대 주차가 다를 수 있다.
- **REU 독립 전역판의 "구조상 상한" 재확인 필요** — 5절 표에서 독립 전역 판이
  사전 판정한 이론상 상한(7/12)을 넘겨 9/12가 나왔다. `career_stage: pro_kbl`
  전용으로 봤던 OPP_MOUND·SAME_CLUB·TICKETS·UNIT_INVITE 넷이 독립 전역에서도
  떴다 — 그 넷의 `stages` 배열을 다시 읽어야 한다(이번 실측에서는 안 함).
- **DR·LOC·E2 1차 병렬 실측 실패** — 오케스트레이터 넷을 동시성 2~3으로 동시에
  띄웠다가(실질 8~9 병렬) CPU 경합으로 DR 12판·LOC 6판·E2(부분)가 전부 타임아웃
  났다(표본 0). 코드 결함은 아니다 — 이후 동시성 1·순차 실행으로 바꿔 다시 재서
  각 절을 채웠다.
- **LOC 주인공 개인수치(ERA·IP)의 실행별 편차** — 같은 코드·씨앗·모드를 두 번
  돌려 한 번은 0, 한 번은 정상값(ERA 7.69)이 나왔다. 원인 미확인 — DR절의
  같은 현상(자원 경합 없는 단독 실행끼리도 드래프트 결과가 갈림)에 비춰
  보면 게임의 커리어 경로 자체가 씨앗 재현성 밖에 있는 쪽이 더 그럴듯하다.
  리그 전체 지표는 두 판 다 정상 표본이라 영향이 없어 보인다.
- **MOR "부진 주"** — 주 단위로 그 경기 실점/성적을 주는 프로브가 없어 승패
  여부(패배 주)만 쟀다. 부진(피안타·실점 급증)은 별도 계측이 필요하다.
- **E2 2군** — LOC 판(씨앗 20260802)에서 2군 기간이 0주로 나와 2군 행을 못
  뽑았다. 대학·독립은 `probe-d-e2-growth.cjs`로 잡았지만 표본이 1시즌뿐이다.
- **LOC 씨앗 777 모드 0** — "프로 미도달"로 나왔다(드래프트가 안 됐고 아마
  독립 소속으로 리그 지표를 쟀을 가능성). 그 판만 무대가 다를 수 있어 순수
  모드 비교에서는 참고용으로만 쓴다.
