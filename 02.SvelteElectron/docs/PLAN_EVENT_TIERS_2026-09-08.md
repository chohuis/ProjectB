# 이벤트 등급 체계 — 4단계 기획서 (2026-09-08)

> 사용자 확정(09-08): 한 주에 선택지 하나 · 등급 넷(노말·레어·유니크·히든) · 전부 멈춤 · **빈 등급은 없어야 한다** · 물량이 아니라 폭.
> 이 문서가 A(엔진)·B(데이터)·C(화면)·D(실측)의 정본이다. 값은 전부 **제안값**이고 5단계에서 잰다.

## 1. 흐름 (매주 · 등급 이벤트 한 줄기)

```
1. 등급 추첨   — 노말·레어·유니크·**히든** 넷을 가중 추첨(§3 규칙). 시즌 상한에 닿은 등급은 가중 0.
   🔴 사용자 확정(09-08): **히든도 확률로 들어간다.** 히든에는 조건이 있는 것과 없는 것이 섞여 있다 — 조건 있는 히든은 채웠을 때만 후보, 없는 히든은 늘 후보.
2. (자리 비움 — 히든 별도 검사는 없다)
3. 등급 안에서 — 조건 통과 · 반복 정책 통과 · 「이번 시즌 안 뜬 것」 우선 · 밀린 주 가중 · 가중 추첨으로 하나.
4. 비었으면    — 한 등급 아래로. 🔴 폴백이 한 번이라도 발동하면 `check:tiercoverage` 가 빨강(데이터 부족 신호).
5. 선택        — 플레이어가 고른다. 크기는 등급이 · 종류는 선택지가.
```

밖에 두는 것(지금처럼): 긴급(부상 등) · 주차 고정 필수(진로 허브·드래프트) · 시스템 소식(계약·보직·FA).
랜덤 풀 다섯(몸·미디어·소셜·팀 일상·훈련)은 **노말로 흡수** — 풀 파일은 노말 하위 갈래(`theme`)로 남겨 결이 섞이게 한다.

## 2. 등급표

| 등급 | 감각 | 시즌 빈도 | 시즌 상한 | 보상 폭 | 대가 | 보상 표시 |
|---|---|---|---|---|---|---|
| 노말 | 늘 오는 것 | 40~50 | 없음 | XP 1~3 · 사기·피로·관계·돈 | 없음 | 숫자 그대로 |
| 레어 | 가끔 오는 것 | 4~6 | 6 | XP 8~10 · 훈련 효율 N주 · 기회 | 가벼움(피로·돈) | 숫자 그대로 |
| 유니크 | 시즌의 사건 | 1~2 | 2 | 스탯 +1 · 영구 특성 · 멘토 · 성장률 | **있음**(관계·돈·다른 길 닫힘) | 종류만 |
| 히든 | 드물게 오는 사건 · 일부는 내가 그렇게 해서 만난 것 | **주 1% · 시즌 0.5** | 시즌 1 · 종당 커리어 1 | 스탯 +3 · 구종 · 잠재력 | 되돌릴 수 없음 | 종류만 |

**앞서 확정한 결정과의 관계**: ① 큰 갈림길 XP 8~10 = 레어 폭 · ② 즉시 스탯 상승 30~50건 = 유니크 총량 · ③ 주력 스탯 몰기 = 등급 안 선택지 설계 규칙. 셋은 따로 하지 않는다.

## 3. 등급 규칙 JSON 얼개 (`resource/data/master/events/tier_rules.json` · A)

```
{
  "weights":   { "normal": 80, "rare": 14, "unique": 5, "hidden": 1 },
  "seasonCap": { "rare": 6, "unique": 2, "hidden": 1 },              // 닿으면 가중 0
  "dryBoost":  { "rare": { "afterWeeks": 6, "perWeek": 3, "max": 30 } },  // 마른 시즌 방지
  "stateMod":  { "diligence": { "from": 60, "perPoint": 0.1, "max": 5 },  // 성실 60 위로 1점당 레어 +0.1
                 "condition": { "from": 80, "perPoint": 0.05, "max": 2 } },
  "starve":    { "perWeek": 1, "max": 10 },                         // 등급 안에서 밀린 주 가중
  "hidden":    { "careerCapPerEvent": 1 },                          // 종당 커리어 1회 · 총량 상한 없음
  "fallback":  "step_down"                                          // 비면 한 단계 아래 · 검사가 잡는다
}
```

## 4. 이벤트 파일에 더하는 칸 (A 스키마 · B 데이터)

| 칸 | 값 | 뜻 |
|---|---|---|
| `tier` | `normal` · `rare` · `unique` · `hidden` | 등급. 없으면 검사가 빨강(추론 안 함 — 갈아타기 끝) |
| `theme` | `body` · `media` · `social` · `team` · `train` · `career` · `people` · `money` · `story` | 결. 노말 다양성 · 시즌 집계 |
| `stage` | 기존 `career_stage` 조건 | 무대. 커버리지 검사가 무대×등급으로 센다 |
| `hiddenCondition` | 조건 배열(기존 50종 그대로) | 히든만. **화면에 안 보인다** |
| `cost` | 효과 객체 | 유니크·히든의 대가. 선택지가 아니라 이벤트에 붙는다(어느 갈래를 골라도 낸다) |

기존 `tier`(urgent/important/ambient)는 이렇게 옮긴다: `urgent` 는 그대로 등급 밖 · `ambient` → `normal` · `important` → B 가 판정(레어 후보).

## 7. B 의 등급 달기 기준 (4-2)

1. 결정 없음 → `읽기만` 유지하되, **한 줄 갈래를 붙일 수 있으면 노말로 승격**(예: 「알겠다 / 신경 쓰지 않는다」가 아니라 종류가 다른 두 갈래).
2. 즉시 스탯 · 관계 ±10 이상 · 돈 ±100 이상 → 유니크 후보 → **대가를 붙일 수 있나** 보고 붙이면 유니크, 못 붙이면 레어.
3. XP 합 6 이상 · 훈련/기회 계열 → 레어.
4. 나머지 → 노말. 노말은 갈래 둘이 **종류가 다른가**(XP 대 관계 · 사기 대 돈) 확인. 같은 종류 크기만 다르면 고친다.
5. `repeatable` 은 노말만. 레어 이상은 `once_per_season` 이상.
6. 히든은 **새로 쓴다**(§8). 기존 것을 히든으로 올리지 않는다 — 조건이 숨겨진 것이어야 하니까.
7. 부족분 표를 무대×등급으로 내되 **채우는 순서는 승격 → 읽기만 승격 → 새로 쓰기**다: ① 남는 노말을 레어·유니크로 올린다(§6 승격 규칙) ② 읽기만 154종에 갈래를 붙여 얇은 무대의 노말을 채운다 ③ 그래도 모자란 칸만 새로 쓴다. 히든은 전부 새로.

## 8. 히든 아이디어 (12 · 사용자 검토용 · 조건은 화면에 안 보인다)

> 아래 12 는 전부 **조건 있는** 히든이다. 사용자 확정대로 **조건 없는 히든**을 무대마다 하나둘 더 둔다(예: 「낯선 스카우트의 명함」 · 「이름 없는 후원자」 · 「우연한 특별 훈련」 — 뜨는 것 자체가 사건). 총량 **20~25** — 주 1% 면 15년 커리어에 약 8건이고 종당 한 번이라 그보다 넉넉해야 빈 등급이 안 난다. 조건 있는 것 중 넷은 §12 의 새 조건 종류가 있어야 쓸 수 있다.

## 9. 화면 (C 4-5)

- 이벤트 모달과 소식함에 **등급 칩**(노말은 칩 없음 · 레어 파랑 · 유니크 보라 · 히든 금색 — 색은 C 가 정한다).
- 유니크·히든은 선택지 힌트에 **종류만**(「큰 것을 얻는다 · 관계를 내준다」) · 결과는 고른 뒤 소식으로.
- 위기 이벤트(레어·유니크에 `theme: body` 또는 `crisis`)는 칩에 표시.
- 시즌 결산·기록 탭에 등급 집계(레어 N · 유니크 N · 히든 N) · 업적 셋(첫 유니크 · 히든 3 · 한 시즌 레어 6).

## 10. 완료 검사 (D 4-6 · `check:tiercoverage`)

- 무대별 3시즌 헤드리스 × 씨앗 셋: **폴백 발동 0** · 등급별 실제 빈도가 §2 범위 안 · 시즌 상한 위반 0 · 히든 커리어 상한 위반 0.
- 등급 없는 이벤트 0 · 레어 이상에 `repeatable` 0 · 유니크 이상에 `cost` 없음 0.
- 재회 12종·독립 9/12 재확인을 같은 판에서.
