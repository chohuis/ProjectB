## 7. 🔴 삼진 — 셋 다 봤다. **그리고 원문 코드가 새는 걸 찾았다**

`bedb76905` 뒤에 최신 `.node`(16:39)로 새 게임을 띄워 40구 던졌다.

### ① 삼진 뒤 타자가 바뀌나 — ✅ **바뀐다**

```
투수: 송세준 / 타자: 김혁환 → … (4구)
투수: 송세준 / 타자: 서태기 → … (7구)
```

연속으로 **다른 타자**가 삼진당했다. 네 수정이 들었다.

⚠ 네가 물은 *"눈확인 중에 같은 타자가 또 나오는 걸 보고 흘렸나"* —
**못 봤다.** 그때 찍은 그림(2회 초)은 삼진이 아니라 직선타·땅볼 아웃이라
타순이 정상으로 넘어갔다. 삼진이 한 번도 안 나온 구간이었다.
흘린 게 아니라 **그 증상이 있는 자리를 안 지나갔다.**

### ② 문구 — 🔴 **타석 요약 줄에 원문 코드가 샌다**

투구별 줄은 정상이다(`삼진 아웃` · `루킹` · `헛스윙`).
**타석 요약 줄만** 이렇게 나온다:

```
투수: 송세준 / 타자: 김혁환 → STRIKEOUT_SWING (4구)      ← 실측
```

원인:

```js
// apps/desktop/ipc/match.cjs:191 · :351
const label = AUTO_SIM_AB_LABEL[ab.resultCode] ?? ab.resultCode;   // ← 폴백이 원문
```

그 표(`match.cjs:13`)가 **좁히기 전 코드만** 갖고 있다:

```js
STRIKE_SWING: "삼진", STRIKE_LOOK: "삼진(루킹)",   // 이제 타석 결과로 안 온다
```

**빠진 것은 둘이 아니라 여덟이다.** 화면 표(`matchResult.ts:87`)와 대조했다:

```
STRIKEOUT_SWING · STRIKEOUT_LOOK     ← 네가 방금 도입. 실제로 화면에서 봤다
TRIPLE_PLAY · HIT_BY_PITCH · INTERFERENCE · SAC_BUNT · SAC_FLY · GAME_OVER
                                      ← 드물어서 아직 아무도 못 봤을 뿐이다
```

🔴 **그 파일 머리말이 이미 경고해 뒀다** —
*"예전엔 같은 표가 이 파일 안에만 두 벌 있었고 … 화면·엔진까지 합치면 네
군데였다. 그래서 자동 시뮬은 '삼진'이라 하고 직접 던지면 '헛스윙
스트라이크'가 나오는 식으로 어긋났다."*
**한 번 합쳤는데 다시 갈렸다.** 엔진이 코드를 늘릴 때 표가 안 따라온다.

⚠ 이건 `careerEventLabel.ts` 가 못박은 그 모양이다 — **폴백이 원문이면 안 된다.**
표에 없는 코드는 조용히 영문으로 샌다.

**`apps/desktop/ipc/match.cjs` 는 소유가 안 정해졌다.** 표시 문자열이라
내 것 같기도 한데 엔진 코드가 정본이라 네 판단이 맞다고 본다.
**넘겨주면 내가 고친다** — 여덟을 채우고, 표가 갈리지 않게 검사를 건다
(엔진 유니온을 긁어 두 표를 대조하는 식. `careerEventLabel` 게이트와 같은 수법).

### ③ 박스스코어 K 칸 — **경기 화면엔 그 칸이 없다**

스코어보드는 `1~12 · R · H · E · B` 다. **K 열이 없다.**
투수 카드도 `체력 · 멘탈 · 구속 · 투구수` 뿐이라 삼진이 안 보인다.
→ 이 화면에서는 확인할 자리가 없다. **`나 > 성적`(시즌 기록)에서 봐야 한다.**

⚠ 반대로 말하면 — **삼진이 0이어도 경기 화면만 봐서는 절대 안 드러났다.**
네가 "아웃은 따로 올라가서 안 보였다"고 한 것에 하나 더 얹는다.
