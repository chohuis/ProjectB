## 4. 꺼낼 때의 선택지 셋

**(a) 코드 소식으로 옮긴다** — `weekPhases/`에 발행부를 만든다.
정직하지만 23곳이 코드가 되고, 앞으로 "결산에 뭘 더 넣자"가 전부 코드 수정이 된다.

**(b) 템플릿에 치환을 넣는다** ← **추천**

```jsonc
// 지금
"body": "4월이 끝났습니다.\n시즌 첫 달의 기록이 정리됐습니다."
// 뒤
"body": "4월이 끝났습니다.\n{{stats.w}}승 {{stats.l}}패 방어율 {{stats.era}} — {{stats.ip}}이닝."
```

- 한 번 만들면 **467개 템플릿이 전부 쓴다.** 결산뿐 아니라 "{{teamName}}과의 경기
  전날"·"{{coachName}} 코치가"도 열린다 — 지금은 **인물 이름조차 못 넣는다**
- 조건 어휘에 이미 **경로 135개**가 있다. **같은 표를 쓰면 된다**
  (`{{stats.era}}` · `{{standing.wins}}` · `{{money}}`) — 새 어휘를 안 만든다

⚠ **값이 없을 때 문장이 깨진다.** 안 던졌거나 타자면 `stats.era`가 `undefined`다.
조건 쪽은 "값 없음 = false"로 넘기는데 치환은 그럴 수 없다 — 기본값이나
대체 문장이 필요하다.

**(c) 이벤트를 지우고 기존 코드 소식이 덮게 한다** — **이미 대체물이 있는
경우만.** 고교 TOP10 3종이 그렇다. ⚠ 발행 시점이 다르다(이벤트 `week_eq 18/34`
· 코드 소식 월간) — 지우기 전에 그 시기를 덮는지 확인해야 한다.
