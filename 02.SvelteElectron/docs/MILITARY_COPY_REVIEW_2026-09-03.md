🔴 **데이터를 하나도 안 고쳤다. 후보표다.** 최종 판단은 사용자 몫이다.

## ✅ 적용 완료 (B-27 · 2026-09-03) — 여덟이 다 닫혔다

사용자가 **「캘린더 20종도 합쇼체로 통일」** 로 확정했다. ①③⑤⑥ 을 위 표의
제안 문장 그대로 넣었다. **버튼은 평서체 관례 유지 · 자리표시자는 체언 종지 ·
이름은 안 쓴다.**

```
① 말투        본문 22종            → 합쇼체. 평서체로 남은 본문 0종
③ 부제·대시   제목 3 · 본문 대시 1  → 0
⑤ 라벨        11자리               → 종결형. 비종결 라벨 0자리
⑥ 부호        빼기표 6 · 구분자 18  → 하이픈·쉼표 한 벌. 남은 것 0
```

**손댄 자리 36 + 부호 24 = 60자리.** 기계로 다시 훑어 넷 다 0 을 확인했다.

⚠ **⑥의 구분자가 20 이 아니라 18 이었다.** B-25 에서 `PROMOTE_2`·`D30` 의
힌트를 줄이면서 가운뎃점 둘이 이미 사라졌기 때문이다 — 후보표의 35자리는
그때 값이다.

⚠ **낱말은 안 바꿨다.** `§9 손대지 말 것` 에 적은 대로 어미만 바꿨다 —
「해가 졌습니다」·「초코파이」·「구호가 산을 넘습니다」는 그대로다.

⚠ **첫 선택지 라벨 「받아들인다」 다섯(`MIL_EVT_*`)은 안 건드렸다.** ⑧에서
두 번째 선택지만 달았고, 본문 제안(§8 표의 가운데 열)도 **안 넣었다** —
그건 말투가 아니라 새 문안이라 별도 결정이다.

### ② `MIL_CAL_FIRE_1` — 이름을 문장 끝으로 옮겼다

```

**자리표시자를 체언 종지로 끝내면 조사가 안 붙는다.** 굴절형 표(15명 ×
조사)를 두는 쪽은 값이 안 맞아서 안 골랐다. 평서체는 그대로 뒀고, 60자
한 줄이 두 줄로 갈렸다.

🔴 **네 풀 전수 재검사 — 자리표시자 뒤 조사 0건.** `military_life` ·
`military_common` · `military_general` · `military_sports` 의 제목·본문·
라벨을 `{...}` 뒤 조사 정규식으로 훑었고 남은 게 없다.

### 부대원 이름 15명이 빈 이유 — 설계다

```

**결함이 아니라 사용자 몫으로 비워 둔 자리**이고, 폴백이 계급이라 화면은
돈다. 다만 그 폴백 때문에 ②가 「하사이」로 보였던 것이다 — 이름을 채우면
사라지는 문제가 아니라 **조사 쪽이 원인**이라 문장을 고쳤다.
**이름을 채울지는 사용자 결정이다.**
