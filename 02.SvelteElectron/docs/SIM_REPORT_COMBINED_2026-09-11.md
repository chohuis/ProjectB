## 2. 1차 30판 — 도구가 틀렸다

### 잰 것
성장 20판(프리셋 4 × 씨앗 5) · 안전 5 · 대충 5 · 각 12시즌 · 6병렬 · 벽시계 약 6시간.

### 나온 것

| 성향 | 판 | 프로시즌 | 통산G | 통산승 | 최고OVR | 수술(합) |
|---|---|---|---|---|---|---|
| 성장 우선 | 20 | 6 | 87 | **36** | 81 | **9건 (6/20판)** |
| **안전** | 5 | **8** | **153** | **73** | **83** | **0건** |
| 대충 | 5 | 6 | 102 | 47 | 82 | 3건 |

🔴 **안전형이 모든 칸에서 이겼다. 최고 OVR 마저.**

### 읽는 법이 둘이었다
- **(가) 설계대로다** — 무리하면 다치고 커리어가 짧아진다
- **(나) 도구가 틀렸다** — 「성장 우선」이 고르는 함수에 **피로·컨디션 항이 0개**다

**(나) 였다.** 근거는 최고 OVR 이다 — **성장을 고르는 쪽이 성장에서 지면** 그건 잘 고르는 게 아니라 자해다.

### 그 밖에 1차가 남긴 것
- **군 도달 0/30** — 자동 진행이 입대 모달에서 **늘 「연기」**를 골랐다. 트레이드·강등과 **같은 분류 착오**이고, 그 목록 주석이 이미 두 번 틀렸다고 적혀 있었다
- **연기 대가가 쌓이기만 하고 아무도 안 읽는다** — 연기에 불이익이 없었다
- **고졸 직행 8.3%** — 시작 능력치를 −9 한 뒤 「거의 보장」에서 반대편으로 넘어갔다
- ⚠ **물린 것 하나** — 「대학이 등급을 다 넘긴다」는 잘못이었다. 진로가 갈리는 해의 줄이 빠져 **분모가 어긋난** 것이고, 빼고 다시 세니 목표 안이었다. **없는 결함을 고치러 갈 뻔했다**

## 3. 사이에 고친 것 — 계측 도구

| 무엇 | 왜 |
|---|---|
| **성장형이 몸값을 본다** (계수 0.5) | 판을 안 돌리고 **선택지 559세트를 채점**해 골랐다. 계수 0 에서 안전형과 같은 답을 내는 비율이 **41.9% — 동전 던지기보다 낮다**(해로운 쪽을 적극적으로 골랐다). 3 이상이면 86~90% 라 성향이 둘로 무너진다 |
| **컨디션을 본다** | 자동 진행이 컨디션을 **아예 안 봤다**(피로·사기만). 컨디션은 훈련 산식에 곱으로 들어간다 |
| **성향 셋** | 성장 우선(즉시 스탯 먼저) · 안전(몸을 지킨다) · 대충(**씨앗 고정 무작위** — 「첫 갈래」는 사람이 아니라 데이터 작성 순서를 재는 꼴이다) |
| **군을 성향이 고른다** | 성장 미룸 · 안전 일찍 · 대충 무작위 |
| **연기 대가를 읽는다** | FA 관심도에서 읽는다(1pt = 명성 1) |
| **삼킨 예외를 센다** | 주석에 「프로 2년차 한 시즌 내내 매주 터졌는데 25시즌 런이 정상으로 보였다」고 적혀 있었다 |
| **정지 판정** | 연속 8회 안 움직이면 정지. 예전엔 조용히 빠져나가 **3·15시즌 재려던 검사 여섯이 짧게 돌고 통과**했다 |
| **판 JSON + 통합 보고서** | 데이터는 다 있었고 **꺼내는 자리만 없었다** |
| **자식 stderr** | 실패하면 stdout 800자만 찍었는데 **진짜 오류는 stderr 에 있었다** |
| **동시 실행 상한 6** | 🔴 **예전 8병렬 전멸은 동시 실행의 한계가 아니었다** — 상한이 순차 기준이라 병렬로 판당 1.4~1.6배가 되면 걸렸다. **죽은 건 판이 아니라 타이머**였다 |

### 🔴 그 김에 잡은 게임 결함 — 체육부대

**군을 성향이 고르게 하자마자 드러났다.**

```
체육부대 신청 → 탈락 → 모달의 「연기」 → 같은 주 → 신청 플래그가 그대로 참
→ 다시 탈락 → … 영영 그 주
```

실측: **2028년 49주차에서 주가 50번 연속 안 넘어갔다.** 30판 중 6판이 2시즌에서 끊겼다.

⚠ **아무도 못 밟고 있었다.** 화면에서 「신청」을 눌러야 참이 되는데 계측은 그 대기를 그냥 닫았다(= 미신청). **화면으로 신청을 누른 플레이어는 이미 멈추고 있었다.**

**고친 자리는 가드가 아니라 플래그다** — 결과를 처리하면 신청은 소진된다. 가드만 걸면 플래그가 영영 참이라 **이듬해엔 신청도 안 했는데 판정이 돈다**. 증상을 막는 대신 다음 해에 다른 결함을 만들 뻔했다.

🔴 **같은 뿌리의 세 번째다** — 트레이드 · 강등 · 체육부대. 무대나 소속이 바뀌는 대기를 「알림성」으로 분류해 그냥 닫던 자리다. **테스터가 겪은 「2군 가겠다고 했는데 안 내려간다」와 같다.**

## 4. 2차 12판 — 성향이 갈렸다

### 구성을 바꿨다
**프리셋 4 × 씨앗 1 × 성향 3.** 씨앗을 하나로 묶은 이유 — 답할 물음이 「성향 셋이 갈리는가」인데 **씨앗이 흩어지면 성향 차이인지 씨앗 운인지 못 가린다.**

### 나온 것

| 성향 | 최고OVR 전→후 | 수술 전→후 |
|---|---|---|
| 성장 | 81 → **89** | 9건(6/20판) → **0건(0/4판)** |
| 안전 | 83 → 80 | 0 → 1 |
| 대충 | 82 → 79 | 3 → **5(4/4판)** |

**셋이 각자 다른 것을 잘한다** — 성장은 가장 좋은 투수(OVR 89·수술 0) · 안전은 가장 많이 던지고 이긴다(685이닝·55승) · 대충은 어느 쪽도 아니다(수술 4/4·15승).

**1차에서 성장이 모든 칸에서 진 것은 성향이 갈린 게 아니라 한쪽이 나빴던 것이다.**

### 체력형이 살아났다 — 프리셋이 아니라 도구 탓이었다
```
성장형 체력형   프로시즌 4 · OVR 79   →   6 · OVR 88 · 통산 51승 (성장형 넷 중 승수 1위)
```
체력형은 몸으로 버티는 프리셋이라 **「몸을 안 보는 탐욕」과 제일 나쁘게 겹쳤다.**
⚠ **제구형만 안 올랐다**(80→80 · 부상 9). 프리셋 넷을 다 넣은 덕에 잡혔다 — 둘만 돌렸으면 못 봤다.

### 군에 간다 — 0/30 → 11/12
안전형 **4/4 전부** 실제로 간다(2028~2030 입대). 성장 3/4. **전부 체육부대 자리를 지나간다.**

### 🔴 확정 하나가 실측과 반대였다
성장형이 통산승에서 지는 이유가 **계수가 아니라 군 시점**이었다.
```
안전형   21~22세에 마친다   ← 등판이 없을 때
성장형   26~27세에 간다     ← 25경기 던질 두 해를 통째로 버린다
```
마지막 해를 나란히 놓으면 성장 25G/172IP/19승/OVR89 대 안전 25G/173IP/18승/OVR80 이다.
**「미루면 뛸 해를 안 버린다」는 전제가 틀렸다.**
→ 사용자 확정: **그대로 둔다.** 일찍 가는 쪽이 유리한 것이 현실과 맞고, 플레이어가 그걸 깨달으면 전략이 된다.
