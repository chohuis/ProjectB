# OnePitch 시드 데이터 (이관 소스)

중단된 `03.OnePitch` 프로젝트에서 이관한 **세계 데이터 원본**. 코드는 전부 제거했지만 이 데이터는
기획 문서(`03.OnePitch/02_기획/리그팀/`)를 기계 판독 가능한 형태로 옮겨둔 산출물이라 보존한다.

## 상태

**아직 이 프로젝트에서 소비하지 않는다.** ID 체계가 다르고(`team:seoul_ravens` vs `TEAM_HS_SEOUL_INNOVATION`)
리그 규모도 달라, 지금 `refs.json`을 갈아끼우면 Phase 6(리그 교체)이 끝날 때까지 앱이 동작하지 않는다.

- **Phase 4-4**(완료): 빠져 있던 정의 데이터를 채우고 무결성을 검증했다 — `team_power.csv` · `team_colors.csv` 신설.
- **Phase 6**(예정): master 포맷으로 이관하고 `refs.json`을 196팀(국내182 + 해외24)으로 교체하며 **스위치를 켠다.**

## Phase 4-4에서 채운 것

### `team_power.csv` — 전력★ 정본

기획 문서 표에만 있고 CSV로 옮겨진 적이 없던 값을 정본화했다. `source` 컬럼에 출처를 남긴다.

| source | 건수 | 방법 |
|---|---:|---|
| `doc` | 162 | `02_고교.md`·`03_대학.md`·`01_프로.md` 표에서 직접 추출 |
| `farm_inherit` | 10 | 프로 2군은 부모 1군 값 상속 |
| `budget_inverse` | 9 | 독립 시민구단 — 문서에 ★이 없어 **예산 공식을 역산**<br>`★ = (budget − 하한) ÷ (상한 − 하한) × 5` (전부 정수로 떨어짐) |
| `ranks_inferred` | 1 | 상무 피닉스 — 국방부 예산이라 `budget=NULL`. 과거 5시즌 평균 **1.4위**(리그 최상위)로<br>서울 레이븐스(1.6위, ★4)와 동급이라 **★4**. ★5는 "최강 명문·우승 단골" 티어(182팀 중 6팀)인데<br>상무는 2위도 두 번이라 해당 없음 |

**교차 검증**: 문서에서 뽑은 ★을 예산 공식에 다시 넣어 `team_org.csv`의 실제 예산과 대조 —
**161건 전부 일치, 불일치 0**. 문서 ★과 시드 예산이 서로 정합함을 확인했다.

★ 분포: ★1=6 · ★2=71 · ★3=71 · ★4=28 · ★5=6

### `team_colors.csv` — 팀 고유 식별색

`teams.csv`의 `color`는 **17종 라벨을 182팀이 돌려써** 식별색으로 쓸 수 없다(실측).
라벨이 지정한 색상(hue)의 의미는 지키면서 명도·채도를 벌려 팀마다 고유 hex를 배정했다.

- **182팀 전원 고유, 중복 0**
- **최소 색거리 ΔE = 7.6**, `ΔE < 5`인 쌍은 16,471쌍 중 **0개** (JND ≈ 2.3, 5 이상이면 한눈에 구분)
- 라벨 인지 유지 — 남색 팀은 전부 navy 계열, 감귤은 `#E26132`
- 다크 네이비 UI 위에서 읽히도록 명도를 0.30~0.70으로 제한
- 프로 2군은 부모 1군에 **가장 가까운** 색 (ΔE 15~26) — 연고·정체성 공유를 색으로도 표현
- `label` 컬럼에 원래 라벨을 남겨 텍스트 서술("남색 유니폼")에 계속 쓸 수 있게 했다

## 알아둘 것

- **전력★은 이 데이터에 없다.** 기획 문서(`02_고교.md` §3 등)에만 있고 시드로 옮겨진 적이 없다.
  OnePitch는 대신 `team_season_ranks`(최근 5시즌 실측)에서 별점을 계산했다.
- 대학 조편성 19팀·독립 9팀 전력★ 등 **기획 문서가 비워둔 값을 역산해 채운 항목**이 있다.
  근거는 `03.OnePitch/03_설계/12_구현확정_결정요약.md` §A-1.
- 팀 색상은 102개교가 17가지 색을 돌려쓰는 구조라 **고유 식별색으로는 쓸 수 없다**(실측 확인).
