# OnePitch 시드 데이터 (이관 소스)

중단된 `03.OnePitch` 프로젝트에서 이관한 **세계 데이터 원본**. 코드는 전부 제거했지만 이 데이터는
기획 문서(`03.OnePitch/02_기획/리그팀/`)를 기계 판독 가능한 형태로 옮겨둔 산출물이라 보존한다.

## 상태

**아직 이 프로젝트에서 소비하지 않는다.** 포맷이 OnePitch의 content.db 스키마(CSV/TOML → rusqlite)
기준이라, `resource/data/master/` 포맷으로 변환하는 작업이 남아 있다.

## 파일

| 파일 | 내용 | 규모 |
|---|---|---|
| `leagues.csv` | 리그 5종 | 고교·대학·독립·프로1군·프로2군 |
| `teams.csv` | 팀 정본 | **182팀** (172 + 프로2군 10) — id·이름·연고·리그·색·구장 |
| `schools.csv` | 학교 엔티티 | 고교 102 + 대학 50 (팀과 분리) |
| `stadiums.csv` | 구장 + 파크팩터 | **27개** (프로 10 전용 + 고교 8권역 + 대학 5조 + 독립 4) |
| `team_traits.csv` | 팀 특성 3슬롯 | 철학·자원·위상 (전 182팀) |
| `team_org.csv` | 팀 예산 | `budget = 하한 + (상한−하한) × (전력★/5)`. NULL 11건은 의도된 예외(상무 1 + 2군 10) |
| `team_season_ranks.csv` | 과거 5시즌 순위 | 고정 세계관, 510행+ |
| `team_titles.csv` | 과거 우승 기록 | 대회별 5시즌 |
| `team_rivals.csv` | 라이벌 페어링 | 지역·서사 기반 |
| `name_pools.csv` | 이름 풀 | ko/en/jp 3로케일 — **원래 이 프로젝트(`master/players/name_pool_*.json`)에서 포팅해간 것** |
| `generation_rules.toml` | 리그별 로스터 규칙 | 로스터 규모·투수 비율·OVR 구간. **스케일 20~80(50=평균)** |
| `personality_rules.toml` | 성격 가중치 | 172팀 개별이 아니라 철학12 + 위상7 + 역할7 = **26개 컨텍스트** 룩업 |
| `pitch_types.csv` | 구종 카탈로그 | 10종 |
| `events.toml` | 이벤트 콘텐츠 | **52개** 저작분. `bodies`는 JSON 배열(문장 뱅크 — 직전 문장 제외하고 랜덤 선택) |
| `achievements.toml` | 업적 | 3개 |
| `world_config.toml` | 월드 시드 | `canonical_seed = 20260714` |

## 알아둘 것

- **전력★은 이 데이터에 없다.** 기획 문서(`02_고교.md` §3 등)에만 있고 시드로 옮겨진 적이 없다.
  OnePitch는 대신 `team_season_ranks`(최근 5시즌 실측)에서 별점을 계산했다.
- 대학 조편성 19팀·독립 9팀 전력★ 등 **기획 문서가 비워둔 값을 역산해 채운 항목**이 있다.
  근거는 `03.OnePitch/03_설계/12_구현확정_결정요약.md` §A-1.
- 팀 색상은 102개교가 17가지 색을 돌려쓰는 구조라 **고유 식별색으로는 쓸 수 없다**(실측 확인).
