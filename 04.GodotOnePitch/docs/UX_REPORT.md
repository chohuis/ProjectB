  "동결 해제 후"로 뺀다

# 축 2 — 탐색

## 껍데기 골격은 같다

```
MainScreen (main_screen.tscn)
└ Pad/Col
  ├ Header   DateRow(날짜·요일·주차) + WhoRow(선수명·팀명)

     ├ Main   TabHost
     └ Right  훈련 계획 · 다음 경기 · 진행 버튼 · 진행 막대
```

02는 `170px / 1fr / 220px`(`MainPage.svelte:637`, 좁으면 `154/196`)이다.
**탭 여섯도 같다** — 소식 · 나 · 팀 · 리그 · 인물 · 일정.

## 04엔 키보드가 통째로 없다 — **지금 하자**

```

  _unhandled_input · _input( · InputEventKey · KEY_SPACE  →  0건
```

안 먹게 막아 뒀다(`:58`). **04는 마우스만이다.**

⚠ **검사 전제와 얽힌다.** `04/CLAUDE.md`가 `--ignoreHeadlessMode`를 쓰는 근거로

  못 돌리면 그 검사만 따로 빼거나, 키 처리를 함수로 뽑아 함수 단위로 검사한다.
  **후자를 권한다** — 화면 검사를 헤드리스 밖으로 내보내면 CI가 갈린다
