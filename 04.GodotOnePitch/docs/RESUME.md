```
requested = effective * (1 + 비율)                     비율 −0.2 ~ +0.2
문턱      = effective * 1.15
            * (1 + (기간 − 기본기간) * 0.03)
            * 노트레이드 0.95
            * 구단옵션 [1.0, 1.05, 1.10]
            * 선수옵션 [1.0, 0.97, 0.94]
확률      = 문턱 안이면 95, 넘으면 max(0, 95 − 초과비율*400)
역제안    = 문턱 안일 때만
```

⚠ **문턱도 같은 배수를 탄다.** 제시액만 올리고 문턱을 그대로 두면
**"더 주는데 더 짜다"**가 된다 — 02 주석이 그렇게 적어 뒀다.

⚠ **문턱 안이 95지 100이 아니다.** 100으로 두면 "확실히 된다"가 되어
협상에 긴장이 사라진다.

⚠ **확률이 가파르다.** 초과 비율 × 400이라 **5%만 넘겨도 75%**다.

⚠ **F-7이 전제였다.** 협상 화면에 띄울 제시액을 내는 코드가 없었으므로

```bash

```

⚠ **P0의 "2,124경기 2초"는 두 군데가 틀렸다.** 경기 수를 적게 잡았고,
**게임은 시즌을 통째로 안 돌린다** — 이제 일 단위로 진행한다.

## 남은 것

### 진행 단위가 **일 단위**로 바뀌었다 (사용자 결정)

프로는 경기가 거의 매일 있는데 주 단위로 진행하면 **한 번에 여러 경기가
한꺼번에 끝나서** 자기 등판을 골라 볼 수 없다. 02 설계 문서도 원래
"경기일·이벤트 발생 시 진행 정지"였다(DESIGN.md §209) — 구현만 주 단위였다.

```
D1 달력   sim/calendar.gd    시즌 일차 ↔ 날짜 · 주차 파생 · 요일   ✔
D2 일정   sim/schedule.gd    라운드 로빈 → 요일 규칙으로 날짜 배정  ✔
D3 진행기  sim/day_engine.gd  하루씩 / 다음 이벤트 전날까지        ✔
D4 화면   M7에서            날짜 표시 · "다음 경기까지"
```

⚠ **시간 축만 일 단위다.** 성장·훈련·재정·관계는 7일마다 그대로 돈다 —
밸런스를 안 건드려야 02 실측값과 대조할 수 있다.

⚠ **일정을 압축하지 않는다.** 02처럼 프로를 1~50주에 편다. 압축(24주)은
밀도와 진짜 오프시즌을 주지만 **투수 피로 밸런스를 바꾼다** — 등판 간격이
12일 → 5.8일이 되면 등판 간 회복이 48 → 23으로 반토막인데 손실(약 57)은
그대로다. 시즌 내내 피로 바닥에 붙는다. 되돌리려면 `Schedule.LEAGUES`의
기간만 바꾼다.

⚠ **`radiusGate`를 안 옮긴다** (사용자 결정). 해외까지 매일 풀 시뮬한다.
실측 최악의 날 **118일차 83경기 = 0.71초** (게이트 1초). 압축했을 때(77)보다 오히려
많다 — 성기게 펴면 리그들이 어떤 날엔 몰린다.
