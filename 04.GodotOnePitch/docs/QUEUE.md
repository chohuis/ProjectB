# 이주 작업 큐

**위에서부터 하나씩.** 모듈 하나를 끝낼 때마다 여기 체크하고 커밋한다.

⚠ **이 파일이 이어달리기의 바통이다.** 세션이 끊기거나 컨텍스트가 요약돼도
여기만 읽으면 정확히 이어진다. `RESUME.md`는 **왜 그렇게 했는지**를 적고
여기는 **무엇이 남았는지**만 적는다.

## 모듈 하나의 리듬 (건너뛰지 않는다)

```
① 02 원본을 읽는다        — 값과 근거를 그대로 옮긴다. 밸런스 동결
② 검사를 먼저 쓴다
③ 빨간불 확인            ← 통과하면 그 검사가 아무것도 안 보는 것이다
④ 로직을 옮긴다
⑤ 배선한다               — 안 부르면 없는 것과 같다 (02가 그 결함투성이)
⑥ 실측한다               — measure:*  세계로 굴려 본다
⑦ 변이 검증              — 100% 아니면 검사를 보강한다
⑧ 전체 검사 · 고아 0
⑨ 화면을 바꿨으면 띄워서 본다
⑩ 커밋 · 이 파일 갱신
```

## 막혔을 때 — **멈추지 않는다. 적어 두고 다음으로 간다**

**02가 완제품이라 답은 거의 다 거기 있다.** 값·순서·근거가 커밋 메시지와
주석에 적혀 있으니 물을 게 없다. 그대로 옮긴다.

### **02를 실제로 돌려서 물어본다** — 문서에 없어도 답이 나온다

**02는 죽은 코드가 아니라 살아 있는 대조 장치다.** Rust 엔진이 이미 빌드돼
있고(`engine-native.win32-x64-msvc.node`) `node_modules`도 있어서, Electron
없이 `npm run ...`이 그대로 돈다:

```bash
cd 02.SvelteElectron
npm run test:fa · test:growth · test:draft · test:promotion · test:career
npm run measure:draft · measure:devplayer · measure:training · measure:relations
npm run test:rosterbalance · test:npclifecycle · test:careerpaths
node -e "const d=require('./resource/data/master/players/generation_rules.json'); ..."
```

⚠ **읽기만 한다.** 돌리는 건 소스를 안 바꾼다 — 로그·임시 DB만 쓴다.
02 파일을 **고치지는 않는다.**

실제로 이렇게 값 셋을 추측에서 실측으로 바꿨다:
`developmentPlayerRules.intakeMax` 10 · `salary` 2000 ·
대학 한 해 정원 = `rosterSize / gradeMax` = 8.

02를 돌려도 답이 안 나올 때만 아래에 ❓로 적고, 제일 그럴듯한 값을 골라
**근거를 주석에 남긴 뒤 계속 간다.** 멈추면 루프가 죽는다.

02에 답이 없는 부류는 셋뿐이다:

1. **04가 02와 다르게 정한 것의 파생** — 일 단위 진행 · 해외 풀 시뮬 ·
   1440×900 가로. 02엔 대응물이 없다
2. **02의 명백한 결함** — 그대로 옮길지 고칠지는 밸런스 판단이다.
   **기본은 그대로 옮기고 검사로 못 박는다**(대조가 깨지면 안 되니까)
3. **성능 게이트** — 02는 Electron이라 기준 자체가 다르다

### 묻어 둔 질문

- ❓ **해외 팜 리그 연봉 배수**가 02에 없다. 국내 1군:2군 비(0.3배)로
  파생했다 — `data/salary_rules.json`. **02는 해외 팜 연봉을 아예 안 만든다**
  (`leagueMult`에 항목이 없다). 돌려도 답이 안 나오는 부류다

### 02가 준 기준선

`measure:devplayer` 3시즌 실측 — **04가 이 근처면 맞는 것이다**

```
진로 분포     그만둠 824~924 · 대학 400~483 · 독립 15~125 · 2군 15~37
경로별        draft_undrafted → 대학 883 · 독립 140 · 2군 52 (3시즌 합)
2군 구성      38팀 1,263명 중 육성 100명 · 육성 비중 중앙 0 · 최대 0.26
드래프트 가치  지명자 1군 도달률 0.36 · 육성선수 0.05
연봉          지명자 중앙 3,733 · 육성 2,000
```

⚠ **02도 매년 900명 가까이 야구를 그만둔다.** 04의 ~1,000명은 결함이
아니라 비슷한 수준이다 — 02 주석의 판정선이 "1,000명대면 배선이 죽은 것"이다

**04 실측 (A-3 뒤)** — 대학은 맞고, 2군·독립이 갈렸다

```
        대학      2군      독립     그만둠
04     400~416   100~101   0~7    1,020~1,068
02     400~483    15~37   15~125    824~924
```

⚠ **규칙 순서는 02 그대로인데 결과가 다르다.** 원인은 규칙이 아니라
**04의 2군 로스터가 정원(34)에 딱 맞춰져 있는 것**이다 — 육성 자리가 팀당
10개씩 그대로 남아 매년 100명을 흡수하고, 그 바람에 독립까지 내려오는
사람이 없다. 02는 2군이 [38,40,40,…,43]으로 이미 정원을 넘겨 있어서
육성 자리가 거의 없었다.

**값을 만지지 않는다** — 02 규칙(`intakeMax` 10)을 그대로 쓴 결과다.
2군 로스터 두께가 02와 달라진 이유(승강·콜업 미이관)를 먼저 봐야 한다.
**A-5 트레이드·승강이 붙은 뒤 다시 잰다.**
